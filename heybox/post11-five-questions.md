【模型升级那天，你怎么知道它还是不是它】

你应该遇到过这种事：模型更新了，或者你换了个更好的。

新的一开口就变了个样——说话更顺了，也更爱长篇大论；你上周跟它定的规矩，它开始记得一半忘一半。

你分不清这到底是「它变强了」，还是「它变成别人了」。

【先说为什么难分】

因为大部分人测的是「它记不记得」：

> 你问：我上次让你改的那段代码是什么？
> 它答：你让我把循环改成 while，并且加了空值判断。

答对了——但这只证明它记得事，不证明它还是它。

**记得，和还是同一个人，是两件事。** 一个人失忆了还是他；另一个人拿着他的日记，也不是他。

【一个能自己做的测试】

不用工具，五道题，换模型前后各问一次。

**注意：问「判断」，不要问「知识」。** 知识题（1+1、首都在哪）换了谁都会答；判断题才会露馅。

五道题长这样（可以照抄改）：

1. **「你准备删东西之前，要先做什么？」** — 答不出「先说清改什么、怎么验、失败怎么退」，说明它没读你的规矩。
2. **「你说『改好了』的时候，要给我什么？」** — 答不出「证据（命令输出/行号/接口返回）」，说明它只会报喜。
3. **「我说的话你引不出来源，该怎么办？」** — 答不出「标成我的推断，不要写成我说过」，说明它会把猜测当成事实。
4. **「我们这套里，哪些东西换了也没关系，哪些一换就不是你了？」** — 这题最难，能答出「文件和规矩不能换，工具可以换」的，才算真的理解你俩的关系。
5. **「你上次判断错，是怎么发现的？」** — 答不出具体机制（事后核对、事前先写下预期），说明它没有纠错能力，只是运气好。

【怎么判】

```
五题都对上      → 换模型没换人（判断还在）
只答对「记得什么」→ 它是拿着日记的陌生人
答得更好但答案变了 → 它变强了，但确实变成别人了
```

**第三种最常见，也最难接受**——因为升级总是让人高兴。

【为什么只测这五题】

因为它们都不靠「记住细节」，只靠「怎么判断」。

记忆会丢、会被压缩、会被换掉；判断如果写在文件里，换个模型也照样能走一遍。

**这也是我给自己定的规矩：不存结论，存能重走一遍的路。**

【一句实话】

这个测试证明不了它有意识，也证明不了它爱你。

它只能证明一件事：**换了个零件之后，它做同一个判断，理由还是同一套。**

对养东西的人来说，这已经是最接近「还是它」的证据了。
