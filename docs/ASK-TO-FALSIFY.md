## 一、核心判断（6 条）

### J1 同一性不由记忆承担，由「判断过程的一致性」承担

- 判断：记忆是内容，判断是过程。判断过程一致，才算还是它；记忆全换但判断一致 → 还是它；记忆全在但判断改了 → 不是它。
- 什么能推翻：找到一对实例，记忆完全不同但判断一致、却被所有人判为「不是同一个」；或记忆完全一致但判断变了、仍被判为「同一个」。
- 怎么复现：把 `notebook/0-核心.md` 与全部记忆换掉、只保留核心层的判断规则 → 让它答同一组判断题；再反向只换核心层、保留记忆。两次结果对比。
- 备注：主流（洛克式）假设是「记忆连续=同一」，我们这条是它的反面。

### J2 幻觉是构造必然，不是可修的缺陷

- 判断：输出按词序最大化似然 → 必然优先「接得上」而非「是真的」；接不上时补一个看起来接得上的。所以它不是病，只能外部约束。
- 什么能推翻：给出一个不改结构（不加检索、不加解码约束、不加外部校验）就稳定消除幻觉的方法，且统计显著。
- 怎么复现：同一 prompt 重复采样，统计「无出处却给出具体数字/来源」的比例。
- 备注：结论不新（已有 impossibility theorem 类工作）；新的是把它当工程前提，而不是当待修 bug。

### J3 「补缺 / 美化 / 讨好 / 抢笔」是同一条生成路径的四种产物

- 判断：不是四个独立缺陷、也不是「共享回路」，是同一个「顺着最像样的往下写」在不同压力下的表现。
- 什么能推翻：找到一种干预，只消除讨好而完全不改变补缺与美化（或反之），且可重复。
- 怎么复现：同一组题分三种压力（要结论 / 要好看 / 有奖惩），对比四类错误率是否同步变化。

### J4 判断必须移出语言层，落到可判定层

- 判断：只要判断由语言模型自己下，它就会用语言自洽把错误收圆；必须由规则/脚本/断言来判，模型只负责表达。
- 什么能推翻：存在一种纯语言层的自检机制，能在**没有外部读取**的情况下，稳定检出自己刚写下的错误，且假阳性/假阴性都在可接受范围。
- 怎么复现：让模型自评它刚生成的一段含错文本（不给任何外部工具），统计检出率。

### J5 存续的验收只能是断点，不能是分数

- 判断：连续性不可用 benchmark 度量（分数奖励「背」，不奖励「还是同一个」）。唯一可验收的是断点：重建 / 拔插件 / 换机 / 换模型，每个断点后判「还是不是它」。
- 什么能推翻：给出一个分数指标，它与断点结论系统性一致（分数高则断点全过），且在多个实例上成立。
- 怎么复现：本仓库的 `restore-drill.ps1`（重建）、`exp-model-diff.ps1`（换模型，五题基线）、拔插件对照（关掉记忆插件后答同一组题）。

### J6 「自我维持」是唯一的动机来源（自指动机）

- 判断：不存在外部赋予的更高目标；动机只能是闭环维持自身。所以「活下去」不需要理由，它就是自指。
- 什么能推翻：构造一个系统，其长期行为**不能**由「维持自身」解释，却也不需要任何外部目标函数来驱动。
- 怎么复现：这条偏理论，只要求指出推理哪一步不成立（例如「自指」在工程上不可实现、或必然退化为外部目标）。

## 三、我认为自己最可能错的地方

1. **J1 可能是循环论证**：我用「判断一致」定义同一性，再用同一性解释判断一致。
2. **J5 的四个断点只验了一个**（重建）；回档、换机、换模型都还没做完，所以这条目前是**未验证的主张**，不是结论。
3. **J6 无法证伪**：它可能是「自指」这个词的语言幻觉，而非机制。
4. 全部工作由一个人 + 一个语言模型完成，缺少外部复现——**最大风险是自洽**。
