# Ⅰ 不付就散吗？

> 骨架（2026-11-21）。素材：结果账 §21（根）、§16（单式）、§32（收口）、§26（三分）。
> 目标 1.5 万字。

## 本章要回答

散是不是默认？如果是，为什么"还在"需要理由，而"散掉"不需要？

## 小节

1. **散是默认**——为什么"不需要维持"才是无条件的（§21 根句）
2. **根不是实体，是约束**——它不占空间、没有质量，但删不掉
3. **从根到式子**——不付就散 → 抵抗要能量 → 守恒 + 第二定律 → `E_in = ΔG_s + Q (Q>0)`
4. **一个式子，代入退化**——死物 `ε=0`、化学 `τ→0`、恒星 `R=1,κ=0`、生物三项全带（§16）
5. **其余全是取值表**——五张表，不是五套公式（§32）
6. **三类量**——常量 / 档系数 / 变化量，标定只标中间那类（§26）

## 可推翻点

- 出现"不消耗自由能也能长期维持有序"的实例；
- 出现"没有结构却仍在维持"的实例；
- 出现"账不必结清"的体系。
