# Ⅲ 同一个式子能跨几层？

> 骨架（2026-11-21）。素材：结果账 §1–14（老账）、§15（`δ`）、§19（供给式）、§30–31（供给筛选）、§33–35（社会层）、§44（物种层）。
> 目标 3 万字（本书最重的一章）。

## 本章要回答

一个式子从虚粒子用到人类物种——它是真的跨过去了，还是每层都在偷偷换公式？

## 小节

1. **化学层**：耗散占比 `Q/E_in`；步数成本（§1–2）
2. **恒温账**：24×/30× 实测，食物 5.4×（§3）
3. **温度门槛**：±5℃ 与 Q10（§4，我们算的，文献没直接给）
4. **边界层 `δ = r0`**（§15）：`Sh=2` 是别人的，`δ` 是几何给的、不是自由参数
5. **标度与指数**（§6–8）：1/3、2/3、0.75 是三种主导项；`ε` 0.53 → 0.33（变大换通量不是效率）
6. **死物**（§11）：石头 `E_in=0`，只散
7. **花区供给式**（§19）：`E_in = 自养 + 异养`，死物两项归零
8. **供给是筛选器，不是调节器**（§30–31）：供给少不压代谢率，只筛掉 `E_in < C_m+L` 的；跨代降需求是筛选不是适应
9. **社会层**（§33–35）：人均 2.43 kW（人的代谢只占 4%）；三量 `D`／`v`／`r`；`Λ` 必须逐个体算
10. **物种层**（§44）：人口对 MVP 余量 1.6×10⁶ 倍；弱点在 `T_ref`（25 年）与 `E_in` 链条窄

## 可推翻点

- 每一层都必须给出"这一层的主导项是什么"——给不出的那层，就是偷偷换了公式；
- 若某层的指数与该层主导项对不上（如大尺寸原核实测 0.32 vs 输运 1/3），就要改的是主导项归属，不是数字。
