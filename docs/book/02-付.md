# Ⅱ 这笔账付在哪三栏？

> 骨架（2026-11-21）。素材：结果账 §17（整合式六步）、§28（变形顺序与 `R` 启用）、§26、§23/§25（`E_restore`）。
> 目标 1.5 万字。

## 本章要回答

"付得起"具体指什么？为什么是三栏而不是一栏？

## 小节

1. **六步顺序式**（§17）：`E_in` 取最小 → 净日常 → 净恢复 → `R=step()` → `Λ` → 死活
2. **顺序不能换**——每一步只用前面定义过的符号（我曾把 `Λ` 塞进 `R` 的定义，是循环引用）
3. **三关剪枝**（§17）：L1 生死 → L2 维持 → L3 分配；`R=0` 后面全跳过
4. **`R` 是结果不是输入**——`R = step(净恢复)`；正推输入只有六个量
5. **`R` 怎么测**（§28）：扰动 `E_in` 降 ≥10% 或 `L` 升 ≥20%；观测窗 `3×T_ref`；判据＝回原状态且能跑完一圈
6. **变形顺序**（§28）：无量纲化 + 主导平衡，最小项主导 → 三个指数是三种主导项
7. **`E_restore` 的实测**（§23/§25）：人 64 MJ（6 天余额，下界）／本机 26.6 J（局部下界）

## 可推翻点

- 若出现"余额不够但结构仍长期维持"的实例，第一栏不成立；
- 若 `R` 能在 3 个周期内由外部代付恢复而仍算它自己恢复，`R` 的定义要改。
