# Ⅴ 算出来的是真的吗？

> 骨架（2026-11-21）。素材：结果账 §22–29（取数、`ε*`、变形、深海鱼与蜂鸟）、§38–39（验收与医保数据）、§24（撞一次）。
> 目标 1.5 万字。

## 本章要回答

这套东西给的是"能算"还是"算得对"？哪些数被验过，哪些只是标定？

## 小节

1. **撞一次：每拍 ≈ 1 J/kg**（§24）：小鼠／人／马／大象，跨 5 个量级体重，±15%
2. **蜂鸟盲测判"部分"**（§29）：预测 4.0 mJ vs 实测静息 5.58–7.82 mJ → 偏低 40–95%，系数要按体型档分层
3. **`ε` 按档取数**（§22）：0.53 / 0.33；**`ε*` = 0.36**（贴阈值活的那一档）
4. **可算 / 不可算**：分布能算、轨迹不能算（混沌＝内禀敏感 + 分布固定）
5. **取数纪律**（§38）：先怀疑解码，再怀疑动态加载；命中 0 要写出命中数
6. **社会层验收**（§39）：医保参保 13.27 亿（94.2%）、池子冗余 1.30 年、未覆盖 5.81% = 斩杀线的真实位置
7. **仍缺的两格**：返贫率、个人实际自付比例——没取到就不许把 `r` 写成精确值

## 可推翻点

- 预登记 6 条：1 成立 / 2 推翻 / 3 部分——**推翻的那两条本身就是这一章的证据**；
- 任何"绝对值"必须标"下界/估计"；只有比值可以当结论。
