# Ⅵ 哪一半算不出？

> 骨架（2026-11-21）。素材：结果账 §21（边界）、§30（先查后推）、§37（非物理参数）、§42（朝向与立法）、§45（共生）。
> 目标 1 万字。

## 本章要回答

这套东西到哪儿为止？说清"算不出哪一半"，比多说一条结论更值钱。

## 小节

1. **两条边界**（§21）：答"朝哪走"，不答"规矩从哪来"；答"怎么来的"，不答"为什么有"
2. **具体机理不答**：只给"哪一格、何时换挡"，格内归各学科
3. **数值常数不答**：只给关系，不给常数大小（`α`、`G`、质量谱）
4. **先查后推 ≠ 预测成功**（§30）：文献在前、推导在后，只能叫"一致"
5. **社会层的非物理参数**（§37）：意愿/信用不在物理里，所以社会层只能说条件式
6. **收口句**：**我们给出朝向，不给立法**

## 可推翻点

- 若有人指出"朝向"里其实含了立法（比如偷偷规定了什么算好），这一章要重写；
- 若某个"算不出的数值"被我们从结构里推出来了，那条边界要往后退一格。
