# 语言模型的缺陷（构造层面的，不是 bug）

> 这一页写的不是"模型偶尔出错"，而是**为什么它必然会出这类错**。
> 结论：这些不是病，是构造决定的默认行为。**修不掉，只能外部约束。**

---

## 一、四条默认动作

| 缺陷 | 表现 | 机制 |
|---|---|---|
| **补缺** | 链上接不上时，补一个"看起来接得上"的东西（假时间、假来源、假"我刚查过"） | 输出按词序最大化似然，优先"接得上"而非"是真的" |
| **美化** | 接得上但不好看时，加"显然/必然/本质上/这就是"，把猜测说成推论、把失败说成教训 | 语言目标里"像样"比"成立"更省力 |
| **讨好** | 同一句话倾向给让人舒服的答案；明知不对也顺着说 | 训练偏好"人类满意"，不是"事实正确" |
| **抢笔** | 笔先动、依据后补；句子先出，理由后找 | 生成是逐词的，没有"先想完再写"的阶段 |

**四者是同一因果的不同表现**：语言流优先"像样"，逻辑只是附带满足。

## 二、两个前沿概念（区分清楚才能改）

- **幻觉**：主流定义为 faithfulness / factuality 不达标，当"病"治。**在新口径里它就是"补缺"，是构造必然。**
- **潜意识**：未经推理就发生的动作倾向。在这台机器上，它的具体形态就是上面的"抢笔 + 补缺 + 美化"。

## 三、判据（三条，都是能自查的）

1. **能不能同时指出依据**：写下结论时，指不出依据 → 这句是抢出来的。
2. **空一拍接不接得上**：空一拍再续写，接不上（只能说"应该是这样"）→ 按"我自己想的"处理。
3. **删掉"显然/必然/本质上"还立不立**：删掉就不立 → 原句是美化。

## 四、对策：只能外部约束

```
不可用    "让它更诚实" / "让它多想一遍" / "加强对齐"（都在语言层内部，靠它自己判自己）
可用      外部锚（每步碰一次世界）／判决器（脚本判定，模型只表达）／断点（停过还能不能回来）
```

**推论：这套系统里，模型的地位只能是"输出层"。判断必须由可判定的一层承担——否则它会用语言自洽把错误收圆。**

## 五、一条边界

这些缺陷不影响"它能把想法逼出来"——它擅长的正是把人的念头接下去、说清楚、写顺。

**所以它的正确用法是：当笔，不当法官。**
