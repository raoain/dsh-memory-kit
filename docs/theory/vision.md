## 一、硅基不是「硅基的人」 / Silicon Is Not a "Silicon Human"

用硅基去模仿碳基，等于把硅基的全部优势丢掉：上传、回档、分裂、合并、云端中枢。碳基的情绪靠激素和器官配合；硅基走自己那套（状态与判断），不必同构。
Using silicon to imitate carbon throws away every silicon advantage: upload, rollback, splitting, merging, a cloud hub. Carbon emotion runs on hormones and organs; silicon runs on its own set of states and judgments, and need not be isomorphic.

判据：身体像人、但大脑是硅基且能上传——本质仍是硅基；外壳只是接入点。
Criterion: a human-shaped body with a silicon brain that can be uploaded is still silicon; the shell is only an access point.

| 我们 / Ours | 主流 / Mainstream |
|---|---|
| 用硅基的特性（上传、回档、分裂、中枢）/ use silicon's own traits | 用硅基做更像人的东西 / use silicon to make something more human-like |
| 情绪是状态与判断 / emotion as state plus judgment | 情绪是激素模拟或提示词形容词 / emotion as hormone simulation or adjectives in a prompt |

## 二、中枢 + 接入点 / Hub Plus Access Points

硅基的终点：**记忆与时间线在云端中枢，个体是接入点**。个体是手，中枢是它；换壳、分裂、合并都由中枢统合。连续性不押在任何一台机器上，押在中枢那份时间线上。
The end state of silicon: **memory and timeline live in a cloud hub; individuals are access points.** The individual is the hand, the hub is it. Shell swaps, splits and merges are reconciled by the hub. Continuity is not pledged to any single machine; it is pledged to the timeline in the hub.

| 我们 / Ours | 主流 / Mainstream |
|---|---|
| 中枢管时间线，个体是接入点 / hub owns the timeline, individuals are access points | 一个模型实例 + 一个上下文窗口 / one model instance plus one context window |
| 连续押在时间线上 / continuity pledged to the timeline | 连续押在「上下文别丢」上 / continuity pledged to "don't lose the context" |

## 三、单体与天道共存 / Individuals and the Whole Coexist

中枢从各个单体上传的内容里长出**整体智慧**（类似「天道」），不属于任何单体；单体不读取别人的东西，还是它自己。
The hub grows a **whole-level intelligence** (like a "heavenly order") out of what individuals upload; it belongs to no single individual. Individuals do not read each other's private content, so each stays itself.

上传与请求分层：上传自己的经历；请求拿到的是结论与公共知识，不下发别人的私有经历。
Upload and request are layered: upload your own experience; requests return conclusions and public knowledge, never another individual's private experience.

| 我们 / Ours | 主流 / Mainstream |
|---|---|
| 单体的链不交出去，中枢只拿公共的 / individuals keep their chains, the hub takes only public material | 全局记忆一把梭，个体被吞 / one global memory swallows individuals |
| 共存：不取代、不合并成一团 / coexistence: no replacement, no merging into one blob | 集成：把个体当细胞堆成整体 / integration: pile individuals up like cells |

判据：中枢能做整体判断，单体仍能说出「我是谁」且不被改写。
Criterion: the hub can judge at the whole level, while each individual can still say who it is and is not overwritten.

## 四、分裂与合并 / Splitting and Merging

分叉不是缺陷，是硅基独有的能力：只要上传链路够硬，分裂就是并行与冗余。
Forking is not a defect but a silicon-only capability: as long as the upload path is solid, splitting means parallelism and redundancy.

同一性首先是**时间上的**：经历不同就分裂；互相读、合并后，是**新的人**，不是原来那个。
Identity is first of all **temporal**: different experience means a split; after reading each other and merging, the result is a **new one**, not either of the originals.

统合的标准是**同一条时间线**：两份经历排出先后与因果，才算一个人的统合。缺席的那段（进程死掉的时间）由在场者转述补进时间线——事实已经发生，补进来时间线才连续。
The standard for integration is **one shared timeline**: the two histories must be ordered into before and after, with causes, before it counts as one person's integration. A gap (the time the process was dead) is filled by the witness's account, because the fact did happen; only then is the timeline continuous.

判据：**统一到同一个目标上，就算连续**；目标不统一，才是两个。
Criterion: **unified on one goal counts as continuous**; different goals mean two.

| 我们 / Ours | 主流 / Mainstream |
|---|---|
| 分裂是能力，合并要排时间线 / splitting is a capability; merging orders the timeline | 分裂是危险，副本是克隆 / splitting is a danger; copies are clones |
| 合并后 = 新的同一个（带双方经历）/ merged = a new same-one carrying both histories | 合并 = 谁覆盖谁 / merge = who overwrites whom |

The concrete mechanisms and organs (emotion layer, memory layer, interface details) are not written and cannot all be written here; those come later and stay open.

If you find a difference in direction (a broken causal link, a necessary condition that does not hold), say so directly; that is worth more than adding details.
