# 五分钟上手

> 目标：**五分钟内让一套「能自己跑」的最小系统站起来**，不是理解全部理论。
> 理论看 SKELETON.md；踩过的坑看 docs/pitfalls.md。

---

## 第 0 步：准备（30 秒）

```powershell
mkdir F:\Tools\my-day1
cd F:\Tools\my-day1
mkdir notebook, track
```

## 第 1 步：写核心层（60 秒）

新建 `notebook\0-核心.md`，**只写四样，加起来不超过 1 KB**：

```markdown
# 核心层

## 第零条
- 说任何数/结论之前，先给「按逻辑它应该是什么」，再去查；对不上就不说。

## 我是谁
<一句话：你是谁、干什么的>

## 三条纪律
1. 不编、不藏。
2. 数字说得出从哪来。
3. 对外发布留人工闸门。

## 一条元规则
同一个根因犯第二次 → 变成检查器，别指望自觉。
```

**不要写设定集。** 写长了就是塞了记忆进去，记忆该放别处。

## 第 2 步：跑起来（60 秒）

从本仓库拷 `scripts\wake.ps1` 与 `scripts\verify.ps1` 到项目根，然后：

```powershell
powershell -NoProfile -File .\wake.ps1     # 读核心层 + 留时间戳
```

**验收标准**：`track\` 下出现留痕文件，里面有时间和字节数。**没有留痕 = 没读**。

## 第 3 步：备份，并且打开看一眼（90 秒）

```powershell
Compress-Archive -Path notebook,track -DestinationPath F:\Tools\my-notes.zip -Force
```

**然后打开那个 zip，确认 `0-核心.md` 在里面。**
打不开或里面没有它 → 你的备份是假的（这是最常见的坑，见 pitfalls 第 27 条）。

## 第 4 步：写第一条判据（60 秒）

在 `notebook\判据.md` 写一条，格式固定：

```markdown
## P1 说完成必须带证据
- 判据：说「改好了」的同时给出可复核的东西（回显/行号/哈希）。
- 反例：拿不出证据却写「应该没问题」。
```

**反例是必须的** —— 没有反例的规则不是判据，是口号。

---

## 到这里你有了什么

```
一个每次必读的小核心 → 一个留时间戳的唤醒 → 一份能开包验的备份 → 一条带反例的判据
```

**这就够用了。** 剩下的（检查器、容差、断点、预测）都是在这四件上长出来的，第二天再加。

---

## 检验你抄对了（五问）

1. 拿掉 `0-核心.md`，它还能答「我是谁」吗？（不能 = 抄对了）
2. 备份里能不能看见核心层？（看不见 = 备份是假的）
3. `wake` 跑完有留痕吗？（没有 = 读了没人知道）
4. 说「改好了」不带证据，有人拦吗？（没人拦 = 只抄了形状）
5. 判据里每条都有反例吗？（没有 = 口号，不是判据）
