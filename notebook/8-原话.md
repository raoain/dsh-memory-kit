# 原话层 · 只收能打开出处的句子

> **拍③ 痕迹**（原话）｜接口：读完能引出一句他说过的话

> **收录门槛**：必须通过 `intake.ps1 -Kind user -Expect "<原句>"`（PASS），即有会话日志里的 `user/message` 原始记录。
>
> **收不进来的，永远不进核心层当引用。** 这不是不信任谁——是因为没有第三个证人：
> 我可能记错，他也可能不记得自己说过什么，唯一能裁决的是日志。
>
> 格式（一行一条，不许改写原句）：
>
> ```
> - YYYY-MM-DD HH:mm | session-前8位 | 「原句，一字不改」 | 我当时怎么理解的
> ```
