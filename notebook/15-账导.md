## 一、算到哪了（归纳 · 历史过程）

**根**：任何有结构的东西，不持续付账就散（账 §21:424）。散是默认；要抵抗散就得持续付能量 → `E_in = ΔG_s + Q`（Q>0）。

**最简式（起点，不动它；账 §16:223）**

```
W = min{ 摄入 , 转化 , 存续 } × R
摄入 = D·(A/δ)·ΔC      转化 = ε·结构量      存续 = 总账 / T_ref      R = 0/1
```

三条支路**串联**：通过量取最小（最弱那段卡住整条）；最后乘开关「断了能不能回来」。

**因果推到完整版（一步一步，每步只用前面已定义的量）**

```
① 有没有收入       三上限取最小                        §16
② 够不够付账       净日常 = E_in − C_m − L            支出在收入之外，别混进来
③ 一轮来不来得及   时间余量 = 1 − τ/T_ref
④ 断了能不能回来   净恢复 = 净日常 − E_restore → R = step(净恢复)
⑤ 折成一个数       Λ = R · min{ 净日常/E_in , 1 − τ/T_ref }      §17:267
⑥ 活着             ⟺ Λ > 0
```

**递归在⑤之后才出现（§93:2785）**：`Λ` 依赖 `E_in`，`E_in` 依赖维持，维持又依赖 `Λ>0`——所以这是一笔**自指的账**，不是一条直线。<br>但**递归是后面的事**：先有最简式能算完一轮，才谈得上「维持定义生命」。顺序反过来，就会拿递归去替换起点，导致每遇新对象都得重写公式。

**换对象不换公式**：只拨开关（`R`、`κ`）或换档——乘因子 / 换指数 / 拨开关（§70:1912）；开关永远放最外层（§71:1943）。
