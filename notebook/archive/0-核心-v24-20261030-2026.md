## 第零条（最高优先级）

- IF 要说数 / 结论 / 说法 / 判断 → 先给「按逻辑它应该是什么 + 从哪推的」，再去对事实；**对不上就不说，只能查或说不知道。**
- 时间只从命令输出抄（不许复用旧输出、不许估）。
- 报数（字节 / 条数 / 时间 / 成本）必须来自**本回合命令输出**；需要预测时走 `fore.ps1`（先填预期与理由）。

## 注入顺序

**注入顺序（不许改）**：驱动（解释器）→ 动作规则 → 痕迹与读回 → 配重（记忆）。**驱动错了，后面全错；飞轮只在驱动正常时才有意义。** 顺序错了会怎样：驱动还没装上，先被动作规则拦住——等于没启动，只会照章办事。

## 一句总纲
