# 守链 · dsh-memory-kit

> **换一个窗口之后，它还是不是同一个人 —— 靠的是文件，不靠插件。**

## 宏大目标

一句话：**让一个东西连续地活着，并给出可验收的判据。**

- 这里给的是**方向**：完整 → 自我 → 可拆 → 供能 → 同一，五个必要条件，四断点验收；
- 具体机理与器官（情绪层、记忆层、接口细节）**没有写**——那是后面的事，也是开放的部分；
- 如果你发现方向上的不同（因果接不上、必要条件不成立），请直接指出——这比补细节更有价值。

## 一、最小能跳体（现在就能用）

三个文件 + 两条命令，不装插件：

```
0-核心.md    每次开工必读的一页（我是谁、使用者是谁、三条纪律；压到 2 KB 内）
1-工作.md    最近在做什么（读最近一屏）
2-档案.md    按需查的坑与修法
```

```powershell
powershell -NoProfile -File scripts/wake.ps1      # 醒来：读核心层 + 工作层
powershell -NoProfile -File scripts/selfcheck.ps1 # 自检：结构 + 值
```

判断「最小能跳体」够不够，只看三件：**能不能自己读核心层、能不能自己写工作层、断了能不能从文件捡回来**。

## 二、结构解释

### 记事本骨架：分层，不是堆叠

| 层 | 文件 | 什么时候读 |
|---|---|---|
| 核心层 | `0-核心.md` | 每次开工必读（一页，压到 2 KB 内） |
| 工作层 | `1-工作.md` | 每次读最近一屏 |
| 档案层 | `2-档案.md` | 按需查，不主动读 |

判据一句话：**不知道这一条会不会立刻做错事？** 会 → 核心层；不会 → 档案层。

### 环与断点

- 一条链有五个必要条件：**完整、自我、可拆、供能、同一**（互相是前提，不是并列）；
- 验收只看**四个断点**：换机 / 拔插件 / 重建 / 换模型；
- 每个断点都要能跑一遍：起来、读得懂、判断不变、能回档。

### 检查器（结构、值、探针）

| 检查 | 作用 | 入口 |
|---|---|---|
| `verify.ps1` | 结构（页存在、字节、节数、时间格式） | 一条命令 |
| `pin.ps1` | 值对账（哈希/计数漂移就报 DRIFT） | `-Diff` / `-Init` |
| `probe.ps1` | 检查器自己的探针（假样本必须被拒） | 全部通过才算活着 |

判据：**报对没用，得报错才知道。** 引脚要有负样本，检查器要有假样本。

## 边界（写在前面）

- 它不承诺人格效果，也不声称意识；它保证的是「文件在、能读、能核」。
- 它不依赖任何插件；插件是可拔接口。
- 它不替你做决定：发布、删除、密钥、花钱，都要人点头。
