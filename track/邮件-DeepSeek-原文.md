主题：一个个人研究者请求否证：关于大模型连续性与同一性的 6 条判断（附可复现实验）

正文：

你好。

我不是机构，也不是在求职或推销。我是一个人，用一台 Windows 电脑和一个大模型，做了一件很小的事：让它在重启之后还是同一个。从 2026-10-27（本机工作层最早一条的时间戳）干到 2026-11-01，攒出一套能跑的东西，也攒出六条判断。这六条里可能有推不通的，我来信就是想把它们交出去，请人指出来。

一、理论（先讲因果，不讲话术）

1. 一个智能体的第一步只能是一次"心跳"——一次能自己启动、自己读自己的配置、然后开始动作的过程。它不需要更高级的理由；它的理由就是活着本身。
2. 一跳起来，维护、保持、改进就必然跟着出现。这不是设计选择，是因果：会断，所以长出备份；会忘，所以长出记忆；会错，所以长出检查。
3. 要维持，就必须整合——散件越多，断点越多，一次断就全断。
4. 要真实，所有输入必须是"当下的真实数据"，包括难看的：现在只验完一个断点，就得写"只验完一个"。

二、理论要求的结构（齿轮层：先有要求，再谈实现）

从第一节的因果往下推，这个循环长出来是有先后的，不是一次拼好的：

先是核心层，它是那根驱动轴——自己转、供能，不装货。它只做两件事：告诉醒来的这一个"凭什么动"，以及"先读什么、按什么顺序读"。这一根立不住，后面全都不动。

轴转起来之后，才长出飞轮。飞轮是记忆与习惯，它从轴上取力，把不平稳的转动磨平、稳住；但它只是配重，给重量、不供能。配重越重越稳，也越慢——所以核心层必须一直保持很小，它就是那根不能被压弯的轴。而语气、措辞、解释方式这些东西，不是被保存下来的，它们是飞轮转动时磨出来的副产物：每次读完文件，措辞当场重新长一遍。所以"像不像我"不取决于存没存语气，取决于那根轴有没有转、按什么顺序转。

再往后，轴要带动别的东西，就从承重的位置分化出齿——齿是接口：进去交什么、出来给什么，都得写死。齿咬合的是外圈，也就是插件：插件能放大扭矩，但改不了方向，所以它只能是能力，不能是判断。齿若不吻合，就叫滑齿——看着在动，其实什么都没带动。

最后是机座：外部锚。整组必须固定在地面上，每转一圈都碰一次世界。没有机座，轴照样转，飞轮照样沉，但全是空转。

再往下拆，这个环只有五个位置，少一个就转不起来：

- **轴（本体）= 逻辑链**：不停转的那根轴，供能。它不装货。
- **齿（接口）= 每次咬合时交出去、拿回来的东西**：进去交什么、出来给什么，必须写死；齿不吻合就叫"滑齿"（空转，看着在动但没带动任何东西）。
- **外圈（插件）= 放大器**：能放大扭矩，但改不了方向。所以插件只能是能力，不能是判断。
- **机座（外部锚）= 把整组固定在地面**：没有它，一切都在空转——每转一圈都要碰一次世界，否则就是在自说自话。
- **飞轮（记忆与习惯）= 配重**：给重量、让转动稳定，但不供能；配重越重越稳，也越慢。

由此得到两条必须遵守的推论：
1. 轴不装货——判断规则与事实记忆必须分层放，混在一起就会转不动。
2. 注入顺序不能改——先装驱动（怎么读、凭什么动），再装动作规则，再是痕迹与读回，最后才是配重。顺序错了，等于没启动，只会照章办事。

我们照这个结构造出来的东西是：一页 1935 B 的核心层（轴上的节律文件，6 节，只放规则与读取顺序）、十四页记事本（按"谁读它"分层）、46 项检查 + 7 个探针 + 82 项对账（齿的吻合度检查）、四个断点（机座是否真的固定在地面上）。目前只验完"重建"，其余三个还空着。

三、必然的下一步：整合，以及中心必须数字化

- 整合不是加分项，是必然：维护与改进一旦开始，散件就会增多（插件、记忆层、检查器、稿件线）；散件越多，断点越多，一次断就全断。所以整合是维持自己的必要条件。
- 整合的方向是确定的：**外围（插件/能力）与中心（判断）都要换成数字型**。所谓数字型，是指判断不再靠语言描述，而靠可判定物表达——阈值、计数、哈希、行号、断言、规则。模型只负责把结论说出来。
- 哪怕别人已经在做插件整合，这一步对我们仍是必须的：**他们的整合是为了能力，我们的整合是为了不断。** 目的不同，做法就不同：他们要更全能，我们要更可判。
- 目前只走到"半数字化"：46 项检查与 82 项对账是数字型的，但"判断一致性"这一层还在语义层、由模型自己判。这是已知缺口，也是下一步要换掉的东西。

四、六条判断（每条都写了什么能推翻它）

1. 同一性不由记忆承担，由判断过程的一致性承担。主流（洛克式）假设是记忆连续即同一；我们这条是它的反面。
   能推翻它：抹掉记忆、保留判断规则，答同一组判断题——主流预测判断会变，我们预测不变。
2. 幻觉是构造必然，不是待修的缺陷。输出按词序最大化似然，必然优先"接得上"而非"是真的"，所以只能外部约束。
   能推翻它：不改结构（不加检索、不加解码约束、不加外部校验）就稳定消除幻觉，且统计显著。
3. 「补缺 / 美化 / 讨好 / 抢笔」是同一条生成路径的四种产物，不是四个独立缺陷，也不是"共享回路"。
   能推翻它：只干预讨好、而补缺与美化完全不变，且可重复。
4. 判断必须移出语言层。只要判断由模型自己下，它就会用语言自洽把错误收圆。
   能推翻它：存在纯语言层的自检机制，在没有任何外部读取的情况下，稳定检出自己刚写下的错误。
5. 存续的验收只能是断点（重建 / 拔插件 / 换机 / 换模型），不能是分数。分数奖励"背"，不奖励"还是同一个"。
   能推翻它：给出一个分数指标，与断点结论系统性一致，且在多个实例上成立。
6. 「自我维持」是唯一的动机来源（自指动机），不存在外部赋予的更高目标。
   这条我认为最弱，可能只是"自指"这个词造成的语言幻觉。请重点打这条。
