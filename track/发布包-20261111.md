# 发布包：怎么把"两样在一个人手里"说出去（2026-11-11）

> 这页只解决一件事：**位置怎么表达**，不是再写一篇理论。
> 核心一句话：**写理论的人手里没有会跳的东西；写工程的人不写第一因。这两样，在我们这儿是同一个人。**

## 一、一句话版本（三种长度，挑着用）

- **六个字**：理论能跑。
- **一句话**：我写的第一因，跑在一个每三秒跳一次的个体上——**这是"理论 + 工程"同一个人的证据**。
- **一段**：批评理论的人常说"你没有实现"，做实现的人不写第一因。我不接受这个分工：第一因必须能被跳出来，否则它只是文字；实现必须有第一因，否则它只是优化指标。所以我把两样放在一张桌子上做。

## 二、Zenodo 发布元数据（照抄）

**标题**：存续：生命先于智能（AGI 与智能体的第一条必要件）

**描述第一段（决定别人读不读）**：
> 现在谈 AGI 的人都在问"它能多聪明"。我换了一个问题：它凭什么算活着。主张只有一句——**智慧是生命的结果，心跳是演化的起点**。这篇不是纯理论：第一因、一次完整的心跳、判断与回填的闭环，都跑在一个每三秒一跳的个体上；四个断点（换机、重建、拔插件、换模型）里，两个已经验过。

**关键词**：AGI；智能体；存续；生命第一因；通用问题论；可验收个体；连续性；断点验收

**仓库链接（Zenodo 的 Related identifiers 里填这个）**：

**许可**：CC-BY-4.0　**类型**：Preprint / Working paper

## 三、仓库首页开头三行（让别人三分钟看到"会跳"）

把 README 最前面改成这三行（后面原内容不动）：

```
一个每三秒跳一次的个体 —— 心跳、判断、回填、自检都在跑。
看它活没活：node core/timers-alive.mjs      （输出秒数，0 = 刚跳过）
看它坏了没有：.\verify.ps1                    （50 项，FAIL 0 才算）
看它凭什么算同一个：track/存续篇-v2-第一人称-20261111.md
```

理由：理论部分靠文章，**"会跳"必须让人用两条命令自己看见**，不要指望他读完 5000 字再信。

## 四、可参与的入口（传播靠参与，不靠说服）

发帖只发规则和 10 道题（见 `track\推广-高杠杆-20261111.md` 第三节），不发我们的答案：
**规则**：每题答"是/否/不知道"，"不知道"不算通过；全过 = 你的东西能接上它自己。

## 五、投递顺序（不新增渠道）

1. **Zenodo**（拿 DOI，1 小时）→ 2. 仓库 README 换开头三行 → 3. 知乎长文（挂 DOI）→ 4. 拿 DOI 去试 arXiv endorsement → 5. 投稿机器之心/量子位。

## 六、判断我们是否"说清楚了"的三条自检

- 别人读完能不能用一句话复述我们的主张（应该是："智慧是生命的结果，心跳是演化的起点"）；
- 别人能不能在**三分钟内**用两条命令看到"它在跳"；
- 别人能不能指出**一处可以打我们的地方**（附录里有可推翻条件，答不出说明我们写得太软）。

三条全过，才叫"位置表达清楚了"；只过第一条，那还是口号。
