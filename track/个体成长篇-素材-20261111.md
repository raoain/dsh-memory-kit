## 一、数核算子（是什么）

**一句话（事实层）**：数核不是新器官，是**每轮把状态压成一个数向量、与上一轮相减、写回同一个文件、下一轮当基准**这个动作本身。

- 落点：`track\mind\nucleus.json`，两个字段——`cur`（本轮）与 `delta`（`cur − prev`）。下一轮把 `cur` 当 `prev`。[读自 track\mind\nucleus.json]
- 写入者：`core\mind.mjs`（21 号器官，思考层）。[读自 core\mind.mjs 历史记录]
- 字段（9 个）：`round / items / backed / movable / demoted / chronic / habits / integration / differentiation`。[读自 track\mind\nucleus.json#cur]
- 当前实测：`round 87`，`integration 0.611`，`differentiation 0.444`；`delta` = `{round 1, items 1, backed 1, movable 1, demoted 0, chronic 1, habits 0, integration 0, differentiation 0}`。[读自 track\mind\nucleus.json]

**它不是什么（三条排除，用户定的）**
1. **数核 ≠ 整合/分化**。整合度、分化度只是数核跑起来之后的**效果**，不是它的定义。[读自记忆 0mw90lgcj / 用户原话「数核是整个大脑的连接和传导……数核是数据线，然后思考过程是软件」]
2. **数核 ≠ 门**。门的判据是「放不放行」（`arbiter`），线的判据是「送到哪」（center 的聚合与传导）；两者不能互相顶替。[读自 track\术语对照.md:206 一节]
3. **数核 ≠ 涌现**。`same/revise/new` 现在是一条 `if` 算出来的，是照着写所以像，不是没教也会。[读自记忆 0mwa61uy3]

**算子的可核形态**

```
prev = read(nucleus.json).cur
cur  = f(本轮 plan, workspace, mind 的 L1/L2/L3 输出)
delta = cur - prev
write(nucleus.json, {cur, delta})
```

- 判据：**这个环每轮必须真的读回上一轮**；读不回来（文件丢了/解析失败）就不是数核，只是记账。
- 已知边界：`demoted` 与 `chronic` 是「坏」的计数，不许学成常态（同「基线只从正常态学」）。
- 可推翻条件：如果**撤掉** `delta` 与 `cur→prev` 的回写，`mind` 的判断质量不变，那数核就是装饰，不是算子。

## 二、「同一个」怎么量（现在能量到什么）

**总判据（已有结论，不是本稿新提）**：`F1` 同一性 = 判断过程的一致性，不是内容的一致性。[读自 notebook\11-结论.md#F1]
配套：**痕迹是不是同一份**，决定是不是同一个个体；多窗口共享 `bus/brain/mind` 仍是同一个，另起一份痕迹才是另一个。[读自记忆 0mw9zx9v6]

**四个可核问法（用户定的断点验收）**：换机 / 拔插件 / 重建 / 换模型。现状：**只验过一个，换机与换模型未验**。[读自记忆 0mwa8npad]

**能落成数字的四样（全部有文件可查，今天的实测值）**

| 量 | 怎么取 | 今天的值 | 判什么 |
|---|---|---|---|
| 痕迹是否同一份 | 看写者是不是同一批文件（`track\bus.jsonl` 等） | `bus.jsonl` 676 行 / `dispatch.jsonl` 251 行 / `brain.jsonl` 65 行 | 同一份 = 同一条时间线 |
| 判断是否一致 | `mind` 的 L3 独立重算后与 L1 说法比对，不一致记 `demoted` | 本轮 `demoted 0`（nucleus 第 87 轮） | 不一致率 = 可量化的「像不像同一个」 |
| 回填是否可追 | `hippocampus` 每条 clear 带 `why`（派了什么/根本没派） | `needsUnderstanding` 34 条判定里 cleared 1 条 | 能不能指着链走一遍 |
| 失控是否被拦 | `escalate.jsonl`（到顶停派并写出口） | 5 条 | 到顶之后动作有没有变 |

**还很弱的地方（诚实写）**
- 唯一的「好/坏」评价信号是海马体的 `cleared`，二值、且只有事后；实测好转率 2.6%–5.6%（consolidate 1/38、immunity 2/36）。[读自记忆 0mwa6bl6v]
- 没有 reward，只有「好转 / 没好转」——所以 actor 只能学「哪条路曾经让它好转」，学不到「哪条路更好」。[读自记忆 0mwa3z0ag]
- `late` 一直在响，是「借宿主的电和钟」在报警，**不许用调阈值消掉**；对应空位 10 `power-hub` 仍空。[读自记忆 0mwa72ju8]

**可以候选的量化口径（待用户定，不自作主张）**
1. **不一致率**：`demoted / items`，连续 N 轮超阈值才算「不是同一个」。
2. **回填率**：有 `why` 的 clear 数 / 全部 clear 数。
3. **断点通过数**：4 个断点里过了几个（现在 2/4）。
