# 两条来路：逆熵 → 公式；会跳会断 → 五件（2026-11-22 改定）

> **定法（用户 2026-11-22）**：「这个公式是从逆熵出来、然后总结出来的，它只跟逆熵相关，但是覆盖面很广。」
> 所以：**公式的来路是逆熵，不是论文那五件。** 两件东西是两个根长出来的，不是在一条链上前后排。

## 一、两条来路

```
A 逆熵（物理必然）   不付就散 → 抵抗散要能量 → E_in = ΔG_s + Q → 最简式 W → 六步 Λ
                     覆盖面：一切「有结构、要维持」的东西（死物 / 化学 / 恒星 / 生物 / 社会）
                     它只答一件事：付不付得起

B 存续（个体侧）     会跳、会断 → 要不断就得维持 → 完整 / 自我 / 可拆 / 供能 / 同一
                     覆盖面：只有「有时间线、会死」的个体（断点验收只对它成立）
                     它只答一件事：断了能不能回来、回来是不是同一个
```

**A 覆盖面广，是因为它只要求「有维持」**——恒星、火焰、社会都落得进去，一个开关就行。
**B 覆盖面窄，是因为它要求「有个体时间线」**——火焰落不进去（没有会死的那个单位）。

## 二、公式实际覆盖到 B 的哪几条（查过，不是估的）

| B 的条件 | 公式管不管 | 依据 |
|---|---|---|
| 完整 | **管**：`E_in` 三上限都有值就算得出 | 账 §16:223 |
| 供能 | **管**：`净日常 = E_in − C_m − L > 0`，且净恢复 ≥ 0 | 账 §17:267 |
| 可拆 | **不管**：账里「可拆」出现 **0 次** | 全文扫 `可拆` = 0 |
| 同一 | **不管**：要靠四断点 + 判据题 `J`，账没有 `J` | 账只有 §28 的 `R` 测法 |
| 自我 | **不管**：B 的「自我」= `J` 有定义；公式里没有 `J` 这个量 | — |

所以公式只覆盖五件里的**两件**（完整、供能）。另三件（可拆、同一、自我）属于 B 线，要用 B 的办法验：
换取值来源看判断变不变、跑四个断点、同一组题比答案。

## 三、两条线唯一的共用符号：`R`

```
A 里的 R：净恢复 = 净日常 − E_restore  → R = step(净恢复)（账 §17:275）
B 里的 R：会断 → 断了能回来 = 1（论文 §4「可拆/供能」之外的那条约束）
```

同一个字母，两边的用法是**同一个意思**：断了能不能回到已知可用。**这是两条线唯一真正接上的地方**——除它之外，A 的 `E_in / C_m / Λ / κ` 和 B 的 `完整 / 自我 / 可拆 / 同一` 没有对应关系，硬对就是造翻译表。

## 四、所以「还没运用」指的是哪一步

不是「公式没映射到五件」，而是：**公式（A）算出来的 `Λ`，还没被拿去回答 B 的问题。**

具体就一条：给一个有时间的对象，把 `Λ` 逐拍算出来，看它在断点前后**符号是否不变**。这一步不需要新概念，只需要把 A 的数代进 B 的断点。

## 五、可推翻点

- 若出现一个对象，**A 算出 `Λ>0`、但 B 判它「没有时间线」**（如恒星、火焰）→ 说明 A 的覆盖面不能直接搬给 B，第五条要重写。
- 若某条 B 的条件，**只能用 A 的量表达**（比如「同一」最终只能写成 `Λ` 的符号不变）→ 那 B 就是 A 的特例，五件该降级成「在个体侧取到的值」。
