# 论文投递通道（2026-11-11，随时可发）

> 目标：像投简历一样广投。只列能"上传即得公开链接/DOI"的地方，以及门槛。

## 一、零门槛（上传即公开，最快）
| 通道 | 拿到什么 | 门槛 |
|---|---|---|
| **Zenodo** | DOI（可引用、可版本化） | 无（需账号；已用过，前四篇都在这） |
| **OSF Preprints** | 预印本 + DOI | 无审核，免费（[help.osf.io](https://help.osf.io/article/376-preprints-home-page)） |
| **GitHub 仓库** | 可读可抄的全文（Markdown/PDF） | 无 |
| **Hugging Face Papers** | 论文页 + 讨论 | 无（需账号） |

## 二、有门槛（但曝光更大）
| 通道 | 门槛 | 备注 |
|---|---|---|
| **arXiv**（cs.AI / q-bio） | 需要 **endorsement**（老作者背书）；2026-01 收紧了 AI 生成内容政策 | 值得试：我们先在 Zenodo 有 DOI，可拿 DOI 去申请 endorsement（[arXiv 2026-01 政策](https://blog.arxiv.org/2026/01/21/attention-authors-updated-endorsement-policy/)） |
| **SSRN** | 提交后人工审核（Elsevier 旗下） | 社科/哲学类可用 |
| **OpenReview** | 需要投到某个具体 venue/workshop | 有 AI+哲学 workshop 时可投 |
| **Semantic Scholar / ResearchGate / Academia.edu** | 注册即可，多为"认领已有 DOI" | 用来做二次曝光，不是首发 |

## 三、中文侧（读者多、但不算学术）
| 通道 | 形态 | 门槛 |
|---|---|---|
| **知乎** | 回答/文章，挂 DOI | 无 |
| **微信公众号** | 长文 | 无（需自己开号） |
| **机器之心 / 量子位** | 投稿观点文 | 编辑审，带 DOI 更容易过 |
| **V2EX / 即刻** | 短帖引流 | 无 |

## 四、建议顺序（广投用）
1. **Zenodo 先发**（拿 DOI，1 小时）→ 2. **OSF 同步一份**（同一稿，不同索引）→ 3. **GitHub 仓库放全文 + LICENSE** → 4. **知乎/公众号各发一篇**（挂 DOI）→ 5. **拿 DOI 申请 arXiv endorsement** → 6. **投稿机器之心/量子位**。

判据：**每投一处，都要能回到 DOI**（否则读者接不上，也引用不了）。
