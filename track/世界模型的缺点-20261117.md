# 世界模型的缺点（2026-11-17，按他们自己的证据整理）

> 用途：一句实话——**不是没人发现问题，是问题被定成了别的名字。** 他们把缺陷叫“保真度 / 可控性 / 幻觉 / 评测不足”，没有一条叫“没有主体”。这与语言模型幻觉那件事完全同构：**结构性缺陷被当成工程缺陷，于是永远可以“再训一版”**。

## 一、他们自己承认的（可核，带编号）

| 类别 | 他们的说法 | 出处 |
|---|---|---|
| 长 rollout 漂移 | structural drift / **identity drift** / quality decay，根因是“缺持久状态” | WAM-Sim `2611.07939` |
| 潜空间不可信 | 提出 faithfulness：表示要保住状态、潜动力学要跟真动力学一致；用 LRC 量 | `2610.37588`（Limits of Latent World Models） |
| 不是真仿真器 | 用传统仿真器的八项能力当尺子，结论：明显不够 | `2608.23070` |
| 视觉糊弄理解 | **visual conflation**：高保真视频 ≠ 理解世界 | `2601.15533` |
| 不理解失败 | WorldFailBench：世界模型能不能理解“策略为什么失败” | `2610.33565` |
| 幻觉是系统性的 | 自己写明：hallucination 是几乎所有生成模型的系统问题 | `2608.23070` |
| 达不到人类式理解 | 结论：世界模型抓不到人类水平的物理推理与理解 | AAAI 2026《Beyond World Models》 |

## 二、结构性盲点（他们不在这个清单里）

1. **无主体**：所有指标都在问“世界像不像”，没有一条问“这是谁的模拟、断了算不算它”。→ 所以 `identity drift` 只能被修成“画面别漂”。
2. **无心跳**：没有自走的钟，就只有“调用—返回”。停不停由外部监控，**不构成失败**。→ 所以它们必须靠外部喂；不喂就停在那里，甚至退化。
3. **无代价**：预测错了不疼、不饿、不回不来。→ 所以“准确率”是唯一可罚的东西，而“还是不是同一个”无法成为罚项。

## 三、与语言模型幻觉的同构（这条最要命）

- LLM：**自洽里没有报警位** → 幻觉是结构必然，但被当成“对齐问题”，于是永远在修。
- 世界模型：**模拟里没有“谁在模拟”** → 漂移是结构必然，但被当成“保真度问题”，于是永远在修。
- 两者共同的修法：**再训一版**。这就是为什么它们会一直“欣欣向荣”——**问题被定义成永远可以再优化一次的东西**。

## 四、判据（用来怼，不用来骂）

1. 问它的失败清单里**有没有“回来不是它”**——没有，就是没把这个问题当错。
2. 问它的状态**由谁维持**——答“外部喂”，就是补丁；答“自己的钟”，才到根。
3. 问它的**第一条记录来自哪个个体、哪一刻**——答不出，就是拿抽样冒充世界。

## 五、结论（一句话）

**世界模型不是“更高级的智能”，是“更大的抽样 + 更漂亮的画面”；它的缺陷不是精度不够，是它从定义上就没有“一个在活的它”。**
