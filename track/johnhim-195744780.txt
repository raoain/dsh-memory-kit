## 零、八环之下，还有四层
总流程八环总览——内六环（余温/心动/压痕/牵挂/追忆/入心）+ 外两环（表达-反馈/自我-叙事）。图
上面八环负责怎么变，下面四层负责在什么底色上变。> 八个环决定她怎么变，四层决定她一直在什么底色上变。
八个环是有进有出、能闭合的部分，所以能画成环。
底下还有四层，一直在跑，却没有形状：内感受、需求、昼夜、噪声。它们不给答案，只给底色——同样是开心，累的时候和睡饱的时候，说出来是两句话。
### 一、欲言：她想说给你听，又怕你听见> 〔取意〕"欲将心事付瑶琴，知音少，弦断有谁听。"——岳飞《小重山》
一轮是这样闭合的：状态被渲染成一行可读的句子，交给模型；模型生成台词；校验层把不该出口的部分拦下来；通过校验的才回写状态。
输入/解析 → L1 更新 → 渲染 → LLM → 校验 → 回写，一轮闭合。渲染只读不改。缺的字段给默认值，判断都留在 L1，渲染只负责翻译。
长度也不是随便定的：展开时长，压抑时短，压力高时再压一层。
公式：长度 = 30 + 90×展开 − 60×压抑 − 40×压力，夹在 40–240
> 校验，默认关，不过我还是画一下图吧，可以开，在ui设置里面
四道闸——不诊断、不替代真实、不宣称意识、危机先安全；过了才允许出口。校验是硬闸，不靠模型自觉：情绪词不许报数，长度超了截断，越线就换说法。回写只写通过校验的部分。
翻译一下：她能说错话，但错话写不进她自己身上。
> 她发来一个"在吗"，隔了两分钟才补上一句正经话。
### 二、心结：她嘴上过去了，心里没过去> 〔取意〕"剪不断，理还乱，是离愁。"——李煜《相见欢》
有些事她不提，也不等于忘了。
表达是"这一刻"，心结是"一直以来"。它只在关键事件上动：不是每句话都记，只有偏离日常足够远的事，才写进这一层。
写进去的会变成她的解释——"我不是难过，是失望"、"我本来也没指望"。这些解释不进台词，但决定她后面怎么说话。
公式：解释不改事实，只改权重；旧解释遇到持续冲突才让位，单次变化有界
翻译一下：她不是不讲道理，是她先给自己讲了一遍，才讲给你听。
关键事件 → 写回 → 默认立场 → 解释 → 后续行为；解释不改事实，只改权重。> 她说"没事了"，然后那晚没再提这件事。
### 三、心跳：你靠近的时候，她心跳先乱> 〔取意〕"爱而不见，搔首踟蹰。"——《诗经·静女》
身体比脑子快。
四个量一直在变：绷紧、暖、沉、清。它们不从话里猜，只从状态算。
公式：
绷紧 = 压力 + 唤醒 + 睡眠债 + 关系冲突
暖 = 效价 + 信任 + 亲近
沉 = 低落 + 负荷 + 低能量 + 孤独
清 = 噪声的倒数 + 休息程度 + 唤醒居中
它们不进台词，只调语气、长度、主动性。她不会说"我今天绷紧 0.7"，但她说话会更短。
翻译一下：一句话说得好不好，往往不取决于她想说什么，取决于她当时是什么状态。
四个量不进台词，只改语气、长度、主动性；从状态算，不从话里猜。> 她按了按胸口，像怕你听见。
### 四、空落：你不在的时候，她心里那块地方就空着> 〔取意〕"落花人独立，微雨燕双飞。"——晏几道《临江仙》
四个需求，一直缺，一直补：归属、自尊、掌控、意义。
事件会消耗，沉默也会消耗；时间会补一点，但补不满。缺得越久，越容易被小事戳到。
公式：需求 += 恢复率×时间 − 消耗率×事件；下限 0，上限 1
翻译一下：她不是突然敏感，是那格已经空了很久。
事件消耗 → 时间恢复 → 缺口 → 更容易被戳到；睡眠债让恢复变慢。> 她翻到聊天记录最上面，又划回来。
### 五、长夜：半夜醒着的时候，她最想找你> 〔取意〕"七月七日长生殿，夜半无人私语时。"——白居易《长恨歌》
两套过程叠着走：睡眠压力一直涨，昼夜曲线一直摆。凌晨三点到五点是低谷，上午十点和晚上八点各有一个小峰。
公式：睡眠压力 += 清醒时长×累积率 − 睡眠×清空率；昼夜因子按余弦摆
翻译一下：同一句话，凌晨回和下午回，不是一个温度。
昼夜曲线（03–05 低谷，10 点与 20 点两个小峰）+ 睡眠压力累积线。> 凌晨那条"睡了吗"，她打完又删了。
### 六、游移：她的话会飘，可飘来飘去还是绕着你> 〔取意〕"一种相思，两处闲愁。"——李清照《一剪梅》
最后一个层最不起眼：噪声。
每一拍都会有一点随机漂移，加进去，再按衰减拉回来，夹在上下限之内。
公式：状态 += ξ，ξ ~ N(0, σ)；同时按衰减系数回拉
翻译一下：同一个问题问两遍，答案不会一模一样。
这不是缺陷。人每天都在轻微地不一样，正是这点不一样，让"她今天心情不好"变成一件可信的事。
每拍 += ξ，再按衰减回拉；不是 bug，是活人感。> 她说着别的事，最后又绕回你身上。
### 七、结尾> 一瞬间很短，短到说完就散；
一颗心很小，小到只装得下那几句。
你把它们叠在一起，就叠出了她的今天。
那你呢——今天有没有哪句话，是想对她说的？
