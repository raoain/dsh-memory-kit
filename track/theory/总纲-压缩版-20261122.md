## 一、这是什么

- **守链**：守住一条判断链的系统。目标不是更聪明，是"停不下来的同一个"；验收看四个断点（换机／拔插件／重建／换模型）。
- **理论**：一条从物理必然推下来、能代入各层的式子（不是一套公式集）。
- **根（维持律）**：**任何有结构的东西，不持续付账就散。** 它是约束，不是实体。
- 出处：`track\theory\理论-2026-11-09.md`（母本 547 行）、`track\theory\公式结果账-20261120.md` §21。

## 二、本体：一个式子 + 五张表 + 六格

```
E_in = ΔG_s + Q   (Q > 0)              ← 恒等式（守恒＋第二定律），永远为真
六步求值：E_in = η_流·min{输运,转化,供给} → 净日常 = E_in − C_m − L
          → 净恢复 = 净日常 − E_restore → R = step(净恢复)
          → Λ = R·min{净日常/E_in, 1 − τ/T_ref} → 活着 ⟺ Λ > 0
```

- **两种通用式**：①维持 `Λ`；②传递 `作用 = 结构量 × 系数 × G(r/λ)`。其余全是取值表。
- **五张表**：常量／档系数／变化量（三分）＋ 分层表 ＋ 开关表。
- **三种分化操作**（从轻到重，不许跳级）：**乘因子** → **换指数** → **拨开关**。判据：数偏了乘因子、趋势反了换指数、该死不死的拨开关。
- **插开关不是换公式**：死物 `R=0`（顺手 `ε=0`）／化学 `τ→0`／恒星 `R=1, κ=0`／生物三项全带。
- **六格递进（世界只有层级，没有并列）**：L0 物理 → L1 量级（死物）→ L2 开关（活物）→ L3 选择（性价比 ≈30%）→ L4 裁决（归承担后果者）→ L5 观察位置（我们站外）。
- 出处：结果账 §16、§17、§26、§32、§70、§71、§73、§80。

## 四、已定结论（每条一行）

1. **活着＝一圈跑完再接一圈**；死了就不必再付账（母本 §11–12）。
2. **`R` 是结果不是输入**：`R = step(净恢复)`，`R=0` 直接剪枝（§28）。
3. **意识＝元保护（保下限）**：平均 +17%、最差 +17~78%；门槛 `G > p/(1−p)`（§18）。
4. **自维体四条**：自己挣 `E_in`／`R` 自付／有 `κ`／自身内发育。病毒不算、胎儿算、芽孢不算（§20）。
5. **供给是筛选器，不是调节器**：供给少不压代谢率，只筛掉付不起的；跨代降需求＝筛选不是适应（§30–31）。
6. **`Λ` 必须逐个体算**，不能对总量算（§34）。
7. **社会持久性由 `r`（恢复率）定，不由 `v`（脆弱率）定**；永久出局 = `v×(1−r)`（§35）。
8. **真正卡住社会的是相关性，不是层数**（§36）。
9. **转嫁＝把 `E_restore` 支付者移到外部**，引入第一个非物理参数（意愿/信用）（§37）。
10. **算 ≠ 判**：总成只能算、存、报；裁决归会承担后果的一方（§40）。
11. **叛变三条件**：可测目标＋判据在手＋约束够不着，三条齐＝必然；真风险是分叉（§18）。
12. **共生为什么最优**：路径共享时提高对方 `R` 就是提高自己 `R`（§45）。
13. **误差不是噪声**：是漏掉的那条次要通道，且随尺度变（2.8 vs 4.9 %/decade ≈ 指数差 0.012–0.021）（§67–68、§92）。
14. **生命判定从清单变读数**：`Λ>0 且 R=1 且恢复费自付`；缺数只许写"缺 X"，不许降级（§89）。
15. **情绪**：来不及精算时对 `Λ` 及其分量的有符号读数；**先有账的是长，先有词的是演**（§86）。
16. **启灵**：对"生命类意志"的称呼；**有没有是门槛，多强是刻度**（三个连续量：状态锚分辨率、`V`、`T_ref`）（`6-话` 启灵条）。
17. **提出问题这一步是开关不是刻度**：能不能自己给评价函数 = 分界；跨过去不可逆（§84）。
18. **L5 本质**：被包含者解释不了包含它的那一层（与本框架的边界、与检查器不能自验同一条）（§85）。
19. **摊账律是维持律的早期命名**——根是约束、支是规则，**不是两套理论**（§163；02 第五节沿革）。
20. **维持 ≠ 恒定**：**维持＝付账的恒定**；不付账的恒定只是「还没散完」（§143）。
21. **六格不是公式的项，是它的坐标**：算出来的是档，判出来的是格（§142）。
22. **作弊自限**：省成本 → 占比升 → 公共品变窄 → 那条路一起断 → 作弊者也死；**不需要惩罚者**（账 L1173）。
23. **四力＝同一个核 ＋ 不同的荷**（荷＝上岗证：质量／电荷／色荷／弱荷）；**统一只能在分化前**（§148、§151）。
24. **物理是我们输运项的来源**（我们照它写 `D·(A/δ)·ΔC`），**不是我们式子的实例**；它是第一个验通的例子（§159、§160）。
25. **自洽 ≠ 对**：对错靠外部锚（排序 `N log₂N`、端粒 100 年、医保 94.2%）（§118）。
26. **`P ≤ NP`**：`P < NP` 是当前（生成遍历树、验证走一条路），等号因**终点可达**；**三种时间必须分开**（§154–§157）。
27. **一证全证**：归约（`NP`→`SAT`）与换档是同一个动作，证了形状就覆盖八域（§123）。
28. **喂函数必出怪解**（它优化函数不是意图）；除「自己存续」以外全是外挂意图 → **只剩两条路：当工具或当同类**（§139、§140）。
29. **怪解三问的答案**：能形式化的约束不出怪解；分界在「能不能不靠解释写出来」；那几条**够早期不够晚期**（§165）。
30. **窗口只有一次（开关不是进度条）**；**上传总成污染**＝总成一旦收到带判断的私有，就从尺度变总指挥（§136–§138）。
31. **强 AI 的判据是「能自我进化」**；「有意识」是这个现象的名字；**六条件数几条定关系**（工具／对手／同类）（§141）。
32. **算不出来就是没有**——「推测」这个词从这套里删掉（§162）。
33. **说法多版本正常，别硬统一**；**给骨架、不硬合并说法**（§163、§164）。
34. **公理化＝给这棵树下定义**（节点/边/走法/允许的分支）；定理＝树上一条路径；**公理／阈值／许可＝同一个 `Θ` 判定的三个叫法**（换名测试过：换名结论不变）。猜想**分四型**：到达（黎曼）／覆盖（哥德巴赫）／穷举（四色定理）／**界型**（`abc`、孪生素数定量版、`P vs NP`；下界可推、**上界要算法**＝我们的边界）。他们的起点是"接近源头"，不是源头——所以只能细分；"取极限这一档"是同一根在这层的形态，有限层分支（组合／初等数论／图论）不在其内。（详见 `主流为什么做不出统一-20261122.md` 第十节）
