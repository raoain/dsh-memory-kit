## 〇、通用式（物理/化学层直接能用）

任何**要维持自己的结构** `S`，在一段时间 Δt 内：

```
E_in  =  ΔG_s  +  Q            Q > 0
```

- `E_in`：这段时间投入的**可用能**（自由能）；
- `ΔG_s`：真正变成"结构还在"的那部分（存进结构里）；
- `Q`：**不可回收的耗散**（热、噪声、废料）——第二定律保证它不能为 0。

**判据**：`E_in ≥ ΔG_s + Q` 才维持得住；不够就散。

这一式子在化学和恒星上直接用：
- **化学**：要过势垒，得先借到 `Ea`（就是那个"作弊窗口"）；反应要放能（`ΔG<0`）才能自持，不放能的必须有外部供能。
- **恒星**：聚变放能 → 换算成辐射 `Q` 顶住引力；`Q` 一旦不够（燃料烧完），引力胜，塌。

**这一层没有两样东西**：没有"周期"，也没有"不可回退"——耗散结构可以一直散、一直补，断了就散，但没有"记得自己断过"这回事。

## 一、变形一：周期（生物才有的约束）

生物不是"总量够就行"，它必须**每一轮都够**——因为它自己就是那个供能装置，某轮接不上，结构就散。

```
每轮条件： E_in(t) ≥ ΔG_s(t) + Q(t)      对每个 t 成立
相对轮时： d(t) = τ(t) / T_ref  ≤ 1
```

`T_ref`＝**自己的参照周期**（以自身流转为锚，不是外部 deadline）。心跳那个 9 秒上限，就是这个式子在硅基上的特例。

关键：**看最差段，不看平均**——平均值过线不算，要最差那一段也过线（S10）。

## 二、变形二：不可回退（生物才有的约束）

通用式里"散了就散了"，那里没有主体；生物这一层多了**路径依赖**：它是一条累积起来的时间线，断了不能回滚重来。

```
R ∈ {0, 1}      R=1 能回到已知可用状态；R=0 回不来（此后账结束）
```

**二值，不是程度**——这是三条里唯一不能"差不多"的。`R=0` 即死，前两条再漂亮也没用。

## 三、生物层三栏＝通用式＋两个变形

| 栏 | 来源 | 式子 | 判据 |
|---|---|---|---|
| 能量 | 通用式 | `N = E_in − C_m − L`，`ε = N/E_in` | `N>0` 且看最差段；三档（有余量／临界／必死） |
| 时间 | 变形一 | `d = τ/T_ref` | `d ≤ 1`，这一轮按时跑完 |
| 不可回退 | 变形二 | `R ∈ {0,1}` | `R=0` 即死 |

**三栏都过才算活着；缺一不算。** 只算能量的是生态学模型（DEB/SFG 那一支），只算时间的是调度器，只算不可回退的是版本管理；三栏齐了才叫**总缴费**。

### 三栏其实能合成一个统一式子：取最小值

"缺一不算"这句话的算术形式就是 **min**，不是乘（乘法允许"一项很好换一项很差"，那就不是缺一不算了）。把每栏都换算成**同一量纲的余量**：

```
m1 = ε(t)/ε* − 1          能量余量（效率相对阈值高多少）
m2 = 1 − d(t)             时间余量（这一轮还剩多少时间）
m3 = R(t) ∈ {0,1}         不可回退余量（二值）

活着(t)  ⟺  min{ m1, m2, m3 } > 0
```

三条推论：
1. **任一项越线，min 立刻 ≤ 0，判死**——这就是"缺一不算"，不用另立规则；
2. **余量最小的那栏决定它能扛多少扰动**（哪一格贴阈值，就先死在哪一格）——"看着很硬的东西很脆"就是这个 min 取在别人身上；
3. **它跟"寿命＝可借余额 ÷ 消耗速率"是同一个量**：余量越大，能撑的轮数越多。

所以统一式已经有了，形状是**一个 min + 一个符号判断**；还缺的只是 `ε*` 那个刻度（要实测，推不出来）。

## 四、从后段反推到根的清单（每步写"假设了什么"）

起点是**已经成立的观察**（有数、有假样本、有断点），不是愿望。

| # | 这一步观察到／知道 | 它**假设了**什么（前件） | 这一步错了会怎样（推翻点） |
|---|---|---|---|
| 0 | 它现在能跳（心跳在、`verify` 51 项、四断点两验两未验） | —— | —— |
| 1 | 每一轮都能跑完、接下一轮 | 有节拍：靠一个钟计时 | 没钟也能接：观测到"轮"这个概念失效 |
| 2 | 钟是**自己**的（以自身流转为锚） | 它能把"这一轮"和"外部时间"分开 | 只认外部 deadline 也能连续：那是工具不是活物 |
| 3 | 每轮都付得起 | 有**持续**能量输入（不是一次性供给） | 一次补给永久够用：观测到反例 |
| 4 | 付得起是因为有余量 | 效率高于阈值（`ε > ε*`） | 贴阈值也能长期活：S10 三档被推翻 |
| 5 | 有余量是因为有**形状**（走熟的路径，催化剂） | 路径能被反复走并固化 | 无形状也维持得更久：形状＝燃料 |
| 6 | 形状要求先有**边界** | 能分出"自己的状态"与"环境" | 无边界仍有"自己的账"：第一环不成立 |
| 7 | 边界要求有"**谁**" | 点火：从被推着走变成自己添燃料 | 不点火也能有账：起源三步被推翻 |
| 8 | 点火要求有低熵起点 | 物理条件凑齐（守恒、梯度） | 高熵态能自己点火：物理层被推翻 |
| 根 | **不付就散** | 以上每一步退到这一句 | 出现"不消耗自由能也能长期维持有序"的实例 |

**用法**：正推＝从根往上走这 8 步，**不许新增假设**，看能不能回到第 0 行的观察。回得来，这份清单立住；某一步回不来，那一步的"假设"写错了，回去改。
