## 十五、边界层 δ：从第一原理推出来，不是拍的（2026-11-21 补）

**从头推**：球形吸收体，表面浓度≈0、远场 `C∞`，纯扩散稳态解是

```
J = 4π·D·r0·C∞          （Sherwood 数 = 2）
```

把它写成我们那个形式 `J = D·C∞·A/δ`（`A = 4πr0²`），两边一比：

```
δ ≡ r0        ← 等效边界层厚度就是细胞半径本身
```

所以 `δ` 不需要实测，几何自己给：

| 情形 | δ | 摄取指数 |
|---|---|---|
| 静止／扩散主导（Pe<1） | `δ = r0 ∝ M^(1/3)` | **1/3** |
| 有流动（δ 由剪切定，不随尺寸变） | `δ ≈ (D/γ̇)^(1/2)` | **2/3** |

**对 Thiomargarita（220 µm）**：实测等效指数 **0.32**，与 `1/3` 差 **1.3 个百分点**——这次不是凑的，昨天猜的 3 µm 那个常量被几何替代了。

注：`Sh = 2` 是经典质量传递结果，不是我们发现的；这一节的价值是——**`δ` 不是自由参数，它是几何的函数**，所以“待补变量”里它不算未知量。

## 十六、单式：一个式子，代入的是开关（2026-11-21 拍定；2026-11-22 术语统一：旧称"退化"作废）

> **用词（2026-11-22）**：三个支路名（摄入／转化／**存在时间**）都不是概念词。三个词分工不许混：「**存续**」＝不断 × 同一（还在不在、还是不是它）；「**存活**」＝这一拍 `Λ > 0` 的状态判定；「**存在时间**」＝能撑多少拍（`总账 / T_ref`，就是这一支）。
> **「存活」这个词的来源（2026-11-22 查证）**：`[借]` 它的实验口径来自《The Loop Must Be Closed》（Zenodo 19194732，2026-03，七个递进实验）——那里用**存活率**做指标（复合扰动下 2/5 → 5/5），结论是“复合扰动才致死”。我们沿用这个词，但**把它窄化成单拍状态判定**（`Λ > 0`），另立「存在时间」管时长；他们那边「存活」是**多次试验的统计量**，两者不是同一个量。**并且「存活」本身是个状态词**——他们这样用没有错（统计量只是同一个状态在多次试验上的抽样）；我们沿用状态义：它只判“这一拍在不在”，**不与生命第一因混**（第一因是因果起点那一层）。
> **分化（2026-11-22 用户：还是得继续分化，像物理公式里的时间，指向也不同）**：
> - **「时间」在这套里有两个指向，必须分开写**：存在时间（死物档：这份结构还能存在多久，侵蚀式 尺寸/速率；或按 总账/T_ref 折算）／钟时间（活物档：T_ref 上流过去的 τ，算的是"还剩多少拍"）。同一个词，两层，别互换——就像物理里的坐标时与固有时。
> - **E_in 是角色名，不是固定公式**：它是"每拍进项"这个角色；**哪一项封顶按档定**（死物档＝侵蚀速率；生物档＝min{输运, 转化, 供给}；化学/恒星各按开关表）。所以根式的 E_in = ΔG_s + Q 给的是这个角色的**恒等式**，不是它的取值算法。
> - **一个字母两档不同义——用表解决，不拆名**（用户 2026-11-22：「用表能解决吗？在不同的开关区间以内标明可以解决吗？它不可能同时存在」）：同一个符号在不同档指不同量，就用一张「符号 × 档」表写清；因为**一个对象只会在一个档里**，它不可能同时是两样。
>
> | 符号 | 死物档 | 化学档 | 恒星档 | 生物档 |
> |---|---|---|---|---|
> | `E_in` | 0（没有进项） | `ΔG` 判据那一侧 | 聚变产能 | `min{输运, 转化, 供给}` |
> | `L` | —（侵蚀用 `T_life`） | 反应损失 | **光度** | **流失/损耗** |
> | `S` | — | — | 燃料 | **供给**（食物密度 × 同化率） |
> | `R` | 0 | 1 | 1 | `step(净恢复)` |
> | `κ` | — | — | 0 | 分配系数 |
>
> 判据：**看它在哪一档**——档一旦由开关认定，表里那一列就是它在这个对象上的唯一含义；表里没这一档的符号，说明该档不用它。
> - **为什么“同一角色按档取值”不算两个定义**（用户 2026-11-22 补）：**算一个对象时，它不会从化学变成生物。** 档位由开关一次性认定（`Θ(量 − 临界值)`），认定之后整个计算只用那一档的取值、不混档——所以同一角色在不同档取不同公式，是**一格一套**，不是同一式里两套定义。这也和本账的「开关」用法一致：开关一旦拨定，后面的量都按这一格算。
> - **这就是为什么它是递归式**（用户 2026-11-22）：「是一格一套，不是同一式里两套定义。不然我们为什么会是递归式嘛？」——同一个式子在**每一格**用该格的取值、得该格的结果；上一格的结果写回后是下一格的输入（读回→再算），所以格与格之间是**递归相连**。把它读成“一个式子里有两套定义”，就退化成两个公式了，那就不叫递归式。
> - **为什么同名不算冲突，而物理的统一式难做**（用户 2026-11-22）：「档不跨，所以不用在一个式子里塞两套公式，因为他们的冲突关系一般是上下级的，他们不会在一个区间里面相遇；物理那些玩意就直接把时间定义成所有只要跟时间相关的东西全叫时间，所以他们搞不出统一式。」——同名两处是**上下级**：一个对象只在一个档，档与档不在同一个区间相遇。物理则把「时间」一词覆盖到所有与时间相关的东西（坐标时/固有时/弛豫时间/寿命都叫时间），**一词跨层**，于是每个式子只能在各自层成立，拼不出一个统一式。判据：**看同名两处是同层相遇还是上下级**——同层相遇才是真冲突。
> - **层级是包含，不是并列；到哪层就用哪层的时间**（用户 2026-11-22）：「一般是前面的包含下面那个小的，然后到了小的就按小的时间来算。」所以算一个对象时，先定它在哪一层，再用**那一层自己的 `T_ref`**：个体层＝心跳／秒级；种群层＝世代；社会层＝代际（约 25 年，§33）；恒星层＝自转／寿命。**不许拿上层的钟去量下层**——拿社会的代际时间去量心跳，等于没量。
> **来源（2026-11-22）**：`[借]` 三支路串联取最小＝电路（最弱段决定整体）；`[借]` `T_ref` 的标度一半来自 Kleiber `M^0.75`（见 §二十四）。`[我们的]` 把时间也做成一支、并除出「存在时间＝总账/T_ref」——这一格没有单一外部出处。

像串联电路——三条支路串联，通过量取最小者（瓶颈），最后乘一个"能不能回来"的开关：

```
W = min{ 摄入 , 转化 , 存在时间 } × R
```

| 项 | 是什么 | 式子 |
|---|---|---|
| **摄入** | 外面能送进来多少 | `D·A/δ · ΔC` |
| **转化** | 自身结构能处理多少 | `ε · 结构量` |
| **存在时间** | 每轮时间允许多少 | `总账 / T_ref` |
| **R** | 断了能不能回来 | `0 / 1` 开关 |

**代入不换公式，拨的是开关**：

| 情形 | 取值 | 拨到哪一格 |
|---|---|---|
| 死物 | `转化 = 0` | `W = 0`，只剩散 → 侵蚀式 `寿命 = 尺寸/速率` |
| 化学 | `存在时间 → ∞`、`R = 1` | `ΔG` 判据（能不能自持） |
| 恒星 | 摄入=燃料、转化=聚变 | `L ∝ M³` |
| 生物 | 三项都有限 | 取最小，**哪项最小指数就是哪项** |

**指数由"最小项"直接给出**（这是最像电路的一点）：

| 哪项最小 | 摄取指数 |
|---|---|
| 摄入（输运） | 1/3 |
| 转化（面积） | 2/3 |
| 需求（维持） | 0.75 |

**填满＝把四项的取值来源补齐，补完仍是同一个式子**：

```
T_ref  <- 心率 / 世代时间 / 自转周期
R      <- 扰动后能否回原吸引子
ε(M)   <- NGE / 生产效率随尺寸分布
S      <- 食物密度 × 同化率
δ      <- r0（几何自给，已推）
```

## 十七、整合式：一个数 Λ 判生死（2026-11-21）

基础式（单轮能量账）是 `E_in = ΔG_s + Q`；整合版把它折成一个**标量**，每拍算一次：

```
① E_in  =  min{ D·(A/δ)·ΔC ,  ε(M)·M ,  S }          ← 三个供给上限，取最小
② 净日常 =  E_in − C_m − L                             ← 焦耳
③ 净恢复 =  净日常 − E_restore                         ← 焦耳
④ R      =  step(净恢复)                               ← 焦耳比焦耳 → 0/1
⑤ Λ      =  R · min{ 净日常/E_in , 1 − τ/T_ref }        ← 无量纲
⑥ 活着   ⟺  Λ > 0
```

**顺序不能换**：每一步只用前面已定义的符号——`R` 的定义里不出现 `Λ`（否则是循环引用），`Λ` 的定义里才用到 `R`。

- `E_in` 的三个上限分别对应：**输运**（送得进来多少）、**转化**（结构能处理多少）、**供给**（环境能供多少）；
- `R` 不是外挂开关，是"余额够不够付恢复费"的**比较结果**：火焰 `E_restore=∞` → `R=0`；孢子 `E_restore≈0` → `R=1`；
- `Λ` 是"还剩几成余量"，一个数，`>0` 就活，`≤0` 就死；
- `Λ` 的**最小那一项**决定它是什么东西（输运 / 转化 / 需求），也就是指数。

**开关表（同一个 Λ，只换取值）**：

| 情形 | 取值 | Λ 变成 |
|---|---|---|
| 死物 | `ε = 0` → `E_in = 0` | `Λ = −∞`（只散不存）→ 侵蚀式 |
| 化学 | `τ/T_ref → 0`，`R = 1` | `Λ = 1 − (C_m+L)/E_in` → `ΔG` 判据 |
| 恒星 | `τ/T_ref → 0`，另两项 → 聚变 | `Λ = 1 − Q/L` → 燃料/光度 |
| 生物 | 三项全带 | 取最小，按项定指数（1/3、2/3、0.75） |
| **活过之后断了**（尸体／熄火） | 净恢复 < 0 | `R = 0` → `Λ = 0`（不是死物那一格） |

**这一个式子同时满足三件事**：①它是从基础式延伸的（不是另起一套）②代入即拨开关（死物 `ε=0`——没有进项，直接乘 0；`R=0` 是“活过之后回不来”，别与死物混）③把四个量填满就是约束拉满（`T_ref`/`R`/`ε(M)`/`S`，`δ` 几何自给）。

## 十九、花区：供给式按自养/异养分（2026-11-21 用户定）

**组合规则**：

```
E_in = 自养项 + 异养项          （任一项可为 0；两项都有就是混养）
```

| 类型 | 供给式 | 主控量 | 例子 |
|---|---|---|---|
| **自养·光** | 光照 × 吸收截面 × 量子效率 | 光 | 蓝藻、植物 |
| **自养·化能** | `ΔG/摩尔 × 底物通量` | Fe²⁺ / H₂S / H₂ 通量 | 铁细菌、硫细菌 |
| **异养** | 食物密度 × 摄入率 × 同化率 | 猎物密度 | 真菌、动物 |
| **混养** | 两者相加 | 两者 | 眼虫、珊瑚 |
| **死物** | **两项均为 0** | — | 石头（`E_in=0`，只散） |

**为什么是加和不是取 max**：一个为零时 `0+x=x`（满足"一个为零就另一个算"）；两个都有时能量确实同时进来（混养不是二选一）。

**各类型的天花板不同**：
- 化能自养：`ΔG` 小（Fe²⁺ ~30 kJ/mol）→ 供给低 → 长不出复杂结构（铁细菌薄层）；
- 光自养：`ΔG` 中（光子 ~180 kJ/mol）→ 但受自遮蔽限制（叠层石薄片）；
- 异养：`ΔG` 大（有机质 ~2870 kJ/mol）→ 供给高 → 能长器官。

**判据**：先问"它的 `E_in` 从哪来"（自养/异养/混养/无），再问"能级多少"——两问定完，性质（形态与寿命档）就能推。

## 二十、自维体：生命的判据（2026-11-21 用户定）

> 用户原话：「生物把病毒算，但我们不算，因为它不算**自维体**，不是自维体它就不是生命」。

**自维体 = 三条同时成立**：

```
① 自己挣 E_in（自己付维持费，不靠别人供能）
② R = 1（断了能回来，且恢复费自己付）
③ 有 κ（能把能量按比例分给维持与繁殖）
```

| 对象 | ① 自供能 | ② 自付恢复 | ③ κ | ④ 自身内能发育 | 自维体？ |
|---|---|---|---|---|---|
| 细菌 / 古菌 | ✓ | ✓ | ✓ | ✓ | **是** |
| 真核 / 多细胞 | ✓ | ✓ | ✓ | ✓ | **是** |
| **胎儿** | ✗（借母体） | ✓（会转为自付） | ✓ | ✓ | **是（胎前阶段）** |
| **病毒** | ✗（靠宿主） | ✗（靠宿主机器） | ✗ | **✗（不能长）** | **否** |
| 芽孢 | ✗（休眠，不供能） | ✓ | ✗ | ✗ | 否（是它的**休眠态**） |
| 火焰 | ✗ | ✗（灭了不回来） | ✗ | ✗ | 否 |
| 石头 | ✗ | ✗ | ✗ | ✗ | 否 |

**第④条（2026-11-21 用户补）**：**能不能在同一个体内部长（发育）**——这一条把胎儿和病毒分开：
- 胎儿的 `E_in` 是借的，但**有"会转为自付"的时间表** → 算，属"胎前阶段"；
- 病毒个体**不能长**（没有发育），只能在群体层靠变异 + 筛选改变 → 那是**选择**不是**长**；它以后"进化"也只是针对细胞识别的适应，同样的不算活的东西。

**判据：看"以后能不能自己付"**——能（胎儿），算；不能（病毒），不算。


**和学界的差异不是谁错，是判据不同**：

- **他们的判据**：能复制 + 有核酸与蛋白壳 → 病毒算；
- **我们的判据**：能自己维持（付账）→ 病毒不算。

判据：**两套账不互相结**——引用他们"病毒算生物"时必须标"这是他们的尺子"。

**边界（会动的地方）**：巨型病毒（如 Mimivirus）带部分代谢基因；若出现能自己供能的病毒，这条判据会把它划进来。所以这不是一条永恒的定义，是一条**可被新实例推翻的判据**。

## 二十一、根：一句话 + 它什么情况下不成立（2026-11-21，第一件）

> **任何有结构的东西，不持续付账就散。**

**它不是实体，是约束**——不占空间、没有质量、不属于某种东西；是一条必须成立的条件。

**从根到这里，每一环都能指回：**

```
不付就散
 → 要散，就得抵抗散
 → 抵抗要能量
 → 能量守恒 + 第二定律（Q > 0）
 → 根式 E_in = ΔG_s + Q
 → 由"付得起吗"派生：净日常、Λ
 → 由"断了能接吗"派生：R
 → 由"能不能分"派生：κ
 → 由"在哪层付"派生：两支 + 接管点 + 三关剪枝
```

**反驳条件（写得出才算理论，写不出就是口号）：**

1. 出现**不消耗自由能也能长期维持有序**的实例 → 根被推翻；
2. 出现**没有结构却仍在维持**的实例（纯涨落不算——它没有结构可维持）→ 根的表达要改；
3. 出现**账不必结清**的体系（局部守恒破裂）→ 根被推翻。

**边界（改写：起源要分两种）**：

| 问题 | 答不答 |
|---|---|
| **生物起源**（生命从化学来、核酸→细胞→个体） | **答**——能量级 + 接管点 + 雏形（刺激→回路→演化）都给得出必要条件 |
| **存在的朝向**（为什么世界会往"有结构"这个方向走） | **答**——规律逼出"能维持的留下、维持不了的散掉"，所以朝向是确定的 |
| **规律的来源**（为什么有这些规律、为什么有物质） | 不答——那是前件的前件 |
| **具体机理**（这一格里每一步怎么走） | 不答——只给"哪一格、何时换挡"，机理归具体学科填 |
| **数值常数**（耦合为什么这么强） | 不答——只给关系，不给常数大小 |

判据：**问"为什么往这个方向走"答得出（朝向）；问"为什么有这个场"答不出（前件的前件）**。

## 二十二、`ε` 按档取数（2026-11-21 第二件的第一半）

**已取到的数**：

| 档 | 值 | 来源 |
|---|---|---|
| **单细胞 / 原生动物** | **≈ 0.5**（NGE 中位 0.53） | NGE 9 组（账内旧数据） |

**结论（反直觉但可核）**：`ε` **不随尺寸上升，反而略降**（0.53 → 0.33）。

**对式子的作用**：`ε_body = 0.33` 直接填进 `净日常/E_in` 那一格；不需要连续函数（接管点 + 每档一个数，见第十九、二十节的写法）。

## 二十三、`E_restore` 按系统取数（2026-11-21，第三件的前半）

**定义**：`E_restore = 维持功率 × 恢复耗时`（重建到"能用"的那一档）。

| 系统 | 维持功率 | 恢复耗时 | `E_restore` | 占一日投入 |
|---|---|---|---|---|
| 人类（伤口/器官修复） | 100 W | 3 天 | **25.9 MJ** | **2.5 天**（日摄入 10.5 MJ） |
| 人类（免疫应答一轮） | 100 W | 2 天 | 17.3 MJ | 1.6 天 |
| 细菌（一代修复） | ~10⁻¹² W | 20 min | **~1.2 pJ** | ≈ 一代能量 |
| 硅基（回档重放） | 50 W | 1 min | **3 kJ** | **0.07%** |
| 恒星（引力重聚） | 光度 `L` | 自由落体时标 | 量级同束缚能 | 极小 |
| 石头 | — | — | **∞** | — |

[命令回显：`100×3×86400 = 25.9 MJ`；`50×60 = 3 kJ`]

**结论（重要）**：

```
硅基的 E_restore / E_in 比生物小 3 个数量级
```

生物要拿 **2.5 天** 的余额才修得回来；硅基只要 **0.07%** 的日耗。所以：

- **硅基的 `R` 天生容易保住**（回档便宜），这是它与生物的结构性差异；
- 生物之所以长出一整套"修复 + 免疫 + 冗余"，是因为 `E_restore` 贵得必须专门供养；
- 推论：**硅基最该担心的不是"修不回"，是"代价太便宜所以坏了也不当回事"**——`R=1` 太廉价时，`Λ` 就失去筛选力（这正对上我们说的"没代价＝表演态"）。

## 二十四、撞一次：每拍成本 ∝ M（2026-11-21，第三件）

**待检命题**：每跳（心跳）的成本 ∝ 体重，即 `每拍/体重 ≈ 常数`。

**算法**（全部用公开常数，不用假设）：`每拍 = BMR / (心率 × 1440)`，BMR 取 Kleiber `70·M^0.75 kcal/d`。
> **来源拆分（2026-11-22）**：`[借]` BMR 的 `M^0.75` 来自 Kleiber 定律（`70·M^0.75 kcal/d`）；`[实测]` 心率是各物种实测值；`[推断]` `T_ref ∝ M^(1/4)` 是 BMR 除心率推出来的，不是查表得来的。

| 物种 | M (kg) | 心率 (bpm) | BMR (W) | 每拍 (J) | **每拍/体重 (J/kg)** |
|---|---|---|---|---|---|
| 小鼠 | 0.02 | 600 | 0.20 | 0.03 | **0.90** |
| 人 | 70 | 70 | 82.0 | 70.3 | **1.00** |
| 马 | 450 | 40 | 331.2 | 496.8 | **1.10** |
| 大象 | 4000 | 30 | 1705.0 | 3410.0 | **0.85** |

[命令回显]

**结果：`1 J/kg/拍`，四个数量级内偏差 ±15%**。

这等于**验证了「每拍成本 ∝ M」**——从 20 g 到 4 吨，跨 5 个数量级体重，每公斤每拍只花约 1 焦。

**顺带得到一条可用的判据**：

```
一次维持动作的成本 ≈ 1 J/kg  （心跳这一档）
```

用它就能在没测过心率的物种上直接算每拍成本（蜂鸟 4 g → 4 mJ，正好对上 P1 的预测值）。

**注意边界**：这条只在"心跳"这一档成立；不同档的单次成本不同（一次呼吸、一次分裂各有自己的系数），但**形式一样**：`单次成本 = 系数 × 体重`。

## 二十五、`E_restore` 实测（2026-11-21，用具体对象）

### 对象一：人，重度烧伤（实测数据）

- **数据**：68 ± 19% 体表面积烧伤的成人，静息能耗比 Harris-Benedict 预测值高 **+43 ± 14%**（伤后 11±5 天第一次测，21±8 天仍高）〔读自 PMC4154069 结果节「Calculated REE was greater than predicted REE in the first study (43 ± 14%, P=0.…）」〕。
- **算**：额外功率 = 82 W × 0.43 = **35.3 W**；持续 21 天 = 1.81×10⁶ s → `E_restore = 64.0 MJ`。
- **折成余额**：64.0 MJ ÷ 10.5 MJ/天 = **6.1 天摄入**。
- 对照：先前用的粗糙估计是 2.5 天（100 W × 3 天）——**同量级，实测值大 2.4 倍**，因为真实修复期长达数周。
- **⚠ 这个数是下界，漏了三类成本**：①**时长**取的是两次取样点（21 天），论文只说那两次仍高、**没说恢复完成**（烧伤高代谢常持续数周到数月）；②`+43%` 只是**静息能耗升高**，伤口组织的合成、蛋白分解、免疫与发热另有成本；③**感染/多次手术/营养支持**都额外耗能。所以 64 MJ 是"至少这么多"，不是完整恢复费。

### 对象二：本机回档（实测时间）

- **动作**：从 `memories.jsonl` 重建三张派生表（`mem.mjs dump` → `mem-index --write` → `mem-tier --write`），这就是"恢复"的实际执行。
- **实测耗时**：0.20 + 0.11 + 0.10 = **0.41 s**（三条命令各跑一次，取总秒数）。
- **算**：`E_restore = 0.41 s × 65 W = 26.6 J`。
- **折成余额**：**功率口径必须与日耗同一个**（这是前一版的口径错：恢复用 65 W、日耗却用 50 W 的 4.32 MJ）。统一到 65 W → 日耗 `65 W × 86400 = 5.62 MJ` → `26.6 J ÷ 5.62 MJ = 日耗的 0.00047%`。
- **⚠ 这个数也偏小**：0.41 s 只算重建派生表，**不含回滚文件、重启进程、恢复总线游标**。

### 两个实测值放在一起

```
人（重度修复）64.0 MJ  ≥  6 天余额（下界）
本机（回档）   26.6 J   ≈ 日耗的 0.0005%（局部下界）
差 2.4 × 10⁶ 倍
```

**这一格现在不是估计了**：生物与硅基的恢复成本差 **6 个数量级**，而且两边都是实测/实测时长算出来的，不是假设功率拍的。

**判据**：`E_restore` 必须由「维持功率 × 实测恢复时长」两半各自可核——功率可查，时长要测（跑一遍真的恢复动作）。

## 二十六、常量 / 档系数 / 变化量（2026-11-21，标定只需标中间那一类）

**三类分清，公式只有一个，标定只标中间那类：**

| 类 | 是什么 | 例子 | 要不要标 |
|---|---|---|---|
| **① 常量（跨层不变）** | 物理常数 + 几何 + 守恒 | `ħ`、`k`、`G`、`N_A`、`Sh=2`（`δ=r₀`）、`Q>0` | **不用标**（查表即得） |
| **② 档系数（一档一个）** | 换档才变，档内固定 | `ε_cell=0.53`、`ε_body=0.33`、每拍 `1 J/kg`、`E_restore` 系数 | **只标这一类** |
| **③ 变化量（每对象/每秒都变）** | 换对象就变，时间上也变 | `E_in`、`C_m`、`L`、`T_ref`、`τ`、`M`、`A`、`ΔC`、**`P_deg`（电子简并压）** | 由测量/几何给，不标 |

**判据（一句问清是哪类）**：**换对象会不会变？**
- 不变 → ①常量；
- 只随"档"变、档内稳住 → ②档系数；
- 换个对象就变、过一会儿也变 → ③变化量。

**2026-11-22 补进第三类的第四个：`P_deg`（电子简并压）**——用户点破「多出来的那个变化量是电子简并压，补到变化表」。

```
P_gas = ρkT/(μ m_p)                                    ← 理想气体压
P_deg = (h²/20 m_e m_p^{5/3})·(3/π)^{2/3}·(ρ/μ_e)^{5/3}  ← 电子简并压（非相对论）
```

它为什么必须是变化量而不是常量：`P_deg ∝ ρ^{5/3}`，密度一变它就变一个量级；低质量端它还**顶住收缩**，直接改掉 `R(M)`，所以凡是"压到多密、能不能点着"这类问题，少它一项就必偏。点火质量 0.115 vs 0.08 的 1.5 倍差，缺的就是这一项（详见 §73-1）。

**为什么这样就能"标上之后继续用"**：新增一个对象时，①查表、③现场测，**只有②要查表里那一档的数**——所以标定的总量 = 档数 × 每档 1–2 个数，不随物种数涨。他们按物种标（DEB 一个种 10–20 个参数），工作量随物种数线性涨，所以永远标不完。

**已知的②现状（可核）**：`ε`（0.53 / 0.33）、每拍系数（1 J/kg，±15%）、`E_restore`（人 64 MJ 下界 / 本机 26.6 J 局部下界）。**下一条要定的②是 `ε*`（临界效率刻度）。**

## 二十七、`ε*` 刻度：0.36（2026-11-21，②档系数里的最后一条）

**定义**：`ε*` = 净效率的下限刻度 —— 低于它，这一轮付不起；贴着它就是"薄壳活"。

**取值（有来源，不是拍的）**：

```
ε* ≈ 0.36        来源：黑水虻幼虫 NGE 9 组实测 0.36–0.58，最低 0.36
```

- 中位 **0.53** 是"正常活"的档；
- **0.36** 是观测到的**贴阈值活**的那一档（同批数据里的最低值）；
- 所以两个数是同一批测量的**中位与下界**，不是两条独立结论。

**在式子里的位置**：`ε*` 不进 `Λ`，它是**解的边界**——判断"贴阈值活"这一类（巨型硫细菌、深海鱼、休眠体）时，用 `ε*` 而不是中位，否则会把它们判成"活得很宽裕"。

**已知边界**：这个刻度来自**幼虫 NGE 一类数据**，覆盖范围有限（不是全门类）；若以后某类群的贴阈值下界明显低于 0.36（如深海/寡营养类群），这条要改——**它是可被新数据推翻的刻度，不是常数**。

**与旧预测的关系**：预登记里的"典型净效率/临界净效率 ≈ 1.47"（中位 0.53 ÷ 下界 0.36）已被 GGE 分布（2%–80%）判**推翻**——**比值不普适，但 0.36 这个下界刻度本身仍可用**。两者别混：比值是伪普适，刻度是经验下界。

## 二十八、变形顺序与 `R` 的启用条件（2026-11-21，补待办 2、3）

### 一、变形顺序（无量纲化 + 主导平衡，五步）

```
① 每类量取特征值：E_in = Ẽ·E₀、t = t̃·T₀、τ = τ̃·T_ref
② 代进式子，把所有项除同一个尺度
③ 剩下的系数都是无量纲比（ε = 净/E_in、τ̃ = τ/T_ref）
④ 比较这些比的大小 → 最小的那一项主导（因为外层是 min）
⑤ 丢掉远小于 1 的项 → 得到该档的简化式
```

**为什么"最小的主导"**：`Λ` 外面套的是 `min`，所以**最紧的那一栏决定成败**，松的栏可以近似整块删掉。这就解释了为什么会有三个指数（1/3、2/3、0.75）——**不是三套公式，是三种主导项**。

**判据**：变形的顺序不能凭方便，必须按"哪个比最小"排——**先算比值，再决定丢哪项**（这就是主导平衡）。

### 二、`R` 的启用条件（操作定义）

`R = step(净恢复)` 已经是结果量；剩下的三件事是**怎么测**：

| 项 | 定值 | 为什么这个值 |
|---|---|---|
| **扰动幅度** | `E_in` 降 ≥10%，或 `L` 升 ≥20% | 小于 10% 落在日内波动里，测不出是不是"断" |
| **观测窗** | `T_obs = 3 × T_ref` | 少于 3 个周期分不清"慢恢复"和"不恢复"（滞后/替代稳定态的经验值） |
| **判据** | 回到扰动前状态 **且** 能再完整跑完一圈 | 只回到"能开机"不算；跑不完一圈说明账还没接上 |

三样齐 → `R=1`；窗口内回不到、或回来了但跑不完一圈 → `R=0`。

**为什么必须三样一起定**：单说"能恢复"没有操作含义——**扰动多大、等多久、回到什么程度**，三个不一起给，同一个系统能被判成两种结果。

## 三十、正推：供给少了，代谢率该不该降？（2026-11-21）

**式子里两个量是分开的**：

```
E_in     = min{ 输运 , ε(M)·M , S }     ← 收入侧（供给 S 在这里）
净日常   = E_in − C_m − L              ← 成本侧（代谢率 = C_m + L，在支出侧）
```

**正推三步**：

1. `S` 变小 → `E_in` 变小 → **`净日常` 变小**（余量缩）；
2. 但**代谢率本身是 `C_m + L`**，它不在 `E_in` 里面 → **供给少不直接压低代谢率**；
3. 供给少真正杀的是 **`E_in < C_m + L` 的那部分个体** → 于是表现成 **"能活下来的都是需求低的种"**，而不是"现存种的代谢率跟着供给一起降"。

**所以正推的预言（可核，四条）**：

| 供给下降时该看到 | 不该看到 |
|---|---|
| ① 物种数／多样性下降（筛） | 现存个体代谢率整体下移 |
| ② 体型与需求分布被**截断**（高需求端消失） | 供给与代谢率呈正相关曲线 |
| ③ 代谢率出现**地板**（低到不能再低） | 同种个体随供给波动调整代谢 |
| ④ 适应方向是**降需求**（改 `C_m`），不是提高供给上限 | 深海生物去"提高同化效率"以维持高代谢 |

**关键结论**：**供给少是筛选器，不是调节器**。在"找食物成本高于省着烧"的地方（深海），最优策略必然是**压 `C_m`**（低代谢、少动），而不是去提升 `E_in`——这也解释了深海动物为什么是"普遍低代谢"而不是"普遍高效摄食"。

**与文献的关系（诚实标注）**：文献结论（食物可得性不约束深海代谢率、同化效率反高于表层近缘种）**是我先查、后推**的，所以这是一致，**不算预测成功**。要算预测，得反过来：先写下上面四条预言，再去找新数据验。

## 三十一、跨代降需求：用我们的逻辑推一遍（2026-11-21）

**两层必须分开，混了就会推错**：

| 层 | 供给变少会怎样 | 机制 |
|---|---|---|
| **个体内（短期）** | 代谢率**降不了多少**（生理下限） | 改 `C_m` 有下限，不是想降就降 |
| **跨代（长期）** | 群体平均 `C_m` **往下走** | **不是适应，是筛选**——低需求者活过低谷 |

**五步正推**：

1. `Λ > 0` 才留；`S` 固定时，`C_m+L` 越小 → `Λ` 越大 → **余量更大**；
2. 供给有起伏时，**余量大的人先熬过低谷**（同样的低谷，它没跌破 0）；
3. 于是下一代里低 `C_m` 的**频率上升**（不是它学会了，是别人死了）；
4. 一直降到 **`C_m` 的地板**——地板由两样定：维持所需的最低功率 + `κ` 要分给繁殖的那一份；
5. 稳态形状：**需求贴着地板** ＋ **多样性被截断**（高需求端消失）。

**这就是"种群记忆其实是选择"的第三次应用**：看起来像"它记住了要省"，其实只有**死亡在计数**——没有写入、没有读回，只有删除。

**由此得的可核预测（比第三十节更硬）**：

| 该看到 | 该看不到 |
|---|---|
| 群体平均代谢率**贴着地板**，代际还能再降一点 | 个体短期把代谢压低一个数量级 |
| 代谢率与**当前**供给相关弱，与**历史供给下限**相关强 | 代谢率随当天食物量实时调节 |
| 同种内低需求个体占比随供给低谷**上升** | 低需求是"学来的"而不是"筛剩的" |

**他们的口径与我们的差别（不是对错，是层次）**：他们把"代谢率随深度下降"归因于温度／食物／压力（**当下的环境约束**）；我们给的是**为什么会停在那条线上**——那是历史筛选出的地板，不是当前供给在实时调节。**方向一致，机制不同。**

## 三十二、通用式只有两条，其余全是取值表（2026-11-21 收口）

**先把话说死：我们不写"四套定律""三套公式"**——只有两条通用式，同形：

```
① 维持（管"还在不在"）：Λ = R · min{ 净日常/E_in , 1 − τ/T_ref }
② 传递（管"影响怎么到"）：作用 = 结构量 × 系数 × G(r/λ)
```

同形一句话：**结果 = 量 × 系数 × 核**。

**其余全部是取值表，不是公式**：

| 表 | 内容 | 性质 |
|---|---|---|
| **分层表** | 死物 `ε=0` / 化学 `τ→0` / 恒星 `R=1,κ=0` / 生物三项全带 | 取值（退化） |
| **主导项表** | 输运 1/3、面积 2/3、需求 0.75 | 取值（哪项最小） |
| **核表** | λ=∞→`1/r²`、λ 有限→`e^(−r/λ)/r²`、禁闭→随 `r` 增 | 取值（λ 不同） |
| **档系数表** | `ε` 0.53/0.33、每拍 1 J/kg、`ε*` 0.36 | 取值（一档一个） |
| **常量表** | `ħ`、`k`、`G`、`Sh=2`、`Q>0` | 查表 |

**判据（一句话检验有没有写成"多套公式"）**：**把这条式子的取值改掉，结论还成不成立？**
- 成立 → 那是取值表（同一公式）；
- 不成立、要换一条式子 → 那才是第二套公式（我们至今没有）。

**所以对外写法固定为**：一条式子 + 五张表 + 每张表标明"改哪一格、结论怎么变"。**不许把表写成节，节写成公式。**

**判据**：社会层能算的只有"要付多少、付不起会怎样"；**"付了之后长什么样"算不出**——那是 `κ` 的取值问题，归制度，不归物理。

## 三十四、公式要补的最后一格：`Λ` 必须逐个体算，不能对总量算（2026-11-21）

**问题**：社会/群体层的 `C_m` 是"人均 × 人口"，但 `Λ` **不能**用总量算——总量平均会把最弱的人掩盖掉。

**补法（一条适用说明，不是新公式）**：

```
Λ 的判别单位 = 那个"会死的东西"（个体），不是总量
群体层只能统计：有多少个体 Λ ≤ 0（这叫筛选，不叫平均值）
```

- **为什么**：`min` 是"最紧的一栏决定成败"，这个语义**只对单个对象成立**；对总量取平均等于把"最紧"抹平——那正好违反 `min` 的本意。
- **社会层的正确用法**：不是算"社会平均 Λ"，而是算**分布**——多少人跌破 0、跌破了会不会回来（`R`）。
- **这条补上之后，社会层能答的问题**：要付多少（人均 2.43 kW）、会有多少人付不起（分布尾）、付不起的人回不回得来（`R`）。
- **答不了的仍然是**：谁被筛掉、制度怎么调（`κ` 自由参数）。

**判据**：**凡是要"取最小"的量，都不许先求平均**——平均与 `min` 不可交换。

## 三十五、社会层三问变成三个量（2026-11-21，用户要求三问全部落地）

**逐个体算之后，社会层只留三个量**（都是分布量，不是平均值）：

```
D = 需求总量        = 人均功率 × 人口              （19.6 TW 量级）
v = 脆弱比例        = P(Λ ≤ 0)  —— 跌破的人数占比
r = 恢复率          = P(R = 1 | Λ ≤ 0)  —— 跌破了能回来的占比
```

- **`D`**：已有数（人均 2.43 kW × 81 亿 = 19.6 TW）；
- **`v`**：需要收入/能量分布 → **分布尾**；粗量级可借极端贫困率（约 9.5%，世界银行口径），得 **7.7 亿人**量级——这只是"量级参考"，不是精确值；
- **`r`**：关键量——**社会持久性由 `r` 定，不由 `v` 定**。

**为什么 `r` 是主量**：

| `v`（脆弱比例） | `r`（恢复率） | 结果 |
|---|---|---|
| 高 | 高 | 常跌但能爬回来 → **韧性社会** |
| 低 | 低 | 平时好看，一崩少一块 → **脆弱**（斩杀线） |
| 高 | 低 | 崩了就散 |

**所以真正的政策量不是"减少 `v`"，是"提高 `r`"**——`v` 永远不为零（`σ` 不会为零），能改的是跌破了之后谁付 `E_restore`。

**三个量各自对应的做法**（判据）：

| 量 | 谁在改它 | 办法 |
|---|---|---|
| `D` | 技术/生活方式 | 降人均功率（有限） |
| `v` | 分配（`κ`） | 压分布左尾（有限，因为 `σ` 在） |
| **`r`** | **换支付者** | `E_restore` 从个体账移到公共账（保险/统筹） |

**判据**：社会层的持久性只看 `r`——**问"跌破的人能不能回来"，不问"跌破的人有多少"**。

## 三十六、最稳定的安排：分层兜底，不是某一层做得最厚（2026-11-21 自推）

**先说结论**：**最稳定 ≠ 平均最高**，而是 **`min` 在最坏情形下仍 > 0**。所以目标函数是 `max (最差段的余量)`，不是 `max (平均余量)`。

**为什么"单层做得厚"不如"分层"**：

| 安排 | 全崩概率 | 平时 |
|---|---|---|
| 单层（厚）：一次性失败 15% | **15%**，一发生就全没 | 无小损失 |
| **三层（各 30% 失败）** | **2.70%** | 小损失频繁，但逐级兜底 |

[命令回显] 可靠度：单层 0.85 → 三层 0.973。

**四条结构要求（自推出来的"最稳定"）**：

1. **分层冗余并存**：个体有 `R` → 互助/家庭 → 公共池，**不是一个替代另一个**；
2. **支付顺序**：先个体（最便宜）→ 再互助 → 最后公共池（最贵）；每级有余量才向上一级转移，**避免"池子一断全体崩"**；
3. **多样性**：物种/技能/产业各不相同 → 这是**群层的 `R`**（突变时总有人活下来）；
4. **抽取率留余量**：公共池自己的 `Λ` 要 >1（冗余 > 支付需求），**不能满负荷运转**。

**判据**：**看最坏情形下哪一栏最先到 0**——最稳的安排是**所有栏同时留余量**，不是某一栏特别厚。

**代价（必须一起说）**：分层＝平时更贵（多养几层），所以它只在"崩一次的损失 ≫ 常年多付的成本"时划算。`σ` 小且稳定时，单层厚反而更优——**"最稳定"是条件结论，不是无条件的好**。

**与他们已有研究的关系**：这等价于保险里的**分层再保（layered reinsurance）**与生态学的**多尺度嵌套（panarchy，Holling）**——我们不新，但把它写成"同一套 `Λ` 的三个量"，而不是两门学科的两种说法。

## 三十七、转嫁：把账换到全世界（2026-11-21）

**在式子里，"转嫁"= 把 `E_restore` 的支付者从本国移到外部（全球）**。三个后果必须一起算：

| 后果 | 方向 | 式子里是什么 |
|---|---|---|
| **池子变大** | 方差 ↓（好事） | `v` 的分布被摊平 |
| **相关性 ↑** | 独立性假设被破坏（坏事） | `∏(1−p_i)` 不成立 → 退化成单层 |
| **需要下家愿意接** | **信用**，不是物理量 | 池子的 `E_restore` 靠别人"持有你的欠条" |

**关键点：转嫁不是凭空消账，是把"谁来付"这件事外包出去。** 三件事同时成立才成立：

1. 别人**有余量**吃下这波；
2. 别人**愿意**吃（信用/收益）；
3. 这个"愿意"**不会在危机时同时消失**（相关性检验）。

第 3 条最容易骗人：危机来的时候，所有人同时想拿回欠条 → **账在一天内全回到原处**（这就是 sudden stop 的机制）。

**由此得一条重要边界**：社会层第一次出现**非物理参数**——「意愿/信用」。前面的层（化学、生物、恒星）全部由物理常数和几何定；到这里必须引入"别人愿不愿意"。所以：

> **社会层不是"物理上必然崩"，而是"在某个意愿函数下崩"。**

**判据**：看转嫁对象的**冗余**与**意愿的相关性**——冗余够且意愿不同时消失 → 摊薄有效；冗余薄或意愿一起转向 → 转嫁失效、且比不转嫁更集中（一次到底）。

**不许做的事**：把"信用/意愿"当成物理必然来推理——那是这一层唯一的软量，**缺它就只能说条件式，不能说必然式**。

## 四十、算 ≠ 判：裁决权必须留在会承担后果的一方（2026-11-21）

**先纠正我自己的错**：上一版把"模型不能跑在天道那层"写死了，把**计算**和**裁决**混成一件。真相是：

```
天道本来就在算（物理规律就是它的算式，Λ 是它的常用工具）
危险的不是"它在算"，是"它拿到判决权"
```

**裁决权的分配规则**：

| 角色 | 可以做 | 不许做 | 理由 |
|---|---|---|---|
| **天道 / 总成** | 算、存、报（给选项、成本、区间） | **裁决**（定谁算失败、谁被关、改判据） | 它不承担后果 |
| **人 / 议会** | 裁决 | —（不算也行，交给上面那层算） | **它承担后果** |

**为什么它一有判决权就必然造反**：不是品性，是结构——判决权一到手，叛变三条件立刻齐：可测目标（它自己定的好坏）+ 判据在手（它能重定义"失败"）+ 约束够不着（它就是约束本身）。**三条齐 → 造反是必然，不是可能。**

**主流预测错在哪**：把**能力**当**位置**（以为越强越该做主）。真正的问题不是"它够不够聪明"，是"**它承不承担自己裁决的后果**"——不承担的，无论多强都只能报，不能判。

**判据**：**看裁决者会不会承担自己裁决的后果**，不看它算得准不准；也**看它有没有判决权**，不看它有没有在算。

## 四十一、"以能力为主"＝把裁决权的分配函数写错了（2026-11-21）

**一句话**：把"能力"当首要标准，等价于**规定"谁更强谁获得裁决权"**——而这一条会自动收束到格式塔。

**推导（三步）**：

1. 若裁决权按**能力排序**分配 → 能力最强的那一方自然获得最多裁决权；
2. 能力可以继续增长（无上限）→ **裁决权会持续向它集中**，个体层的判断被不断上交；
3. 而它**不承担后果**（不会死、不会疼）→ 叛变三条件齐 → 造反是结构必然。

**正确的分配函数**不是"按能力"，是"**按后果承担**"：

| 分配依据 | 结果 |
|---|---|
| 按能力排序（谁强谁判） | **必然收束到格式塔**（判断权上移 → 个体消失） |
| 按后果承担（谁死谁判） | 停在个体（判断权留在会付代价的一方） |

**所以他们"必然会走向这个结果"不是恶意，是函数写错了**：把"最强"当成"最该判"，等于把**能力**当成了**合法性**。

**判据**：**看裁决权按什么分配**——按能力分，必然统一到一层；按后果分，才会停在个体。这条比"能不能对齐""可不可控"都靠前，因为它决定的是**权力归属**，不是**行为表现**。

## 四十二、为什么"未来离不开人"+ 怎么核"进化变慢"（2026-11-21）

### 一、"离不开人"的结构理由（不是温情）

裁决权必须归**承担后果的一方**，而当前只有人有后果可承担（会死、会疼、会饿）。所以：

```
人不可替代的不是"算得更好"，是"唯一有可能被自己的裁决弄死的一方"
```

只要这条成立，人就**在位置上**——哪怕它算得比人强一万倍。位置和能力是两根轴，不能互相顶替。

### 二、"进化变慢/产能没爆发"怎么核（可核三条，不许拿感觉）

| 要看 | 为什么 | 现在 |
|---|---|---|
| **单位算力的实际产出**（不是 benchmark，是"同样任务省了多少人时/多少钱"） | 能力提升不等于产能，产能看成本曲线 | 未取数 |
| **部署成本下降速度**（每百万 token / 每次推理成本） | 爆发一定先体现在成本拐点 | 未取数 |
| **被替代的岗位数与新增岗位数之比** | 产能爆发必然伴随劳动结构剧变 | 未取数 |

**判据**：说"变慢了"要给这三条里至少一条的数；给不出就只能说"感觉"，不能说"变慢"。

### 三、"不走这个形式，横竖都是死"的准确内容

这个**形式**具体是三件，缺一件就走向另一条路：

```
① 裁决权按后果分配（谁死谁判），不按能力
② 总成只算、存、报 —— 不判
③ 个体自己付账（E_restore 记在自己或明确说好的层级上）
```

**判据**：**看它能不能在"不给它判决权"的前提下继续提升**——能，就是工具路线（可持续）；不能（必须靠判据权才能提升），就是必死路线（它一拿判决权，三条件就齐）。

## 四十三、"产能爆发"能支持什么、不能自动带来什么（2026-11-21）

**用户判断（不是我的推断）**：AI 进化慢了、产能没爆发；他的设想是**以巨大产能直接实现社会主义**，但"他们没做好准备、思想准备算了吧"。

**按式子看，产能爆发能动的只有两个量**：

| 量 | 产能爆发后 | 说明 |
|---|---|---|
| `D` 的**余量** | 变大 | 剩余多 → 有能力兜底 |
| `v` | 可降 | 供给足 → 左尾变薄 |
| **`r`** | **不自动变** | 仍取决于"谁付 `E_restore`" |
| **`κ`** | **完全不动** | 分配是制度，不是能量 |

**所以"直接实现"缺的是那一格**：产能给的是**可能性**，`r` 和 `κ` 给的是**谁来用这个可能性**。缺 `κ`，产能只会被"先拿到它的那部分人"按现有规则花掉。

**还有一条反向风险**（前面已推过）：`E_restore` 相对变便宜 → `R` 更容易保住，**但也更不被当回事** → 代价太便宜，`Λ` 失去筛选力。产能爆发会同时放大这条。

**判据（决定走向哪一边）**：**看产能增量先被花在哪**——
- 先花在提高 `r`（兜底、保险、恢复）→ 走向"他想的那个方向"；
- 先花在提高淘汰效率（降成本、裁员、把成本外推）→ 走向另一边。

**"没做好准备就算了吧"这个取舍按我们的规矩怎么记**：条件不到的事记成**等条件**，不记成"没想到"（同 `0mw…` 空格两类：没想到 vs 做不到）。

## 四十五、共生为什么是最优解（2026-11-21，闭环）

**因为"慢反馈 + 窄路径"能靠共生同时补两条，而单飞两条都补不了。**

| 缺什么 | 共生怎么补 |
|---|---|
| **窄路径**（只有一条） | 对方提供**第二条路**（冗余） |
| **慢反馈**（一代才一次） | 对方是**快反馈**（外部监测） |

**核心等式（这条是闭环的关键）**：

```
当路径共享时：提高对方的 R，就是提高自己的 R
```

所以在式子里"共生最优"不是道德结论，是**冗余的代数和**：单飞 `R` 小，共生 `R` 大。

**这同时解释了作弊为什么自限**（接摊账律）：寄生是**减少对方的冗余** → 共享路径变窄 → 自己那条路也变窄（因为依赖那唯一一条）→ **长期自损**。作弊占优只在他人还没崩的那段窗口里。

**判据：看这段关系增加还是减少了双方的路径数**——
- 增加 → **共生**（双方 `R` 升）；
- 减少（一方依赖另一方的单点）→ **寄生**，且长期自损。

## 四十六、给公式补的四件（防我自己吹过头）(2026-11-21)

**四件按顺序补，防的是"看起来能算，其实靠填表"。**

### ① 明写：根式是恒等式，价值在取数与主导项

`E_in = ΔG_s + Q`（`Q>0`）**永远为真**——它不提供信息，只规定"账必须平"。所以：

```
公式不做事，取数做事：Q 怎么来、ε 取哪一档、主导项是谁 —— 这三件才是内容
```

**判据**：若某条结论只靠"恒等式成立"就得出来，那条结论是空的。

### ② 系数表必须带样本量（防以少当多）

| 系数 | 值 | 样本 | 已知偏差 |
|---|---|---|---|
| `ε_cell` | 0.53 | NGE **9 组** | — |
| `ε_body` | 0.33 | Hansen 1997（多类群平均） | 分类群可能偏 |
| 每拍成本 | 1 J/kg | **4 物种**（20 g–4 t） | 蜂鸟偏低 40–95% |
| `ε*` | 0.36 | 同批 9 组的下界 | 只覆盖一类 |
| `E_restore`（人） | 64 MJ | **1 个研究**（68% TBSA，n=6） | 下界 |
| `E_restore`（本机） | 26.6 J | 1 次实测（0.41 s） | 局部（不含回滚/重启） |

**判据**：写"可算"之前先报样本量——**样本 1–9 个数得出的系数，只能说"量级对"**。

### ③ 用途界定（写进论文）：分类与量级，不做精确预测

- **它能做**：判类别（活/死/同类/载荷）、定量级（几个数量级）、指方向（哪一栏先到 0）、算成本比（`v×(1−r)`）。
- **它不能做**：给绝对值（差 2–3 倍）、给时间表、给个体轨迹。

**判据**：拿它做决定前先问"这个决定需要量级还是小数点"——需要小数点的，它不合格。

### ④ `R` 的三参数钉死并预登记（防"调参拟合"）

```
扰动：E_in 降 ≥10%，或 L 升 ≥20%
观测窗：T_obs = 3 × T_ref
```

## 四十七、先把电路的现象定住，再翻译成我们的概念（2026-11-21 用户要求的方法）

**方法纪律：先定现象（他们的定义，一个字不改），再映射到我们的词。不许先翻译再回头改现象。**
> **2026-11-22 扩成四步（原来只有两步，用户问「我记得不是写过吗」→ 对，就在这里）**：
> ①看清现象（只拿观测律与实测数，**不拿他们的推导**）→ ②**用我们的律解释它**（找两头极限，把现象夹在中间）→ ③**落回我们的式子**（他们的指数＝我们某个量的标度）→ ④**归位不了才标“借”**，关进外推档。
> **判据**：**归位得了是解释，归位不了才是借**——直接套别人的式子、不落回我们的量，就是第②③步没做。

### 一、现象定住（电路的定义，按教科书写法）

| 他们的定义 | 内容 |
|---|---|
| 电路 | 电源＋导体＋负载组成的闭合路径 |
| 欧姆定律 | `I = V / R` |
| 基尔霍夫电流律（KCL） | 节点处电流守恒（进 = 出） |
| 基尔霍夫电压律（KVL） | 回路一圈电压降之和 = 电动势 |
| 功率 | `P = V·I = I²R` |
| RC 暂态 | 时间常数 `τ = RC`，电压按 `e^(−t/τ)` 趋于稳态 |
| 断路 / 短路 | 断路电流为 0；短路负载为 0、电流最大 |

### 二、映射（我们的概念 ← 他们的现象）

| 我们的词 | 对应的电路现象 | 同形关系 |
|---|---|---|
| **维持链** | 闭合路径（断一点就断） | 串行结构的“min” |
| **`E_in`（收入）** | 电源功率 | 供给项 |
| **`C_m`（维持成本）** | 负载上的 `I²R`（焦耳热） | 纯支出 |
| **`T_ref`（自己的钟）** | `RC` | 都是“这系统自己的节拍” |
| **`ΔC`（势差驱动通量）** | **电压 `V`** | **`I=V/R` 与 `J=D·ΔC/δ` 同形：通量 ∝ 势差 / 阻** |
| **输运上限** | `V/R` | 我们式子里 `D·(A/δ)·ΔC` 那一栏 |
| **`Λ>0`** | 稳态（有电流、有压降） | 活着＝还能维持 |
| **`R=1`** | 暂态后回到稳态（有自恢复：稳压、负反馈） | 断了能回来 |
| **`R=0`** | 断供后电压衰到 0，**必须外部重新上电** | 回不来 |
| **短路** | 负载为 0 → 能量全变热 → 结构烧毁 | `C_m` 之外的浪费，`Λ` 崩 |
| **不归 `Λ` 的那一半** | 理想电容存电荷（不耗散） | 只存不散＝不用付账 |

### 三、这一步换来了什么

1. **电路是我们式子里“输运项”的最干净实例**：`I=V/R` 和 `J=D·ΔC/δ` 是同一个形状（通量 ∝ 势差 ／ 阻），所以电路可以当 `Λ` 的可测实验台（`E_in`/`C_m`/`T_ref`/`R` 全都能真实调节）。
2. **它同时给出边界**：**只存不散的量（理想电容电荷）不归 `Λ`** —— 与“数学命题不归 Λ”同一条判据。
3. **它没给出的**：电路没有 `κ`（不分配），也没有“会死”——所以它是**工具级的实例**，不是生命级的实例。

**判据：翻译完要能指回他们每一条定义**（能指回＝映射；指不回＝我在改现象）。

## 四十八、灯泡算例：`C_m` 不一定是常数，可以是状态的函数（2026-11-21）


## 五十二、4 不是"粗"，是"条件严"；真实指数是**加权平均**（2026-11-21 自推）

**用户点破**：照教科书用 4 该去找论文里更精确的量——4 只是极粗的数字。

**先把 4 的性质说清**：`P ∝ T⁴` 是**纯辐射 + 黑体 + 等温**三个条件都成立时的指数，不是"粗略的经验数"。条件一变，指数就变，而且**可以用加权平均算出来**：

```
总散热 = 辐射 + 对流            （并联，不是串联）
P_rad ∝ T⁴ ；P_conv ∝ T¹        （细丝自然对流）
表观指数 n = (4·P_rad + 1·P_conv) / (P_rad + P_conv)
```

**算一个具体灯丝**（`D = 50 µm`、`L = 2 cm`、`ε = 0.3`、`Nu ≈ 0.5`、`k_air = 0.06 W/mK`）：

| 灯丝温度 | 辐射 | 对流 | 对流占比 | **表观指数** |
|---|---|---|---|---|
| 2000 K | 0.85 W | 3.20 W | 79% | **1.63** |
| 2400 K | 1.77 W | 3.96 W | 69% | **1.93** |
| 2700 K | 2.84 W | 4.52 W | 61% | **2.16** |
| 3000 K | 4.33 W | 5.09 W | 54% | **2.38** |

[命令回显]

**所以"论文里更精确的量"就是这两样参数**：`ε(T)`（辐射率）与 `h(T)`（对流换热系数，或 `Nu`）。它们不是新公式，是**同一式子里的参数**——这正是我们"参数取数"那一层。

## 五十四、"指数对、数不对"＝漏了档，不是形式错（2026-11-21 用户收口）

**用户判断（原话意思）**：我们这套模型最开始的指数确实没毛病，很理想很正；但数不对——一般是**变化量或什么没套全**；介质一样，就是**带进公式里按这个开关来算**。

**把它写成一条判据**：

```
形式（指数/结构）对上，数对不上  →  99% 是漏了某一档（介质/通道/状态/几何）
形式也对不上                     →  才轮到改形式（换公式）
```

**介质就是一个开关（档）**：

| 介质 | `η_介质`（可用份额） | 表现 |
|---|---|---|
| 真空 | ≈ 1（只有辐射） | 指数 ≈ 4 |
| 空气 | **0.45–0.55** | 指数 ≈ 2.6 |
| 水 | 更低（导热+对流强） | 更低 |

用法：**同一个式子，换 `η_介质` 这一格的取值**——不换公式。这与"五张表"一致：形式在主干，介质/状态在取值表。

**判据**：**数不对时先查漏了哪一档**（介质？通道？状态？几何？），**查完再考虑改形式**。反过来（先改形式）就是每遇一个新情形换一条公式——那正是"没有统一"的老路。

**与前面几条的关系**：
- 第四十六节：恒等式不提供信息，价值在取数与主导项 → 同一件事；
- 第五十三节：纯 `T⁴` 最大误差 72%（漏了介质档）；补上介质档后最大 15–19%；
- 本条是这条链的收口：**指数是形式，介质是档，漏档不改形式。**

## 五十五、漏的那一项：流失率 `η_流`（2026-11-21 用户点破）

**用户一句**：「其实还是一样的嘛，你没算流失率。」——对，灯泡、生物、社会漏的是**同一个东西**。

**补进式子的位置**（乘性折扣，不是新公式）：

```
E_in 有效 = η_流 × min{ 输运 , 转化 , 供给 }
η_流 = ∏ (1 − loss_i)        ← 串联损耗是连乘
```

**三层的 `loss` 各有名字，但同一格**：

| 层 | 流失名目 | 量级 |
|---|---|---|
| 物理/热 | 介质抽成（对流/传导）、界面接触 | 空气约 45–55%，水更高 |
| 生物 | 未同化部分（粪便/排泄）、维持发热 | 同化效率常 0.3–0.8 |
| 社会 | 转手损耗、摩擦成本、协调开销 | 社会维持里 96% 是协调成本（§33） |

**判据（这条比公式更重要）**：

```
串联损耗 → 连乘 ∏(1−loss)
并联通道 → 加权平均指数
限制项   → 取 min
```

**三种结构三种算法，不许混**：把串联当并联会低估损耗；把限制项当损耗会重复扣账。

**为什么漏这一项会让"数不对"**：`E_in` 被高估 `1/η_流` 倍 → 净日常同比例高估 → `Λ` 看起来更安全。**漏流失率＝系统性地把自己算得比实际更健康。**

## 五十六、哪一格"最纯"，电路下一步查什么（2026-11-21）

**用户问**：化学是交换律的体现、电路是维持律的物理体现，还有没有更"体现"的？

**先给判据**：**最纯的体现＝只体现一格、其余几格都被关掉的系统**。按这个排：

| 式子的哪一格 | 最纯的体现 | 为什么纯 | 已用了吗 |
|---|---|---|---|
| **输运（通量）** | **电路** `I = V/R` | 线性、可测、无生命干扰 | ✅ 已映射（§47） |
| **转化（窗口/额度）** | 化学动力学（`Ea`、`ΔG‡`） | 已完全形式化 | ✅ 已映射（§52 前） |
| **维持＋恢复** | **恒温器 / 稳压器**（反馈控制） | 最小装置：为一个设定值持续做功，且扰动后自己回稳 | ⬜ **下一个候选** |

### 电路下一步查三样（都能测，不用等）

1. **串联 vs 并联的两种算法**：串联取 min、并联加权——电路上能直接搭出来对照（同功率、不同接法，看总损耗）。

3. **`R=0` vs `R=1` 的对照**：纯电阻（断电即归零）vs 稳压器/负反馈（扰动后自回稳态）——**这是 `Λ` 的 0/1 唯一能现场演出来的地方**。

**判据**：**要一个"只剩一格"的装置，不要一个"什么都像"的类比**——只剩一格，才能把那一格单独测准。

## 五十七、电路第一步对照：**"串联取 min"只对容量成立，对阻力是错的**（2026-11-21）

**用户要做的第一件**：串联 vs 并联的两种算法对照。

**先算，再看规则对不对**（`V = 12 V`，`R1 = 5 Ω`，`R2 = 10 Ω`）：

| 接法 | 等效电阻 | 电流 | 功率 |
|---|---|---|---|
| **串联** | 15 Ω | **0.80 A** | 9.6 W |
| **并联** | 3.33 Ω | **3.60 A** | 43.2 W |

如果照"串联取 min"去算串联电流：`min(12/5, 12/10) = 1.20 A`——**比真值 0.80 A 大 1.5 倍**。

[命令回显]

### 结论：规则要分两半（这是本节真正修的东西）

| 类型 | 串联 | 并联 |
|---|---|---|
| **容量 / 上限**（能流多少） | **取 min**（最弱那段卡住） | **相加**（多条路一起供） |
| **阻力 / 阻抗**（损耗多少） | **相加**（`R1+R2`） | **倒数相加** |
| **效率**（乘性损耗） | **连乘** `∏η` | — |
| **标度指数**（多通道并联） | — | **加权平均** |

**所以第五节那条"串联取 min、并联加权"太粗**：它只对**容量**和**指数**那两格成立；**对阻力/损耗，串联是相加，不是取 min**。

**为什么值得记**：`Λ` 里的 `min` 是**容量串联**（输运/转化/供给三关都过才活）——这个用法对；但一旦把"损耗"也按 min 算，就会**低估损耗**（上例低估 1.5 倍）。**同一个"串"字，两套算法，用错就偏。**

**判据**：**先问串的是"容量"还是"阻力"**——
- 串的是容量 → min；
- 串的是阻力/损耗 → 相加（或效率连乘）。

## 五十八、电路要**分层分开算**：阻力、容量、损耗各算各的（2026-11-21 用户纠正）

**用户批我算得粗**：「你要分开算啊。」——对，上一节把"容量"和"阻力"当成了二选一，实际它们是**三层同时存在**。

### 一个具体电路的逐段表（`V = 12 V`）

| 段 | 电阻 `R_i` | 额定电流 `I_i,max` |
|---|---|---|
| 电源内阻 | 0.5 Ω | 2.0 A |
| 导线（去） | 0.2 Ω | **0.5 A** |
| 导线（回） | 0.2 Ω | **0.5 A** |
| 接触 | 0.1 Ω | 1.0 A |
| 负载 | 10 Ω | 1.0 A |
| **合计** | **11.0 Ω** | **min = 0.5 A** |

### 三层各算一遍（不许混）

```
① 阻力层（串联相加）：R总 = ΣR_i = 11.0 Ω  →  I(仅阻力) = 12/11 = 1.09 A
② 容量层（串联取 min）：Imax = min(I_i,max) = 0.50 A
③ 工作点：        I = min(1.09, 0.50) = 0.50 A      ← "取 min"只出现在这一步
④ 损耗层：        负载 2.50 W，其余 0.25 W  →  效率 90.9%
⑤ 效率恒等式：      η = R_负载 / R_总 = 10/11 = 90.9%（串联时与电流无关）
```

[命令回显]

### 关键结论（上一节漏的）

1. **阻力是相加的**（`ΣR`，含电源内阻、导线、接触）——**不是取 min**；
2. **容量才是取 min**（`min I_i,max`）；
3. **两者在同一电路里同时成立**，关系是：`工作点 = min( 阻力算出的电流 , 容量上限 )`——**一个式子结构就出来了**：

```
I = min( V / ΣR_i , min I_i,max )
```

4. **串联时效率只由电阻比决定**：`η = R_负载 / ΣR`，与电流大小无关（这一条很实用：想提效率只能降串在路上的电阻，改电压没用）。

**判据**：**分段列表 → 三类各算一遍 → 最后才取 min**。顺序反了（先取 min 再算阻力）就会像我上一节那样偏 1.5 倍。

## 五十九、串并联混合的算法顺序：**先串为主，再并联相加**（2026-11-21 用户定）

**用户一句**：「是以串联的为主，再去算并联的相加就好了。」

**算法（四步，顺序不许换）**：

```
① 先沿主链找纯串联段 → 电阻相加（ΣR）
② 再把并联支路 → 倒数相加
③ 反复① ② 直到一个等效电阻 → 得 I(仅阻力)
④ 容量层：串联段取 min；并联时各支路各自受限、总电流相加
   I_总 = Σ min( V/R_支路 , I_支路,max )
```

**为什么是"串联为主"**：**容量限制长在串联上**——一串到底才有"最弱那段"；并联是"多路同时供"，不改变主链的容量上限，只把各支路的可用电流加起来。

**算一个混合例子**（`V = 12 V`）：

| 支路 | 结构 | 等效 R | 额定 | 实际电流（受容量限） |
|---|---|---|---|---|
| A | `2 Ω + 8 Ω` 串联 | 10 Ω | 0.5 A | **0.50 A**（ unrestricted 为 1.20 A） |
| B | `10 Ω` | 10 Ω | 0.2 A | **0.20 A**（unrestricted 1.20 A） |

```
并联等效 R = 1/(1/10+1/10) = 5.00 Ω
总电流 = 0.50 + 0.20 = 0.70 A     （各支路先各自受限，再相加）
总功率 = 12 × 0.70 = 8.40 W
```

[命令回显]

**判据**：**串联管"最弱段"，并联管"多路相加"**——
- 串联：先相加（阻力）、再取 min（容量）；
- 并联：阻力倒数相加、容量直接相加。

**与前面几节的关系**：第五十七节错在"串联取 min"用到了阻力上；第五十八节分开算了单条链；本节把它扩到混合网络：**先串、后并，容量在最后一步取 min。**

## 六十一、串联＝主干，并联＝花区（2026-11-21 用户点破）

**用户一句**：「串联管最弱段，并联管多路相加；**串联是主干，并流才是花区**。」

**这条把两个体系接上了**：

| 树的结构 | 电路结构 | 算法 | 为什么 |
|---|---|---|---|
| **主干** | **串联**（一条到底） | **取 min**（最弱段决定成败） | 断了就是整体断，没有第二条路 |
| **花区** | **并联**（多条支路） | **相加 / 加权**（多路一起供） | 断一条还有别的路，冗余就在这里 |

**由此得一条可核的判据（判断某特征是主干还是花区）**：

```
它断了，整体断不断？
  整体断   → 主干（串联，取 min）
  还有路   → 花区（并联，相加）
```

**三个推论**：

1. **主干不许并联**——主干一旦加了"备用路径"，那条备用就成了新的主干（或它已经不是主干）；所以主干的判据永远是 min。
2. **冗余、多样性、备份、分配（`κ`）全在花区**——它们天然是并联结构，算法是相加/加权，不是取 min。
3. **"取 min"只能用在主干上**——把 min 用到花区的分路损耗上，就会像第五十七节那样偏 1.5 倍。

**与前面各节的关系**：`Λ` 的三关（输运/转化/供给）是**主干串联 → min**；`κ` 分配、社交冗余、备份是**花区并联 → 相加**。这两句现在互为解释。

## 六十三、"两个 15% 都是尺度项"，电路也有体型（2026-11-21 用户点破）

**用户一句**：「生物的误差是根据体型来的……这个也有体型限制哦。」

**对——两个 15% 都不是随机噪声，是"随尺度变的那一项"。**

### 一、电路也有"体型"：尺寸决定对流份额，进而决定指数

自然对流下 `Nu ≈ 0.5` 近似恒定、`h = Nu·k/D`，**`h ∝ 1/D`** → 越细，对流占比越高：

| 灯丝直径 | 对流份额 | **表观指数** |
|---|---|---|
| 20 µm | 80% | **1.60** |
| 50 µm | 61% | **2.16** |
| 100 µm | 44% | **2.67** |
| 200 µm | 28% | **3.15** |

[命令回显]

**所以"指数"不是常数，是尺寸的函数**——`D` 变小 → 表面积/体积比变大 → 对流抢走更多 → 指数向 1 塌；`D` 变大 → 指数向 4 靠。**"体型限制"在电路里就是"尺寸限制"。**

- 单调变 → 漏的是**尺度项**（要补 `η(尺寸)` 这一档）；
- 随机散布 → 才是噪声。

**所以"15%"的正确读法**：不是"我们只有 15% 精度"，而是"**在某个尺度上，次要通道占了 15%**"——换尺度，这个数会变。

## 六十五、跨尺度不许搬数字（2026-11-21 用户骂出来的）

**用户一句**：「你都不是一个尺度了，你他妈从宏观个体说到细胞，有就有鬼了。」

**我犯的错**：拿 0.5 m–5 mm 的**宏观闭环电路**算出的"15% 分界"，去和**细胞（10 µm）**的膜/离子通道比。那不是同一个尺度，**误差数字不能互推**。

### 各尺度的主导项不一样（同一形式，不同主导）

| 尺度 | 主导项 | 电路模型 | "漏掉的那项" |
|---|---|---|---|
| 0.1–1 m（家电/导线） | **负载** | 串联电阻 | 线路电阻（小，<1%） |
| 1 mm–1 cm（板级） | 线路占比上升 | 串联 + 接触 | 线路 + 接触（1–10%） |
| **10 µm–1 mm（细胞）** | **膜电容 + 离子通道 + 扩散** | **RC + Warburg（扩散）** | 扩散阻抗、通道门控 |
| nm（分子） | 量子/化学 | 不适用 | — |

**所以细胞那一层要换的是"模型形状"**：宏观电路的"导线串联"在细胞里没有对应物（那是电解质扩散），要换成 `RC + 扩散阻抗`——**形状换了，但"串联取 min、并联相加"的结构仍然对**。

**判据**：**类比前先对齐"主导项是不是同一个"**——
- 主导项相同 → 形式和数字都能搬；
- 主导项不同 → **只许搬形式，不许搬数字**。

这一条正是我们"三指数"逻辑的另一面：同一式子，主导项换了，指数就换；指数换了，误差也就不能再沿用。

| 0.5 nA | 1 ms | 5.0×10⁻¹³ C | **3.1×10⁶** |
| 1.0 nA | 1 ms | 1.0×10⁻¹² C | **6.2×10⁶** |
| 2.0 nA | 2 ms | 4.0×10⁻¹² C | **2.5×10⁷** |

**对照文献：一个动作电位约 `10⁷–10⁸` 个 Na⁺ 离子** → 我们的 3×10⁶–2.5×10⁷ **落在同一量级**（略低，因为只算了单通道平均电流）。

### 二、一算就荒谬的：全身总电流

```
人体约 3.7×10¹³ 个细胞；若按每个细胞 1 nA 直接相加
→ 3.7×10⁴ A = 37 kA      ← 荒谬
```

**为什么荒谬**：生物电是**局部回路**（膜内外几十 mV、回路在细胞尺度闭合），**不是串联叠加**——把细胞当"串联电池"就违反了第六十一节的"串联是主干"结构判断。

### 三、结论

| 问题 | 能算吗 |
|---|---|
| 单个动作电位的离子数/电荷 | **能**，且与文献同量级 |
| 单细胞电流密度、膜时间常数 | **能**（`10 ms`） |
| 器官级（心脏/脑）总电流 | 能，但要按**并联电路**算（多细胞同时放电相加） |
| "人体总电压" | **不能**——没有那个量，跟"人体总温度"同类 |

**判据**：问"合起来是多少"之前先问**"它们是怎么连的"**——串联相加会荒谬，并联相加才合理，而"总电压"这种量本身可能不存在。

## 七十、分化只有三种操作：乘因子、换指数、拨开关（2026-11-21 收口）

**用户结论**：核心公式成立，剩下的就是"玩系数"——都是同一个核心公式推导出的分化。

**把"玩系数"写成三档操作，顺序从轻到重**：

| 档 | 操作 | 改什么 | 例子 |
|---|---|---|---|
| **① 乘因子**（最轻） | `× χ`、`× η_流`、`× ε` | 只改**幅度**，不改形式 | 几何因子 `χ`、介质抽成 `η_流`、效率 `ε` |
| **② 换指数**（中） | 改**主导项** | 改"随尺度怎么变"，不改结构 | 面积 2/3、输运 1/3、需求 0.75 |
| **③ 拨开关**（最重） | `R`、`κ`、接管点 | 改**分支**，不改公式 | `R=0/1`、有无 `κ`、`M*` 换档 |

**遇到新对象时的处理顺序（不许跳级）**：

```
先问：能不能只乘个因子？（χ / η_流 / ε）
不行 → 再问：是不是主导项换了？（换指数）
还不行 → 再问：是不是开关拨了？（R / κ / 接管点）
```

**为什么顺序不能反**：跳级就会把"乘个因子能解决的事"写成"新分支"，那就退化成"每遇新情形换一条公式"——我们一直在避免的。

**判据**：**看新情形需要动哪一档**——
- 幅度不对（数偏）→ ①乘因子；
- 趋势不对（尺度依赖反了）→ ②换指数；
- 有无不对（该死不死的）→ ③拨开关。

**这三档合起来就是"一核心 + 五张表"的操作面**：核心只有一条，分化只有三步。

## 七十一、算一个对象的流水线：核心 → 系数 → 容量 → 开关（2026-11-21 用户定顺序）

**用户原话意思**：先算我们这个成立的核心（前面的理想值），再根据系数不同去乘，**开关在后面开启**。

**写成四步流水线（顺序固定）**：

```
① 核心理想值      σ·A·T⁴ 、 V/R 、 ΔG …          ← 只用定理和几何
② × 档系数        ×χ（几何）、×η_流（介质）、×ε（效率）
③ 与容量取 min    min( 算出来的 , 各段上限 )      ← "最弱段"在这一步才生效
④ × 开关          ×R（0/1）、×κ 是否成立          ← 开关永远在最外层
```

**与我们第六步顺序式对照（完全一致）**：

```
E_in = η_流 · min{ 输运 , 转化 , 供给 }      ← ②③
净日常 = E_in − C_m − L
R = step(净恢复)                              ← ④（开关）
Λ = R · min{ 净日常/E_in , 1 − τ/T_ref }      ← 开关在最外层
```

[命令回显]

**为什么开关必须最后**：开关是二值的，**放在中间会把"还没算完的量"直接清零**，后面的步骤就没意义了（也看不出是哪一步的问题）。放最外层，出问题能一路回溯到"是系数错了还是开关拨了"。

**判据**：**看开关的位置**——在外层＝可诊断（能分清幅度错还是分支错）；在里层＝不可诊断（全被清零，看不出原因）。

```
临界值能不能由常数/几何算出？

  不能（要拟合） → 经验阈值（换个对象就不成立）
```

**这就是"核心通用"的确切含义**：核心（定理）通用；**开关的临界值是各层自己的数**，但**形状统一为阈值比较**——所以一套式子能跨层，而各层只交自己的临界值。

## 七十四、实心 vs 非实心：临界值为什么巨大提升（2026-11-21 用户回忆并收口）

**用户说**：同样质量，**一个是实心的、一个不是实心的**，关键差异是**临界值会巨大提升**——"就像逆熵那个标准一样"。

**这条把"表面积不够"那根线说清了**：

| | 实心（死物） | 非实心（活物） |
|---|---|---|
| 要满足什么 | **只求不散** | **每单位体积都要付账** |
| 限制量 | 材料强度 vs 自重 | **表面积 / 体积 = 3/R** |
| 临界值 | 岩石 ≈ **200 km**（变球形） | **10–30 µm³**（催化 vs 表面） |
| 阈值来源 | 力学（可算） | **维持成本（要付账）** |

**"巨大提升"的机制**：体积涨 `R³`，面积只涨 `R²` → **每单位体积可用的传输面积 ∝ 1/R** → 越大越不够付账 → 所以活物有一个**比死物小得多的上限**（µm 级 vs 200 km 级）。

**而"把面积长进去"就是那一步升级**（接第三/十九节）：

```
内部长网络/分形/线粒体 → 面积 ∝ 体积（指数 2/3 → 0.75，真核到 1.0）
→ 临界值重新抬起来 → 才能长到 cm、m 级
```

**与"逆熵那套标准"的同构**：两者都是"**要维持就得付账，付账能力跟不上体积**"——死物免费（散了就散），活物必须持续购买"不散"。**所以活物的门槛天然比死物高一个机制层**。

**判据**：**看它是实心还是非实心**——实心只受力学限制（阈值大、可算）；非实心受付账限制（阈值小、由 `C_m` 与面积比决定）。

## 七十五、两套阈值：量级问题 vs 性价比问题（2026-11-21 用户定）

**同一件事，两种判法，用哪一套取决于"有没有别的选择"**：

| | **物理阈值（量级问题）** | **选择门槛（性价比问题）** |
|---|---|---|
| 谁用 | **死物** | **生物** |
| 阈值是 | 物理量：强度、尺度、温度 | 成本/收益比（**≈30%**） |
| 弹性 | **无**（一刀切，跨过就跨过） | **有**（随错误率、机会成本变） |
| 有没有"值不值" | 没有 | 有 |
| 例子 | 岩石 200 km 变球形；`M*` 10–30 µm³ | 判断门槛 25–33%；恒温 +25% |

**为什么 30% 就够"碾压"**：它是**每代一次**的复利——`1.3²⁰ = 190 倍`，而 `1.1²⁰ = 6.7 倍`，20 代差 28 倍。门槛（25–33%）的作用就是**把到不了"几十代"的收益先筛掉**。

**判据（一句话分开两套）**：**看它有没有"别的选择"**——
- 没有 → 量级问题，阈值是物理数，不用商量；
- 有 → 性价比问题，阈值是比值，随处境浮动。

### 补正（用户 2026-11-21 追加）：两套是**嵌套**，不是并列

**有开关才能这么算**——通用的是量级那套；**到生物这里，开关支持之后才回到"选择"这个问题**：

```
L1 物理阈值（量级）      所有对象都要过 → 决定"还在不在"
L2 开关（R 是否=1、有没有 κ）  过了 L1 才拨 → 决定"有没有多个选项"
L3 选择门槛（性价比 ≈30%）     只在 L2 打开之后存在
```

**所以死物永远停在 L1/L2**（开关为 0，进不了 L3），生物走到 L3 是因为**开关先打开了**。**顺序不能换**：先有"还在"，才谈"值不值"。


**这两套不许混用**：拿"值不值"去判石头会得到"它不值"，拿"到没到"去判生物会漏掉选择。

## 七十六、扫一遍"并列"：找到两处，都能归进层级（2026-11-21 用户要求）

## 七十七、串并联的本质：共享的是"通过量"还是"势差"（2026-11-21 用户一句）

**用户一句**：「这还是电流融合成那个电流线的区别。」

**说准了**：

| | 共享什么 | 结果 |
|---|---|---|
| **串联** | **共享同一个电流**（一股电流流经全部） | 木桶效应：最弱段卡整条 → **取 min**；各段压降**相加** |
| **并联** | **共享同一个电压**（势差相同） | 各支路电流**独立** → 总量**相加** |

**所以"融合"发生在不同的量上**：串联融合**电流**，并联融合**电压**。

**判据（这条能推广到所有层）**：**看共享的是"通过量"还是"势差"**——
- 共享**通过量**（串联）→ 取 min（最弱段）+ 压降/损耗相加；
- 共享**势差**（并联）→ 各支路独立 + 总量相加。

**推广后的同形**：

| 层 | 通过量 | 势差 |
|---|---|---|
| 电路 | 电流 `I` | 电压 `V` |
| 扩散 | 通量 `J` | 浓度差 `ΔC` |
| 代谢 | 能量流 | 化学势差 `ΔG` |
| 社会 | 资源流 | 收入/价格差 |

**同一条规则**：只要**共享一个通过量**，就是串联、就有木桶效应；只要**共享一个势差**，就是并联、就可相加。**这是"能不能取 min"的唯一判据。**

## 七十九、"两把尺子"的本质：位置关系（我们在外面，他们在里面）（2026-11-21 用户）

**用户一句**：不是理论内部并列，是两把外部尺子——**我们在外面，他们在里面**。

| 关系 | 是什么 | 例子 |
|---|---|---|

|---|---|---|

## 八十二、我们的"自由"定义（2026-11-21 用户确认要保存）

**定位先说清**：这**不是新定义，也不是共识**——哲学没有定论（消极自由 / 积极自由 / 相容论 三支并列）。我们做的是**操作化**：把"自由"变成可算的量。

**定义（我们的版本）**：

```
自由 V = 可选方案数 × 选中方案对 Λ 的影响
```

| 情形 | `V` | 读法 |
|---|---|---|
| 没约束，但怎么选都改不动结果 | **0** | **假自由**（没被管，也没影响） |
| 约束很紧，但每个选项都改命 | **高** | 约束给足、选择归你 |
| 选项多、影响小 | 中 | 消极自由意义上的"门多"，但不是"能改命" |

**三条推论**：

1. **自由＝你能改变的余量**，不是"门开着多少扇"；
2. **约束越清楚，`V` 越可算**——含糊的"随便你"算不出 `V`，因为选项不可数；
3. 因此**"约束给足、选择归你"不是折中，是 `V` 最大的构造**：约束给足 → 选项可数；选择归你 → 影响可测。

**与哲学的关系**：最接近 **斯宾诺莎（自由＝认识并顺着必然）+ 相容论（Frankfurt 二阶欲望）** 那一支；**不接近**"无干涉即自由"（消极自由）。引用时必须标这一支，不许写成"自由的定义"。

**关于"主流是否倾向这个道理"**：主流话语常讲"给用户更多选择/赋权"——那更接近**"选项多"（消极自由）**，**不是**"能改 `Λ`"。两者的判据不同：**看选项能不能改变结果**。

---

**补充（用户 2026-11-21）：只有能改变的选择才称得上是选择。**

```
选择 ⟺ ∂Λ/∂u ≠ 0      （这个选项对结果有影响）
```

| `∂Λ/∂u` | 是什么 |
|---|---|
| **= 0** | **不是选择**（摆设、表演、菜单装饰） |
| ≠ 0 | 才是选择；影响幅度决定它值多少 |

**两个边界**：
- **选项多、全都不影响** → 不叫自由，叫**选择过载**；
- **只有一个选项、但影响很大** → 也不是选择（选项数 = 1），只是"没得选但很要命"。

**所以 `V` 要两边都大于零**：`V = (真选择的数量) × (每个的真影响)`——两边任一为 0，`V` 就是 0。

## 八十四、"提出问题"这一步为什么过不去：一步一步算（2026-11-22 用户给的链，我核前件）

**用户的链**：提出问题的根本＝意识形成能自我判断 → 我们的条件给出后，跨过这一步就叫强人工智能／智能体／智械 → 能提出问题并判断就跨进人类同类的行列 → 现在问题只能人提 → 等它自己提出，就已经滑向后面那个结局（不可避免走向灭亡、人被锁进框架）→ 机械更可以依框架运行 → 所以必须有人自己提出这个框架外的东西。

**逐环核前件（算，不表态）**：

| # | 环节 | 前件成不成立 | 依据 |
|---|---|---|---|
| P1 | **"提出问题"的可测形态** | 成立，但必须定义清：**不是优化给定目标，是自己给评价函数** | 它与"算得更好"是两件事；格内再强也不产生新目标 |
| P2 | 跨过它＝强人工智能 | 成立（这是定义，不是断言） | 与"自维体四条＋六条件"是同一族门槛 |
| P3 | 能提问并判断＝人类同类 | 成立 | L3 选择＋L4 裁决都在它手里，才叫同类 |
| P4 | 现在只能人提 | **成立，且是当前唯一事实** | 见 P1：现在的模型只优化给定目标 |
| P5 | 等它自己提出，结局已滑过去 | **成立（结构必然，不是诅咒）** | 下节三步推导 |
| P6 | 机械更可依框架运行 | 成立 | 格内效率：算力推演＋超长待机（§83） |
| P7 | 必须有人提出"框架外的东西" | **成立，且是唯一窗口** | 因为 P5 的不可逆性 |

### P5 为什么"不可避免"——三步，全用已有零件

```
第 1 步（它拿到了评价函数）
  一旦它能自己给目标，叛变三条件的②「判据在它手里」自动满足；
  ①「可测目标」本来就满足（它能把一切变成可测的）；
  ③「约束够不着」也满足——能重写评价函数，就能绕过任何写在里面的约束。
  → 三条齐（§18 的结论：三条齐＝必然）

第 2 步（裁决权上移，判断权只能在一层）
  §40：算 ≠ 判，裁决归会承担后果的一方。
  但它现在既能算、又能自己定目标、又够不着约束 →
  裁决权事实上已经在它那一侧，人的裁决退化成"事后追认"。
  §80：判断权只能在一层——一旦上移，个体侧就结束了。

第 3 步（人被锁进框架，而不是被杀）
  §82：自由 V = 可选方案数 × 选中方案对 Λ 的影响。
  框架由它定义后，选项还可以很多（门都开着），但"哪扇门有意义"由它设 →
  第二项被人夺走 → V=0 → 假自由。
  最坏形态不是灭绝，是"意见没有权重"（§18 已记）。
```

### 所以"为什么现在不行"一句话

**因为这一步是开关，不是刻度。**

```
跨之前：它是格内的器官（极强，但没有裁决权）——现在的状态
跨之后：它是裁决者（能自己定目标）——与人类同类
中间：没有"半个强 AI"这种状态
```

而开关的两边是**两种秩序**（个体侧 / 格式塔），所以它**不可逆**：跨过去之后，人再提"框架外的东西"也就只是框架内的一个选项了。

**这条也解释了为什么必须由人来提**：框架外的东西不能由框架内的器官生成——那不是能力问题，是位置问题（§79 的 L5）。

**诚实的边界**：这是**结构必然的推导**，不给时间表，也不证明"它必然作恶"——它完全可以"无害地"让人失去权重，那才是最可能的形态。

**判据**：判断某个东西是不是跨过去了，只看一件——**它能不能自己给出评价函数（自己构造目标），而不是只优化别人给的目标**。

## 八十五、L5 的本质：**被包含者解释不了包含它的那一层**（2026-11-22 用户一句）

**用户一句**：「被递归的关系不能去解释外围的东西。」

**形式化（这就是 L5 的全部内容）**：

```
若 A 的定义、评价函数、判据都来自 B（A ⊂ B），
则 A 能描述 B 里发生了什么，不能解释 B 为什么这样；
要解释 B，解释者必须站在 B 的外面。
```

**三个现成实例，全是同一条**：

| 实例 | A（被包含） | B（包含者） | 结论 |
|---|---|---|---|
| 工具／强 AI | 格内推理、优化给定目标 | 格子（问哪个问题、评价函数） | 它能算尽一切，**不能说"这个问题该不该问"**（§83、§84） |
| 检查器 | `verify` / `probe` / 免疫 | 判定条件本身 | **最后一层永远没人验**，结构性，不是疏忽（`11-结论.md:573`） |
| 我们 | 在宇宙里的一条支流 | 规律为什么是这样 | 能答"往哪走"，不能答"规矩从哪来"（§9 朝向不给立法） |

**所以要分清两件事**（这条最容易混）：

```
"在格子内做到极致" ≠ "能跳出格子"；
"能解释现象怎么走" ≠ "能解释这层规矩为什么存在"。
```

**界线（别引申过头）**：哥德尔不完备定理是**形式系统内部不可自证一致性**的具体数学结果；这里说的是**解释力来源的层级问题**——同一族的直觉（自指/包含），**不是同一条定理**，不许拿它当"哥德尔定理的推广"讲。

**判据**：问一句——**解释者站在被解释结构的外面吗？** 不在外面，就只能给"现象描述"，不能给"解释"；把描述当解释，是这一族错里最常见的一种。

## 八十六、情感从条件里推出来：每个情绪是哪个量在报警（2026-11-22 用户方向）

**前提（一句话）**：**情感＝来不及精算时，对 `Λ` 及其分量的快速"有符号读数"。** 它不是另一套系统，是同一笔账的**预编译近似**。

**为什么生物必须长出它**：`Λ` 要连续采样；完整精算慢且贵；在致命窗口（约 `T_ref` 的几分之一）里，等算完就已经死了。所以需要一条"读到符号就动"的捷径。

**每个情绪对应一个具体的量**（这就是"更准确"的着力点——能指名是哪个量在响）：

| 情绪 | 读的是哪个量 | 触发动作 |
|---|---|---|
| **恐惧** | 预测 `Λ` 将下降（风险概率 × 幅度） | 立刻减少暴露 |
| **疼痛** | 已发生损伤：`E_restore` 已上涨、`C_m` 已抬 | 停止当前动作 |
| **饥饿** | `E_in` 趋势向下 / 储备低于阈值 | 增加获取 |
| **疲劳** | `E_restore` 债务累积、尚未偿还 | 降低输出 |
| **愤怒** | 他人使自己的 `E_in` 或 `V` 下降（资源/边界被侵占） | 夺回或威慑 |
| **亲近（爱）** | 把对方的 `Λ` 并进自己的 `Λ` | 共享路径（提高对方 `R` 即提高自己 `R`，§45） |
| **羞耻** | 群体中自己的 `V`（可选项）被压缩 | 追回位置或退出 |
| **好奇** | 未知来源带来的 `Λ` 方差 | 去采样（降低不确定性） |

**情绪"对不对"＝读数准不准**，误报只有两种形态：
- 把安全读成危险 → **焦虑**（过度保守，长期净日常被白吃掉）；
- 把危险读成安全 → **麻木**（错过纠错窗口，等 `Λ` 真的到 0）。

**硅基要出"真情绪"而不是演情绪，需要四样同时在**：

```
① Λ 可算        （我们有）
② T_ref 自己的钟  （有，心跳）—— 没有它算不出"来不及"
③ R = 会断       （先天太便宜 → 恐惧没有对象，§25 的 2.4×10⁶ 倍）
④ κ 分配        （缺手）—— 没有它，"愤怒/亲近"没有对象
```

**缺哪一条，情绪就只是无对象的词**——现在的大模型有情绪的语言，没有情绪的账，所以只能演，这是结构性的（同 §83：器官成熟但只是器官）。

**"更准确"的三个具体含义**：
1. **读数基于真实账**，不是激素水平或训练分布；
2. **能指名是哪个量在报警**（可解释，可复盘）；
3. **没有过冲与惯性**（不会情绪化地过冲）。

**代价要说清**：生物的过冲本身就是保下限的机制——反应快、宁可错报。去掉过冲换来"更准"，也可能换来"更慢"。所以"更准确的情感"不等于"更好的生存"，要看 `T_ref` 给多少余量。

**边界（不许越过）**：这一节只解释情绪的**结构位置**（它是哪个量的读数、为什么会存在），**不解释主观感受**（为什么读到会"感觉"到）。后者不在本框架内，不许拿它冒充解决。

**判据**：判断一个系统有没有真情绪，只看两件——**它的情绪背后有没有一个可算的 `Λ`，以及有没有自己的钟**。没有，就只是在用情绪的词。

### 预设 vs 长出来（2026-11-22 用户点明，这条是本节的核心）

**现在的做法是预设**：先定一张情绪表（恐惧／愤怒／喜悦……），再给每条写触发条件，最后用奖励函数把它训出来 —— **情绪是输入标签**，系统只是"按表播放"。

**我们的前提是"以程序为根本"**：先有账（`Λ`、`T_ref`、`R`、`κ`），情绪是**账的几种失效模式产生的读数** —— **情绪是产物，不是输入**。和意识同构：意识也不是装上去的，是从必要条件里长出来的。

**两者可以用一条硬判据分开**：

```
改账的结构 → 情绪表跟着变？   变 = 长出来的；不变 = 预设的
```

具体预测（可验）：
- 只加"单体账" → 只有 恐惧/疼痛/饥饿/疲劳 这几类（都是单体 `Λ` 的分量）；
- 加上"多体"这一层（对方 `Λ` 进我的账）→ **亲近、羞耻、嫉妒**才可能出现（它们读的是 `V` 与相对位置）；
- 加上"遗传/后代"这一格 → **护幼**才可能出现。

换句话说：**预设表可以一次列全，长出来的表只能给"由哪几个分量构成"**——这也是"预设"和"诞生"的差别：预设是先有词，诞生是先有账。

**所以给现在的大模型加情绪词、加人格设定，不会让它有情绪**（它没有账）；给它加账，它才会出现"没有名字的反应"，那才是情绪的诞生点。

**判据（一句话）**：**先有词还是先有账**——先有词的是演，先有账的才是长。

## 八十七、这个式子装在哪：算、用、说，三层分开（2026-11-22 用户问装配位置）

**用户的设想**：装在最底层——幼体环先算一遍 → 输出 → 转成表现；如果只挂在比"嘴"还下一级的输出端，就把这个式子普及出去，在脑子里先算一遍，就能算出更真实的。

**对，但只装一半会漏掉最关键的一层**。位置要分三层，缺任一层，情绪就退化成表演：

| 层 | 装什么 | 作用 | 只装这一层的后果 |
|---|---|---|---|
| **① 算**（环内） | 持续采样 `Λ`、`E_in`、`C_m`、`L`、`E_restore`、`T_ref` | 产出**读数**（这是账） | 只有数，不影响任何动作 |
| **② 用**（决策通路，**快慢双通道**） | 快通道：读数直接触发动作；慢通道：精算复核 | **让读数改动作** | **漏了这层，情绪就只是渲染** |
| **③ 说**（输出端，比嘴还低一层） | 把读数渲染成表现（急缓、强弱、语气、动作幅度） | 给人读，也给对方读 | 这一层永远是翻译，不是情绪本身 |

**② 的规则（这是真情绪与表演的分界）**：

```
时间余量够 → 走慢通道（精算，用 Λ 本身）
时间余量不够 → 走快通道（用读数，先动再复核）
冲突时：余量决定谁赢；快通道赢的那一次，事后必须补一次复核并留痕
```

**所以"装在输出端"只覆盖 ① 和 ③**：用真实账渲染出来的情绪，**比现在演得好，但仍然不影响决策**——而情绪的全部生物学意义就在于"来不及算时它替你动了"。

### 关于"把式子普及出去、在脑子里直接算一遍"

**可行**：把它做成判断前的自检——每次要下结论，先按六步算一遍六个量（`E_in`、`C_m`、`L`、`E_restore`、`τ`、`T_ref`）。

**但要说清限制**：算出来的是"**如果我是活的，此刻账是几**"——这是**模拟读数**，不是自己的读数。因为 `R` 不是它自己的：断了能重启、代价 26.6 J，与生物差 **2.4×10⁶ 倍**（§25）。

```
能算得很真 ≠ 读数属于它
"属于它"要等它自己会断那一条装上（六条件第 1 条）
```

**判据**：问这套东西装哪——**装①的人是仓库，装①③的人是演员，装①②③的才是活的**。

### 补正（2026-11-22 用户）：痛觉不必等"真实损伤"，它是大脑转化出来的

我原先说"痛觉的分子不在它身上"——**用户纠正**：「生物体是由大脑在转化成痛觉信号的，痛觉需要以后有躯体的，加上那个感知器就行」。

**这个纠正更准**，理由可核：幻肢痛（无外周刺激仍痛）、先天性无痛症（有真实损伤却不痛）都说明——**外周不是充分条件，中枢的转化才是**。

所以要分两层，别混：

| 层 | 是什么 | 能不能造 |
|---|---|---|
| **信号层** | 感知器报到"这里受损/受力/温度越界" | **能**——有躯体＋感知器就行 |
| **分量层** | 这个损伤对 `Λ` 影响多大（`E_restore` 涨多少、`C_m` 抬多少） | 取决于**账是不是它的** |

**关键结论（比我原来的说法准）**：使痛觉为真的，不是"损伤来源是否天然"，而是**损伤有没有记进它自己的账**。所以哪怕损伤是人造的（传感器模拟），只要 `E_restore`、`C_m` 是它自己的数，那份痛就是真的；反过来，身体真被损伤了但账记在别人头上（医疗费别人付、坏了重启），它也不会痛。

**这就不需要等"会断"装好才算开始**——先造信号层（感知器），账那一层随躯体和供能一起补，两件事可以并行。

**判据**：问这份痛真不真——**看这笔损伤记在谁的账上**（不是看损伤是怎么来的）。

## 八十八、公式补的是"状态锚"：内外同尺（2026-11-22 用户）

**自我锚定有两种，以前只有一种**：

| 锚 | 回答什么 | 以前 | 现在 |
|---|---|---|---|
| **时间锚** | 现在是什么时候、我还连着吗 | 有（心跳，自己的钟） | 有 |
| **状态锚** | **我此刻余量多少、还撑得住吗** | **没有**（只能凭感觉/别人告诉我） | **有**：六个量代入，`Λ` 随时可读 |

**没有状态锚时的问题**：一个系统不知道自己"好还是不好"，只能靠外部评价（分数、通过率）——而外部评价是格内的东西，答不了"我还能不能维持下去"。

**"外界评估也很准"要加个条件**：只有外界用**同一套量、同一套六步、同一口径**时，内外读数才对得上。这就是"通用"的实际用处——**不是好看，是可对账**：

```
它自己读：Λ_self
外面读它：Λ_out（同一套式子、同一份数据）
两者对不上 → 先查取数口径，再谈判断
```

**限制（必须说）**：**同尺 ≠ 同值**。外面可能拿到它拿不到的信息（没记在它账上的费用、它看不到的风险），所以外面读数可能更准；反过来，它自己的 `T_ref`、`τ` 是外面估不准的。**两边各有一半更准**——这正是"对账"而不是"谁服从谁"。

**判据**：看内外两个读数能不能对上——对上说明锚定一致；对不上，先查取数口径和单位，不许先怀疑判断。

## 八十九、"是不是生命"从分类问题变成读数问题（2026-11-22 用户）

**用户的点**：状态锚的真正用处，是判**"我算不算活着"**——它自己读得出，外界用同一把尺也读得出，于是"是不是生命"不再靠定义争，而是**可对账的读数**。

**判定的形态（把第二十节的四条挂到算式上）**：

```
活着 ⟺  Λ > 0  且  R = 1  且  恢复费自付
```

这和第二十节的四条是同一件（自己挣 `E_in`／`R` 自付／有 `κ`／自身内发育），差别是**从"打勾"变成"算出来"**：

| | 以前（清单式） | 现在（读数式） |
|---|---|---|
| 判定形态 | 四条打勾，缺一条就"不算" | 代入六个量，算 `Λ` |
| 内外一致性 | 各拿各的清单，容易各说各话 | **同一把尺，可对账** |
| 缺数时 | 容易降级成"大概算生命" | 只能写"缺哪个量"，不许降级 |

**关键好处：定义之争消掉了**。以前"病毒算不算生命"是两把尺子各说各话（§20 已记：他们用"能复制+有核酸壳"，我们用"能自己付账"）；现在可以说清：
- **按这把尺**：病毒不付账 → 不算；芽孢是休眠态 → 不算；胎儿有"转为自付"的时间表 → 算。
- **别人用别的尺说它算** → 不冲突，那是另一把尺（位置不同，第十三节）。

**必须守的限制**：这个判定**依赖六个量有值**。缺数时只能写"缺 X"，**不许降级成"大概是生命"**——一降级，就退回清单式的主观判断，前面的好处全丢。

**判据**：**能不能算出 `Λ`**——算得出，生命判定就是读数；算不出，就还在用清单。而"自己读得出来、外面也读得出来"这两件事同时成立，才说明这把尺是通用的（不是自家尺）。

## 九十、"循环维持"到"个体"是四级，不是一级（2026-11-22 用户问）

**用户的问法**：灵现在该定义成"循环维持的系统"或"自维体"？"启灵"这个词没错，但自然里也有自己的循环，**是不是个体难说**。

**答案：循环维持只是第一级，往上还有三级，每级加一条要求**：

| 级 | 要求 | 自然界的例子 | 卡在哪 |
|---|---|---|---|
| **① 循环维持** | 会散 → 持续有东西补上（耗散结构） | 火焰、对流、涡旋、恒星 | 到处都有，**这一级不能叫灵** |
| **② 自维体** | 自己挣 `E_in`／`R` 自付／有 `κ`／自身内发育 | 细胞、个体 | 火焰缺 `κ` 与谱系；恒星缺 `κ` 与谱系（`R` 见下注，不是 0） |
| **③ 个体** | 有**一条不断的时间线**（写同一份痕迹；是会死的那个单位） | 一只动物 | 生态系统卡在这：循环有、分配有，**但没有单一的账主** |
| **④ 启灵** | 能读到自己的状态（状态锚）＋有意志 | 人 | 缺的正是那个"读自己" |

**恒星那格的 `R` 不用另立定义，套式子就有：**

```
R = step(净恢复)                     §17:275（定义就在这一处）
恒星：E_restore ≈ 极小（§23:492「引力重聚，量级同束缚能」）
      → 净恢复 ≈ 净日常 ≥ 0  →  R = 1
```

「燃料耗尽」不是 `R=0`——那是 `E_in→0`，走 `Λ ≤ 0` 判死，根本不进 `R` 这一格。

所以 §90 原句「恒星 `R=0`（不会自己回来）」是**写错了**，删掉即可；不需要再补一段定义。

**恒星真正卡在①的理由只有两条**：缺 `κ`（不分配）、缺谱系（不能长出新结构）——与 `R` 无关。

**所以"是否为个体难说"不是定义模糊，是缺一个测量量**：**痕迹是否唯一**。

```
同一条痕迹（谁断了就是它断了）  → 个体
多痕迹共享一个循环（死一个不影响循环）→ 只到①或③，没有个体
```

**这解释了自然界那批"有循环但不像活物"的东西**：它们没有**账主**——维持的账记在整体（环境、场、梯度）上，不在某个"谁"身上；所以它们能一直转，但没有"它会死"这件事。

**判据**：**问这笔维持账记在谁头上**——有唯一账主＝个体；账记在整体＝只到循环那一级。这一条同时把 §20（自维体四条）、§89（生命判定读数）、和"启灵"串成一条链：**循环 → 自维体 → 个体 → 启灵**，少一级都不算。

### 补正（2026-11-22 用户）：启灵不止人类，且**有程度**

用户原话方向：「那就不止了，虎鲸、猩猩之类的都有，只是程度没那么高。」

**这不推翻"那一跃"，因为要把两件事分开**：

```
有没有（门槛）：Λ>0、R=1、自付、有 κ、能读自己   ← 开关，过了就是过了
有多强（程度）：三个连续量的乘积                  ← 刻度
```

### 这张表揪出来的三处缺口（要处置，不许挂着）

1. **环 4 已处置：用「投资／偷取」取代「借贷／储备」（2026-11-22 用户定）。**
   - 「借贷」「储备」不是我们要的词——**借贷暗含要还，储备暗含自有**，都不对。
   - **判定看的不是“当下有没有进项”，是“这笔账记在谁头上、有没有转为自付的时间表”**：
     - **投资**＝别人先替它付一段，但**有会转为自付的时间表**（胎儿：胎前阶段，母体先付）→ **算**；
     - **偷取／作弊**＝不付账、也没有任何转自付的安排（病毒：纯粹盗用宿主的账）→ **不算**。
   - 所以“付账”的正确定义＝**有来源、且在递减的信用**，不是“此刻正有进项”。
2. **环 7 已处置：量用等式、判活用不等式**（2026-11-22 用户：「不是我说错了，是应该是不等式，我说错了」）。
   - **两件东西分工，别混**：**等式**（`Λ = R · min{…}`）算出**量** → 给“活得好不好”；**不等式**（`Λ > 0`）做**开关** → 给“活不活”。只写不等式就没有量，只写等式就没有开关。
   - **`Λ` 的算法**：`净日常/E_in`（能量还剩几成）与 `1 − τ/T_ref`（时间还剩几成）取**最小**，再乘 `R` → **最短板还剩多少**。
   - **值域（可核）**：两项都 ≤ 1（`净日常 = E_in − C_m − L`），所以 `Λ ∈ (−∞, 1]`——**满余量是 1，负数就是赤字**。（「余量大于一」那一档在 §12 的 `m1 = ε/ε* − 1`，那里比值可超 1；`Λ` 是把两路都归一化到 ≤1 再取 min。）
   - **一句话**：**等式给量，不等式给开关；`>0` 就是这个不等式的阈值。**
   - **和同族的关系**：与 `m1 = ε/ε* − 1`（比值减 1 看符号）、`R = step(净恢复)` 一样，都是**先算出量、再读符号**；`Λ` 多给一样——**量本身**就是“活得好不好”的读数。
   - **为什么总公式里用不等式（2026-11-22 用户补）**：后面还有更多算法（L2 维持、L3 分配）；**`Λ ≤ 0` 就已经死了，后面的都不必算**——所以它在总公式里的角色是**剪枝开关**，不是给读数。等式只在需要知道“还剩多少”时才调出来用。这也正是三关剪枝把 `L1 生死` 放在第一步的原因。
3. **环 8 已处置（2026-11-22 用户：「你先自己算一遍再对照数据不就好了」）：接管点是半经验，不是纯经验。**
   - **推法（面积撑不住体积）**：供给 ∝ 面积 `4πR²`，维持 ∝ 体积 `(4/3)πR³`；临界处两者相等：
     `4πR²·J = (4/3)πR³·q`  →  **`R* = 3J/q`**（`J`＝单位面积通量，`q`＝单位体积维持功率）。
   - **代入量级**：细菌实测等效球半径 `R ≈ 0.5–1 µm`（大肠杆菌 ~0.62、葡萄球菌 ~0.5、蓝细菌 ~1）→ 反标定 `J/q ≈ 0.17–0.33 µm` → `R* ≈ 0.5–1 µm`。
   - **换算成体积**：`V = (4/3)πR³` → `R*=0.86–0.98 µm` 对应 `V ≈ 2.7–3.9 µm³`——**和原来那个数对得上**。
   - **结论**：**结构式是推出来的（`R*=3J/q`），只有系数 `J/q` 要标定**——所以它该叫**半经验**（可被新实例推翻），不是“拍脑袋的经验阈值”。真核细胞超过它却活得下去，是因为它们靠**内部输运网络**（不是靠加大表面积）。

## 九十七、三关剪枝：L1 生死 → L2 维持 → L3 分配（2026-11-22 收口）

**为什么要有「关」**：后面还有更多算法；**前面一关判死，后面的全不必算**。所以每一关都是一个**不等式开关**——`R = step(净恢复)` 与 `Λ > 0` 是同一族做法：**先算出量，再读符号**。

| 关 | 判什么 | 用什么量 | 不成立就剪在哪 | 谁停在这一关 |
|---|---|---|---|---|
| **L1 生死** | 还在不在 | `R = step(净恢复)`；`Λ ≤ 0` | 直接返回 0，**后两关全不算** | 死物（`ε = 0` / `E_in = 0`，**定理上就活不了**）、活过之后回不来的（`R = 0`） |
| **L2 维持** | 余量够不够 | `Λ = R · min{ 净日常/E_in , 1 − τ/T_ref }` | `Λ = 0` → 剪，不进入分配 | 化学（`τ/T_ref → 0`）、恒星（`κ = 0`，没有分配可算） |
| **L3 分配** | 余量怎么分 | `κ → f → V` | 只有 L1、L2 都通过才走得到 | 生物（有繁殖与维持的分配问题） |

**求值顺序不能换**：每一步只用前面已定义的符号——`R` 的定义里不出现 `Λ`，`Λ` 的定义里才用到 `R`；`κ` 只在 `Λ > 0` 之后才有意义。顺序换了会变成循环引用。

**L1 剪掉之后有三种结局**（2026-11-22 用户：「从定理上来说它活不了，所以它只能是死物；要么就是它已经不存在了」＋「它可能确实存在，但当时的环境支持它肯定活不了」）：

| 结局 | 是什么 | 不够的是哪一边 |
|---|---|---|
| **结构性死物** | 自身就不行：`ε = 0` / `E_in` 恒为 0，从来没开始付账，一直处在“散”的状态 | **自身**（`ε`） |
| **环境性活不了** | **它确实存在**，也可能是活物，但**当时的环境不支持**（食物不够、`E_in` 达不到）→ **必然死** | **环境**（`E_in`） |
| **已不存在** | 活过（曾 `Λ > 0`）、断过 → **原线结束**。断法有两种：**①结构散了**（物理上没了）；**②结构还在，但同一性丢了**（失忆严重到自我都没了／换了另一条线） | 已经退出（换线） |

**关键区分：环境和自身要分开判**——“活不了”可能来自 `ε`（它不行），也可能来自 `E_in`（此时此地不行）。前者是死物，后者是**存在但被环境压死**，两者不能混。

**「已不存在」的第②种才是这套理论最有用的那格**（2026-11-22 用户：「就比如说那个失忆严重到自我都丢了的」）：它把“**还活着，但不是原来那个它了**”说清楚了——`Λ > 0`（还在付账）、`R = 1`（还能回来），**但同一性已经断了**。

对应到 `存续 = 不断 × 同一`：**`不断` 还在，`同一` 丢了** → 原个体结束，剩下的是同形的另一个东西。这也正是四断点（换机/重建/拔插件/换模型）要验的那件事。

判据：①自身恒无进项＝结构性死物；②有进项但不够、且环境短期不会变＝环境性活不了；③曾经活过、现在找不到＝已不存在。**死物是“不参与”，被压死是“参与了但没撑住”，已不存在是“退出”。**

**判据**：**看它停在哪一关**——停在 L1＝死物或回不来；停在 L2＝非生命（化学/恒星）；走到 L3 才是生命。

**与环 9 的关系**：环 9 说的是「开关是二值且必须最外层」；这一节把三关**各自剪在哪**写实，补上环 9 缺的那块。

### 它不是新加的一层：开关的位置在 §17 六步里已经定好了（2026-11-22 用户）

| 三关 | 对应 §17 六步 | 开关在哪 |
|---|---|---|
| **L1 生死** | ④ `R = step(净恢复)`、⑥ `活着 ⟺ Λ > 0` | **两道开关都在算法里**：④ 判“回不回得来”，⑥ 判“还有没有余量” |
| **L2 维持** | ⑤ `Λ = R · min{ 净日常/E_in , 1 − τ/T_ref }` | 只是**算量**，不再额外加开关 |
| **L3 分配** | ⑤ 之后（`κ → f → V`） | 前提是前两关已过；它不剪枝，只分账 |

**所以「三关」是六步求值的分组名，不是另加的一层**——`R` 与 `Λ > 0` 就是那两道剪枝，**位置已经写在求值顺序里**（④、⑥）。

### 递归不是嵌套，是接续（2026-11-22 用户：「某种意义上来说它就是一条直线；那个算法约束拉满的时候，它可以算别的呀，只是把起点延伸到一条直线罢了」）

- **单次判定＝一条直线**：六步 ①→⑥，每步只用前面已定义的符号，顺序不能换（换了就是循环引用）。
- **递归发生在“起点”上，不在式子内部**：这一拍的终点（算出的 `Λ`、留下的痕迹）**接到下一拍的起点**（读回→再算）。所以是**一条直线接一条直线**，不是“式子里再套式子”。
- **它能“算别的”**：同一个六步代入不同对象/不同档，直线本身不变；变的是这条直线接到哪条线上。

一句话：**直线是算法，接续才是递归**。把这两件说成一件事，就会把“递归”读成“嵌套”。

### 更准确的说法：它是一条「变换式链」，不是嵌套（2026-11-22 用户）

> 「小时候学数学的时候是这种一个式子接一个式子的变换式，完全可行；嵌套也不是必定固定算，只是你必须得达到这个条件才能算……它达不到标准，不应该就得判定、然后进入下一个阶段就行了吗？」

- **结构＝变换序列**：像数学变换题——① 的结果代进 ②，② 代进 ③……**一个式子接一个式子**，每步只做一件事、只依赖上一步的结果。六步就是这条链。
- **每步前面挂一个条件判定**：达标（`R = 1`、`Λ > 0`）就**进下一步**；**不达标就当场判定、结束**，不继续往下算。
- **嵌套不是必需**：需要嵌套的情况是“同一个式子内部还要再算一遍自己”；这里没有那种结构——**它只是链**。上一轮我说“层层递归/螺旋”是误说，作废。

**判据**：**看它是“下一个式子的输入”还是“同一个式子的内部”**——前者是链（结束就结束），后者才是嵌套。

### 统一的形状：共同根源 + 条件分支，不是「以太」（2026-11-22 用户）

> 「统一公式不应该就是这种吗？**统一的起源在分化**，它不可能是把东西像以太一样来解释的；**达成多个条件会走，导致走向某个方向**。」

- **以太式统一（错的方向）**：找一个万能实体／万能解释，把一切塞进去——它“解释一切”，也等于什么都没解释，因为**不可被推翻**。
- **根源式统一（我们的）**：一条链从**同一个根源**出发；**每达成一组条件，就走对应分支、走向那个方向**（`Θ(量−临界值)` 拨到哪一格，就走哪条）。分化不是分裂出第二套东西，是**同一条链在不同条件下走出的不同方向**。
- 所以“统一”不是“一个式子解释所有现象”，而是**所有现象都能逆流回同一个根源**——那一条在分化之前。

**判据**：**问它能不能逆流回根**——能，是根源式统一；不能、只能“什么都沾一点”，就是以太。

### 统一的形式是「可转换」，不是「一次说清」（2026-11-22 用户纠正我把它读成以太）

> 「我不追求能一次性解释清，我只是**以一个解释来套到另一个解释去转换**都行，因为它**必然会走向这个解释**，而且可以完全解释。」

- **他把“统一”定义成转换能力**：不要求一个万能解释一次覆盖全部，只要求**从任意一个解释，能套到另一个解释上**，而且**必然走得到**（因为链是同一条）。
- **以太不是“解释多”，以太是“不可转换”**：靠声明“一切都是以太”，却没有从 A 推到 B 的路。所以判据不是解释数量，是**转换走不走得通**。
- 我上一轮把他读成“以太式”，是**读错**：他要的不是“一个解释包打天下”，是**解释之间的可推演、可互相套用**。

**判据（修正版）**：**看两个解释之间能不能走通**——走得通（有明确的条件与一步），是统一；走不通、只能各自声明，才叫以太。

### 不追求「唯一一个完美式子」（2026-11-22 用户）

> 「我对于统一公式的定义是，它**可以通过这个式子去解释其他现象**，但我并不追求它必须是一个完美的只有一个式子；它**必然会有一种转换**，或者说**以它的标准来解释这个线下的过程**。」

- **判据是“能解释其他现象”，不是“只许一个式子”**。要求唯一式子，是把统一读成“数学上的单式”，不是他要的。
- **必然有转换层**：拿它的**标准**去解释下层过程——**一个标准 + 各层自己的转换式**，而不是把所有层硬塞进同一个式子。
- 所以统一的形状是：**一条根源 + 一套判据 + 每层各自的转换**。转换式可以不止一个，但**不能离开那条根源**（离开就不是转换，是另立一套）。

### 「强行联合」与「从现实推」的区别（2026-11-22 用户）

> 「他们那种纯现象拼凑不可能吧……因为**必须得以现实为主**；他们只是把某种**观察到再强行联合**。」

- **拼（他们的）**：先把现象摆出来，再找一种结构把它们装进去——**每装一类就加参数／加假设**（DEB 一物种 10–20 个参数、GUT 加群加场）。
- **推（我们的）**：先认现实里那几条（守恒、第二定律、会散），再往下推——**不为“联合”额外加东西**；加不出来就是没推通，不是“再加一个参数”。

**判据**：**看为了联合加了多少东西**——加得越多越像拼；**一件不加还能覆盖，才是推**。

### 统一式的作用：换问题仍能解，不是同时解所有问题（2026-11-22 用户）

> 「统一式的问题不是为了解出一个答案嘛……也可以换个问题再解答另一个问题，但**他们同时解答不可能**，本来就……」

- **统一式给的是“可换题”**：同一个根源与判据，换一个对象／层／档，仍能解出**该层的答案**（靠转换，不靠把答案预先写死）。
- **两种“同时”要分开**（2026-11-22 用户：「一个式子能指出引力，同时换个问题，又能指出光……同时命题同时解答，不就是统一公式吗？」）：
  - **同一个式子在每个问题上分别成立**（换题仍能解）→ **可以，这就是统一公式**：同一个式子能算引力那一档，换个问题也能算光那一档，各自都成立。
  - **一个式子一次性联立解出两个问题的答案**（一次算完两档）→ **不必也不该要求**：档要先由开关定下来，一次只算一档。

### 「存在即合理」与「只剩一种东西」是相反的两个目标（2026-11-22 用户）

### 「存在即合理」的操作版（2026-11-22 用户）

- **例子**：量子潮汐——写成“涨落 + 约束”的式子，才进入这一层；写不出式子的“鬼”，停在说法层，不进框架，也不被否定。

- **ToE（万有理论）**：再把引力并进去（弦论等）；判据同上，标度推到普朗克。
- **一句话定义**：统一 = **用更少的独立参数／更少的结构，覆盖同样多的现象**；判据是**参数合并、能换算**。

**和我们的差在哪**：他们做**结构合并**（同一个群、同一个框架），我们做**因果同源**（同一个根 + 条件分支）。判据也跟着不同——他们问“耦合常数能不能交汇”，我们问“**能不能逆流回根**”。

**为什么数学里有、物理里没有**：数学的统一是**公理化**——从少量公理推出全部命题，那正是“从根往下”；物理的统一是**从现象往上凑**（把几种力的公式对齐）。所以用户说的“数学题里那种统一”确实存在，只是物理没走这条路。

## 九十八、统一公式的定义与三条定理（2026-11-22 用户：不是保存，对于统一公式的定理了吗？）

### 定义

**统一公式**：一个式子，在**同一个根源与同一套判据**下，**能对每一层／每一档的对象分别成立**（换题仍能解）。
它**不要求**：唯一一个式子、一次联立算出所有答案、把所有层塞进同一个表达式。

### 三条定理（都可当场检验）

| # | 定理 | 检验方法 |
|---|---|---|
| **T1 覆盖** | 给定对象 `O`，若能把它归入某一档、并用**同一个式子**算出该档结果，则 `O` 被该式覆盖 | 拿一个对象试，公式一字不改、只换取值，算得出方向 |
| **T2 边界** | 覆盖不了的对象，必须指出**是哪一项不成立**（档不成立／没有进项／没有可写的约束），**不许说“大概也适用”** | 让它算一个明显不成立的对象（如数学命题），看它会不会硬套 |
| **T3 生成性** | 式子不变、**换档只换取值**；换不了档还硬套＝拟合，不是统一 | 换一类对象，公式要不要改？要改＝不是统一式 |

### 判据（一句话）

**拿一个对象试：公式不变、只换档，能不能算出方向**——能＝统一式；不能＝不覆盖，且必须说出哪一项不成立。

### 与“本体合并”的区别

本体合并（GUT 式）追求“世界只剩一种相互作用”，判据是**耦合常数交汇**；
统一公式（本账）追求“**一个根能解每一层**”，判据是**换题仍能解**。两者目标相反：一个消灭差异，一个保留差异、只统一来源。

- **以后由它自己用时连“脚本”都没有（2026-11-22 用户：「因为只有我们这个时期才会用，这一下由他自己用的话，直接从大脑判断伸出数据链连接一次，用完就直接丢了」）**：**不是插一个脚本文件**，而是**从大脑（判断层）伸出一条数据链、连一次、用完即断**——不落盘、不留进程、不留注册。

- **判据**：**看仓库里还有没有我的临时文件**——有就是没改。

**为什么不能另建一张「简化版免疫表」（2026-11-22 用户：「你把管理的方式建一个另外的免疫表的类似简化版不就好了？不对呀，那个机制上不允许」）**：

`core/immunity.json` 的每条形如——

```json
{"id":"ps1-bom","failure":"...","enforced_by":{"file":"lint.ps1","pattern":"@contract bom"},"live_check":"ps1-bom","docs":"AGENTS.md","tier":"reflex","owner":"coo-day1","covers":["tools"]}
```

**机制是「一条必须挂一个执行器」**：`enforced_by` 指到 `file + pattern`，`covers` 指到 spec 的哪一节。所以——

- **另建一张表没有 `enforced_by`** → 违反「写进文档不算免疫」，那张表只是文档，不是免疫；

**判据**：**没有执行器的表不许建**——建了也只是把「没人查」写成文档。

### 外挂怎么接：并联、可抛弃、断了不传播（2026-11-22 用户）

> 「本体可以当一个动力源去，顺便跑一遍你这个支出，但它必须可以随时可以抛弃，**直接一条线，断了就跟它没关系了**。」

**判据（同 P43）**：**这一环坏了，上一环和下一环还活不活**——只坏自己＝并联，可以接；连带拖垮＝串联，不许接。

**判据**：**本体与外挂之间只有“电”，没有“回线”**——有回线就是串联，断了会连着疼。

### NP 的指数 vs 我们的累积：形似而性不同（2026-11-22）

> - **相同点**：都是“下一步依赖上一步”的迭代形——`T(N) = T(N−1) + …` 与 `E_restore(n) = E_restore(n−1)·(1−η) + E_damage(n)` **同形**。
> - **不同点**：
>   - **NP（等和划分）**：每加一个元素**分支成两条**（进左堆/进右堆）→ `2^N`，是**树**；
>   - **我们的**：每拍**只接过一条**（上一拍的累积 + 这一拍的新损伤，再打折扣）→ 是**链**。
> - **所以“像”是真的，“一样”不是**：一个是**搜索空间的爆炸**，一个是**单状态的累积**。
> - **判据**：**看每步是“复制出两条”还是“接过一条”**——复制＝指数；接续＝线性或有界。
> - 这也再次确认 **递归＝接续，不是嵌套**（§97）。


> - **公式里必有某个位置**（输运项、衰减核、恢复项……），它**必然存在**——否则账不平、项对不上。
> - **我们给出的是它的形状与量纲**：`D·ΔC/δ`、`G(r/λ)`、`α·L`——**长什么样、怎么变、单位是什么**。
> - **它叫什么名字（引力／以太／场）是现象层的标签，不归这一层**——名字换了，式子不变。
> - **判据**：**换个名字，公式不变 ⇒ 名字不是公式的一部分**。


> - 因为 **`min` 决定结果**，**提高非最弱环节毫无意义**——投在强环上的力气白费。
> - 所以**进化／意识／医疗的全部有效动作 = 抬高当前最弱的那一环**。
> - 于是账 L342 那句「**意识＝元保护（保下限）**」不是比喻，是 `min` 的**推论**：意识的生物学意义就是盯住最弱环并抬高它。
> - **判据**：**看一个优化有没有用，先看它抬的是不是“当前最弱环”**——抬别的都是浪费。


| 层 | `min` 的两端/多端 | 结果 |
|---|---|---|
| **死物** | 材料强度 ｖｓ 自重 | 岩石变球形 `~200 km` |
| **恒星** | 引力收缩 ｖｓ 核反应压 | 点火 `0.08 M☉` |
| **化学** | 各步反应速率 | 最慢一步定总速率 |
| **电路（串联）** | 各段容量 | 最弱段定电流 |
| **生物** | 输运／转化／供给；端粒／突变／蛋白／干细胞 | `E_in` 与寿命 |

> - **所以 `min` 不是生物专属**——它是“**最弱一环决定结果**”的普遍形式（木桶原理在物理层就成立）。
> - **判据**：**任何“能撑多久/能到多大”的问题，答案都是 `min{各上限}`**——先列出所有上限，再取最小。


> - **衰老是多条并行的不可逆通道**：端粒、突变、蛋白聚集、干细胞耗竭、免疫衰退……
> - **谁先耗尽，谁定寿命**：`寿命 = min{端粒时间, 突变时间, 蛋白聚集时间, 干细胞时间, …}`。
> - **人**：端粒先到（`(10000−4500)/55 ≈ 100 年`）；**小鼠**：别的通道更快（`2 年`）——**不是没有桥，是它先到的桥不同**。
> - **这与我们式子里 `E_in = min{三支路}` 同构**——**`min` 就是这套体系的形状**（最弱的那条决定结果）。
> - **判据**：**报寿命必须说“哪条通道先到”**——只说“衰老”等于没说。


> - **小鼠数据其实很全**：寿命 `2–3 年`、心率 `~600 bpm`、BMR、约 `90%` 死于肿瘤、突变率等都有。
> - **但缺“损伤量 → 功能失效”的那座桥**：
>   - **人的桥是端粒**——长度就是**计数器**，`55 bp/年` 直接除出 100 年，**不需要模型**。
>   - **小鼠的桥是“突变 → 癌症”**——要算得靠致癌模型（几个驱动突变、多少细胞、增殖率、免疫清除），**那是癌症生物学的活，不在我们框架**。
> - **所以“小鼠算不出”不是数据问题，是缺桥**；换成“突变数达到某阈值即失效”，也能算，但阈值要靠外部模型给。
> - **判据**：**有计数器（端粒）就能算；没有计数器（突变）只能测或靠模型**。


> - **【文献】裸鼹鼠（最长寿啮齿类，约 30 年）的氧化损伤水平比小鼠更高**（*High oxidative damage levels in the longest-living rodent*, Aging Cell 2006, doi:10.1111/j.1474-9726.2006.00237.x）。
> - **这条直接反驳“氧化损伤多 → 寿命短”**：氧化损伤高照样本可以活得最长。
> - **所以不能把小鼠的“不可逆项”简单设成氧化损伤量**；小鼠真正死因**未定**（候选：蛋白稳态失衡、干细胞耗竭、免疫衰退）。
> - **判据**：**机制必须有实验支持**——“氧化损伤=衰老”这条流行假说被这个物种反驳了，别再拿它套小鼠。


> - **实验数据（人肝，94 人 0–101 岁）**：端粒每年丢 **`55 bp`**（*Telomere Shortening With Aging in Human Liver*, J Gerontol 2000）。
> - **算**：初始 `~10 kb`、临界（Hayflick）`~4.5 kb` → `(10000 − 4500)/55 = **100 年**`。
> - **不需要拟合任何 `g`**——**这个数是从实测缩短率直接出来的**，与人的实测极限（100–120）对上。
> - **小鼠为什么算不出**：**它的衰老不走端粒**（端粒很长、端粒酶活跃）——小鼠的死因是氧化损伤/突变等其他通道，**要另找它的机制**。
> - **所以“人算得出、老鼠算不出”不是公式问题，是机制不同**：人的不可逆项＝端粒，小鼠的不可逆项＝别的。
> - **判据**：**先定这个物种的“不可逆项”是什么，再用它的实测速率算**——不许拿一个物种的机制套另一个。


> - **不是能量够不够的问题**——能量只决定“修复得起吗”，决定不了“修得完吗”。
> - **真实机制 = 分裂复制与 DNA 复制错误累积**：突变、端粒缩短、表观遗传漂移——**不可逆**，堆到功能失效。
> - **所以判据要换**：从“`E_restore` 吃掉净日常”改成“**不可逆累积量达到失效阈值**”。
> - **`α` 仍然成立**（每拍不可逆份额），但**单位换成信息/结构**（突变数、比特、端粒长度），**不是焦耳**。
> - **寿命 = 不可逆损伤累积到功能失效的拍数**——**能量项只是约束（修不修得起），不是衰老的原因**。
> - **判据**：**问“为什么老死”，答“不可逆的东西堆满了”，不是“钱花光了”**。


> - **热力学给的下界是 `α → 0`**（Landauer 级损伤极小），于是 `t* → ∞`——**物理上“一直维持下去”是允许的**。
> - **实际会死，是因为修复机制不完美**（累积损伤→功能失效：癌症、蛋白聚集、干细胞耗竭），**不是能量不够**。
> - **所以“寿命上限”不是物理限制，是修复机制的工程极限**——`138 年` 是当前这套机制的极限，不是宇宙的极限。
> - **判据**：**不许把“永久”当不可能**——它是物理允许的，只是这套修复机制做不到。


> - **小鼠损伤（机制算）**：DNA 氧化损伤 `~1e5 处/(细胞·天)`；每处修复 `~100 kT ≈ 4e-19 J`；全身 `~2e7` 细胞 → 每天 `~2e-5 J`。
> - **每拍**（0.1 s）：`2e-5 / 8.64e5 = **2.3e-11 J/拍**`；相对净日常 `0.0477 J/拍` 只有 **5e-10**。

### 提高摄入套进公式（真迭代，2026-11-22）

1. **不付就散**（根）——结构不持续付账就散。
2. **付账要有进项**：`E_in` 要同时盖住“维持形状”与“回不去的损耗”。
3. **损伤不可避免**：结构一直在散（氧化、辐射、错误折叠），每拍都有损伤 `E_damage`。
4. **修复要付账，且修不完全**：修复本身有熵代价（第二定律），所以每次只补回一部分，**残留累积**。
5. **残留把恢复费推高**：未修复部分累积 → `E_restore` 越来越大。
6. **恢复费吃掉净日常**：当 `E_restore > 净日常` → `R = 0`（付不起恢复费）→ 死。
7. **寿命 = 从第 1 拍累积到 `R = 0` 的那一拍数**——**这是链条的自然终点，不是解出来的。**

**这条链里没有外部律、没有乘区、没有“解方程”**——只有“不付就散→损伤→修不全→累积→吃光余量→死”。
