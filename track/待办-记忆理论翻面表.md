> 目的：把主流正面主张逐条翻面，看哪些翻得动、哪些翻不动。
> **翻不动的才是本质；翻完能兑现的才是证据。**

## 表的列

| 列 | 内容 |
|---|---|
| 主张 | 主流那条说法（一句话） |
| 正面朝向 | 它怎么讲「才能成立」 |
| 翻面问法 | 「什么时候等于没有 / 何时不成立」 |
| 能翻吗 | 是 / 否（否 → 硬骨头，标出来） |
| 翻完能兑现吗 | 有没有被事实撞上过（有则写下事故） |
| 他们盲区 | 这条主张量不到什么 |
| 我们能补吗 | 补了之后他们的评测能不能测出来 |

## 筛选规则

```
只收「正面朝向」的主张（怎么成立）
反方向的不用收 —— 它本来就在反面
```

## 产出判据

```

翻完兑现     → 证据（记事故编号）
```
