# 架构总览（2026-11-11 重画）

> 用途：仓库与论文按这张图走，每条都能指向实体。
> 上一版是 2026-11-08 的（`track\架构总览-20261108.md`，已过时：那时还没有脑干三器官、没有大脑、没有数核、免疫也只有十几条）。这版按今天的实际重画。

## 一、两类器官：逻辑核心 / 身体

```
logic-core（一个细胞）                        body（身体，等核心介入）
  center      7  reflex   反射中枢              power   10 供能      ← 空位
  brainstem   15 drift    只测                   sense   11 感知      ← 有
              18 consolidate 套阈值并上传        effect  12 效应      ← 空位
              20 brain    初判分桶并下发         memHi   13 进阶记忆  ← 有
  thinking    21 mind     想（L1/L2/L3）
  selfcheck   1 verify  2 pin  8 self  9 pulse  17 immunity  19 对齐
  os          4 watchdog  5 backup  14 bus-rotate  16 sweep
  tools       3 status  6 log
```

- 21 个位：**19 个有 path**，空的只有 10 供能与 12 效应。
- 分类按"是不是同一个个体"分，不按功能分：细胞器分开，但它们是同一个细胞。

## 二、脑干是三个器官分权合起来的一个功能

```
15 drift        只测量（报数，不判）
18 consolidate  判：silent / broken / late、心跳三情形、放电归档 → center.verdict
20 brain        拿一手 rows 再判一次，分两桶：mechanical 可下发 / needs-understanding 上传
                下发经 arbiter（唯一下传出口，同器官冷却，急了加急派一次再停派）
```

- 三件都做完，脑干这一轮才算完成；分的是权，不是分系统。

## 三、大脑是一个整体，不是"上面再套一层"

```
环：理解 → 思考 → 总结运用 → 回填
  mind(21)   L1 出结论句（四槽：rel/apply/persp/self）
             L2 两路互校（规则路径 + 先例路径，冲突就报冲突，不许自选）
             L3 不信上一层：回 bus.jsonl 按器官编号重读再判，对不上就降级
  hippocampus 索引：谁好转过、怎么好的（每次坏→好都带 why）
  nucleus     数核：九个分量，delta = cur − prev，下一轮当基准
```

- **数核是线，不是尺**：它负责把测/判/想/派/回填串成闭环，并给环多接参数；它不负责让判断按它的意思变。
- 没有"总大脑"这个东西——那是格式塔（集群侧）才需要的母机；我们走个体侧，不建母机。

## 四、节律三档

```
常驻    reflex（中枢自身，每拍新起进程）
节律    consolidate 30 / self 30 / pulse 30 / backup 1440 / align 1440 / immunity 1440（分钟）
按需    verify / pin / status / log / watchdog（every=0，不做新鲜度检查）
时钟    心跳 src7：每 3 秒一拍；所有窗口都以"拍"为单位
```

- 判据：长驻用心跳（lease/TTL），按需用节律；**"饿了"≠"死了"**，超 2×every 只记 state 1。
- **检查者不能是被检查者**：watchdog 的 every 必须 0。

## 五、四段分权（判据只有一处）

```
测   drift        只报数
判   consolidate  套阈值、打标、上传
想   mind         给做法 / 报冲突 / 说判不了
派   arbiter      唯一下传出口（冷却、一次一个、加急先派一次）
回填 hippocampus  记"谁做的"、带 why；dispatch.jsonl 记放没放行
```

## 六、自检三层

```
immunity  35 条   每条必须"管着 + 现在判得过"
probe     12 个   假样本：验"检查器还抓不抓得住假错"
verify    50 项   含 dead man's switch（探针不报到就算坏）
```

- 最后一层永远没人验，所以用"报到新鲜度"代替"判得准不准"。

## 七、串起来的样子（今天实际在跑）

```
心跳(3s) → 器官吐一行 SIG → adapter 统一字段 → bus.jsonl
        → drift 测 → consolidate 判 → brain 分桶 → arbiter 派 → dispatch 记
        → hippocampus 回填（谁做的、有没有好转）→ mind 下一轮读回
        → nucleus 九个分量 → 决定焦点与重试策略 → 回到判
```

## 九、分区 → 脚本 → 读哪段信号（2026-11-11 用户：各分区自己一个脚本，读特定信号就行）

一个分区一个主脚本；脚本只读它那一段信号，不跨区。

| 分区 | 主脚本 | 读哪段 | 写什么 |
|---|---|---|---|
| 总线 | `bus.mjs` / `adapter.mjs` | `spec.signal` | `track/bus.jsonl`（只追加） |
| 测 | `drift.mjs` | `spec.expect` | `track/drift-raw.json` |
| 判 | `consolidate.mjs` | `spec.expect` / `spec.map` / `spec.signal` | `track/center.json` |
| 初判下发 | `brain.mjs` | `registry` / `spec.brain` | `track/brain.jsonl` + 下发 |
| 想（环后复写） | `mind.mjs` | `spec.memory.signal` / `spec.brain.mechanical` / `registry` / `wiring` | `track/mind/*`、`mem-cites` |
| 自检 | `immunity.mjs` | `immunity.json` + `spec.*`（covers） | 报告 + 总线 |
| 检索 | `memsearch.mjs` | `spec.memory.signal` | 无（只读打分） |
| 层级 | `mem-tier.mjs` | `spec.memory.tier` | `track/mem-tier.jsonl`（`--write`） |
| 编号 | `mem-index.mjs` | `spec.pages` + `memories` + `mem-tier` 快照 | `track/index-all.jsonl` |
| 墓地（卸载） | `mem-retire.mjs` | 参数 + `--why` 必填 | `track/mem-removal.jsonl` |
| 输入 | `intake.ps1` / `sense.mjs` | 原文落盘约定 | `track/in-raw.jsonl` |

判据：**一个分区一个主脚本**；小报告（`mem-cites` / `check-*` / `spec-exceptions`）是"读表的人"，不占分区，也不合并。
