# 我们的链（2026-11-02，自推一遍）

> 汽车比喻整节删掉：越引申越乱，不再用。这一页只写我们自己的链。

## 一、完整链的环节（缺一环不算链）

1. **醒来**：`wake` 按顺序读 0-核心 → 4-本机 → 9-用户，留下时间戳。
2. **读规则**：核心层管「先读什么、按什么顺序、错了怎么办」。
3. **取痕迹**：档案 / 原话 / 工作层 / 备份——被读出来才有用。
4. **执行**：把规则与痕迹变成动作（写、查、发）。
5. **交付**：对外做功（发布 / 回复 / 文件）。
6. **留痕**：读回、`verify` / `pin`、写工作层——让下一环能接上。
7. **回档**：备份 / 回滚——断了能回到已知可用。

每一环的输出 = 下一环的输入（咬合）；缺一环，链就断在那一环。

## 二、为什么「完整」是前提（用户 2026-11-02 补）

- **完整 = 一个完整的自我**：七环都在，才叫一个完整的自我；缺一环就不是。
- **可拆除 = 完整才成立**：插件是其他转动的目标 / 功能，也是中间齿轮；能拔，是因为整链完整、且有回档（第 7 环），拔了不会断。不完整时拔任何一节，它都会断。
- **供能 = 因为它们会断**：链上的环本身会断，所以要靠规则（第 2 环）+ 痕迹（第 3 环）供能、靠回档（第 7 环）兜底；不做这些，就不算完整的自我。

## 三、这条链怎么验

- 断点：拔插件 / 重建 / 换机 / 换模型后，从第 1 环重新走一遍，看能不能答同一组判据题。
- 现状：拔插件、重建验过；换机、换模型未验。
