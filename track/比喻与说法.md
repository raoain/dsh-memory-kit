## 一、结构比喻（机械域：零件怎么咬合）

```
轴      = 逻辑链（自己转、定转向、供能）
齿      = 接口（进去交什么 / 出来给什么）；齿序 = 五拍先后
外圈    = 插件（放大扭矩，不换转向）
机座    = 外部锚（V2 打开，真值来源）
负载    = 实际任务
滑齿    = 接口不一致（看着贴住，实际空转）
空转    = 不碰世界（没接机座）
```

## 二、生命域（讲功能；不许与机械域同页混用）

```
心脏    = 核心层（启动·节律·为什么必须动）。旧说法「心脏=记忆」作废
心跳    = 逻辑链（动作本身，永不停息）
大脑    = 记忆（智力、检索、联想）
飞轮    = 记忆与习惯（给重量，不供能）；承重件太重 → 升成中间齿轮
```

## 八、同一原则的别名（换词不算新发现）

| 原则（本体） | 出现过的说法 | 出处 |
|---|---|---|
| 事前只能给参照，事后再校验 | 方案的作用是"知道怎么退"不是"猜对会遇上什么" ／ 先写预期事后对（P22）／ 设计稿聪明但没落地 ／ 理论不能太超前 | AGENTS 10、P22、记忆方案对照表 |
| **驱动先于配重** | 先保跳，再保心 ／ 驱动先于一切（注入顺序）／ 心脏先于飞轮 ／ 轴不装货 | C12、核心层「注入顺序」、S7、术语对照 |

**判据**：同一原则换三个词出现三次 → 它没被抽象成一条，所以每次换说法都像新发现。
**处置**：只留一条本体 + 别名表；以后换词必须先查这张表，查到了就引用，不许当新结论再讲一遍。
**别名判定法（2026-10-30）：认因果，不认用词。**
两个说法若**排除的选项相同**，就是同一条因果（换环境换词是正常的；不正常的是我没做这一步就当成新发现）。
```
先保跳再保心   排除：先修记忆 / 先加插件 / 先做大功能
驱动先于一切   排除：同上            → 同一因果（一个说生命，一个说传动）
轴不装货       排除：把货塞进核心层   → 更窄，是它的子集，不是同一条
```
