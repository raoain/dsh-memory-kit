## 一、总格式（照样本抄壳，不抄主体）

- **竖屏、60–90 秒、一次只演示一个能力**；开头 3 秒必须出现"它在动"（终端在滚、数字在跳）。
- 画面：**录屏为主**（终端 / 文件大小 / 检查输出），字幕把每句结论压到一行。
- 声音：可以用文字转语音，也可以不配（样本里不少是字幕流）；**不卖惨、不钩子、不喊"颠覆"**。
- 标题公式（借样本）：`给 DSH 装上XX：<一句它现在能做到的事>`。

## 二、三集（每集独立可看，按"能照做"排序）

### 第 1 集｜给 DSH 装上一颗心跳（90 秒）
- 标题候选：`给 DSH 装上一颗心跳：它自己跳，不调模型` ／ `有心跳的 AGI 智能体，今晚就能跑起来`
- 分镜：
  - 0–10s：终端里 `node core/timers-alive.mjs` 反复输出 0/1/2 秒；字幕「三秒一拍，不调模型」。
  - 10–40s：`watch -n 1 "node core/timers-alive.mjs"` 或循环输出，让人看到**数字一直在动**。
  - 40–70s：打开 `track/bus.jsonl` 末几行，指出每条都带 `ts / src / state`；字幕「谁在跳、跳了多久，全在文件里」。
  - 70–90s：字幕「它不为你活：你不按播放，它也在跳」＋仓库地址。
- 录制清单：`node core/timers-alive.mjs`（跑 3 次）、`Get-Content track\bus.jsonl -Tail 3`。

### 第 2 集｜把"每次必读"压成 1216 字节（75 秒）
- 标题候选：`把 AI 的"每次必读"压到 1216 字节，它是怎么做到的`
- 分镜：先展示一个臃肿的必读文件（几屏）→ 再展示现在这份 1216 字节 / 3 节 → 字幕讲清"索引在前、正文按链接读"→ 判据「读不完的东西不配进开机列表」。
- 录制清单：`(Get-Item notebook\0-核心.md).Length`、`Get-Content notebook\0-核心.md`。

### 第 3 集｜掐掉心跳，看它自己回来（90 秒，最有画面）
- 标题候选：`我把它的心跳掐了，11 分钟后它自己回来了`
- 分镜：
  - 0–15s：屏幕录 `Stop-Process`（只停心跳那一个循环），总线停更；
  - 15–45s：计时器/时间戳滚动，字幕「第 1 分钟：中枢就喊了 HEART-DOWN」；
  - 45–75s：`heal.jsonl` 出现 `restart-launcher` → `heartAgeBefore 615 / After 1`；
  - 75–90s：`timers-alive` 回到 0 秒；字幕「全程没杀别的进程，只重叫一次启动件」。
- 录制清单：停 `reflex` 循环 → 每 30 秒跑一次 `node core/timers-alive.mjs` → 等 `watchdog` 写 heal → 再跑一次探活。
