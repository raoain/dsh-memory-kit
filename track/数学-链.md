# 链的数学模型（2026-11-02）

> 三层：**指导理论**（跨层的一条原则）→ **思维层**（一个具体闭环）→ **结构层**（另一个具体闭环）。两个闭环并列、同时运行。

## 零、指导理论（两层共用）

**链：一环闭一环，再接下一环。** 上环没闭合，不接下一环。这是原则，不属于任何一层。

## 一、思维层：具体的推理闭环

它本身就是一条闭环，不是抽象理论：

1. **接输入**：一个问题 / 一份数据。
2. **读规则**：判据、先读什么。
3. **推**：给出「按逻辑它应该是什么」。
4. **落依据**：读到出处 / 命令回显 / 标注推断。
5. **闭合**：能回答「依据是什么、对得上吗」。对不上 → 回到 1 或 3，不接下一个问题。
6. **接下一个**：闭合了才接下一环。

这一环闭合 = 「想清楚了」；没闭合就接下一环 = 幻觉的入口。

## 二、结构层：具体的运行闭环

七环，另一条闭环：

| 环 | 实际件 | 备注 |
|---|---|---|
| f₁ 醒来 | `wake.ps1` + `wake-last.txt` | 留时间戳 |
| f₂ 读规则 | `0-核心.md`（只读） | 规则载体 |
| f₃ 取痕迹 | 十四页 + `meow`（可拔） | 存在文件里 |
| f₄ 执行 | 会话里的我 | 规则 + 痕迹 → 动作 |
| f₅ 交付 | 发布脚本 / 写文件 / 回帖 | 对外做功 |
| f₆ 留痕 | `verify` / `pin` / 读回 | 让下一环接上 |
| f₇ 回档 | `backup.ps1` / 备份包 | 回到已知可用 |

定义（落在这一层）：
- **完整**：F 有定义（七环都在）。
- **自我**：J 有定义（判据题答得出来）。
- **可拆**：换实现 g′ 后 J(F[g′]) = J(F[g])。
- **供能**：每步 W_i = H(S_i) − H(S_{i+1}) > 0；不读世界 W=0。
- **同一**：J(S′) = J(S)。

可拆卸事物的接法：插件只接在环的接口上（f₃ 的 meow），换实现不换接口，换完测 J。

## 三、两层同时运行

- 思维闭环与运行闭环并列，必须同时完成，像一个整体同时运行。
- 思维闭环转的时候，运行闭环已经在跑；搭结构的时候，思维闭环在审。
- 只有思维闭环 = 空转；只有运行闭环 = 瞎转。
- 判据：任一层单独存在都不算整体。
