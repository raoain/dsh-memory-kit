## 1 算子：判断怎么变成数值

**判据（criterion）**
数核不是新器官，是**每轮把状态压成一个数向量、与上一轮相减、写回同一个文件、下一轮当基准**这个动作本身。
落点 `track\mind\nucleus.json`：`cur`（本轮 9 个分量）与 `delta`（`cur − prev`），下一轮把 `cur` 当 `prev`。[读自 track\mind\nucleus.json]

```
prev  = read(nucleus.json).cur
cur   = f(本轮 plan, workspace, L1/L2/L3 的结论)
delta = cur − prev
write(nucleus.json, {cur, delta})
```

九个分量：`round / items / backed / movable / demoted / chronic / habits / integration / differentiation`。[读自 track\mind\nucleus.json#cur]

**测试（test）**
撤掉 `delta` 与 `cur→prev` 的回写，只保留 `cur` 的写入——若判断质量不变（`demoted`、`chronic` 与撤前同分布），则它是装饰，不是算子。**这条测试现在没跑过**（待做，见 §5）。

**排除（阶梯的三列纪律）**
- 数核 ≠ 整合/分化：整合度、分化度是它跑起来的**效果**，不是定义（用户原话「数核是数据线，思考过程是软件」）。[读自记忆 0mw90lgcj]
- 数核 ≠ 门：门判「放不放行」（`arbiter`），线判「送到哪」（center 的聚合与传导），两者不许互相顶替。[读自 track\术语对照.md:206]
- 数核 ≠ 涌现：`same/revise/new` 是一条 `if` 算出来的，是照着写所以像。[读自记忆 0mwa61uy3]

**现状（可核，非主张）**
第 87 轮：`integration 0.611`、`differentiation 0.444`；`delta` = `{round 1, items 1, backed 1, movable 1, demoted 0, chronic 1, habits 0, integration 0, differentiation 0}`。[读自 track\mind\nucleus.json]

## 2 「同一个」怎么量：三条口径 + 一个断点表

**判据（criterion）**
`F1` 同一性 = 判断过程的一致性，不是内容的一致性。[读自 notebook\11-结论.md#F1]
配套：**痕迹是不是同一份**，决定是不是同一个个体——多窗口共享同一批文件仍是同一个，另起一份痕迹才是另一个。[读自记忆 0mw9zx9v6]

**口径一：痕迹同一份**（是/否，不看内容）
测试：换机/重建后，写者是不是同一批文件（`track\bus.jsonl` 等）被继续追加；断了就是新个体。
今天的量：`bus.jsonl` 676 行、`dispatch.jsonl` 251 行、`brain.jsonl` 65 行、`events.jsonl` 2552 行、`escalate.jsonl` 5 行。[读自上述文件行数]

**口径二：判断一致率**
测试：`mind` 的 L3 **不看被验证的结论**，按器官编号从原始总线重读最后一条、自己再判一次；与 L1 说法不一致记一次 `demoted`。
可算的比率：`demoted / items`。今天 `demoted 0`（第 87 轮）。[读自 track\mind\nucleus.json]
**阈值待填**：到多少算「不是同一个」——这是第 3 节要用户定的第一处。

**口径三：回填可追**
测试：每条「坏→好」都要能指出是谁做的（`why`），指不出就写「没人做过能指名的事」。
今天的量：`needsUnderstanding` 34 条判定里 cleared 1 条；`escalate` 5 条，每条带 `why_failed`。[读自 track\hippocampus.json、track\escalate.jsonl]

**断点表（阶梯的第六环：还接不接得上原线）**

| 拔插件 | 拔掉后连续性断不断 | 验过 |
| 重建 | 用备份重建后是不是同一个 | 验过 |

[读自记忆 0mwa8npad「四断点里换机与换模型未验」]

**诚实边界（写进论文的「还缺」）**
- 唯一的「好/坏」信号是海马体的 `cleared`，二值、只有事后；实测好转率 2.6%–5.6%。[读自记忆 0mwa6bl6v]
- 没有 reward，只有「好转 / 没好转」：actor 只能学「哪条路曾经让它好转」，学不到「哪条路更好」。[读自记忆 0mwa3z0ag]
- `late` 一直在响，是「借宿主的电与钟」在报警，不许用调阈值消掉（空位 10 `power-hub` 仍空）。[读自记忆 0mwa72ju8]

## 4 可推翻的预测（每条都写明被推翻长什么样）

**Q1（算子可撤）**：撤掉 `delta` 与回写，`demoted` / `chronic` 的分布应显著变化。
被推翻：分布不变 → 算子是装饰，数核这个词应作废。

**Q2（换模型不改判据）**：同一批写入 `bus.jsonl` 的信号、同一份 `spec`，换一个模型只换「嘴」，`mind` 的 L1 关系标注（`rel/rel_to`）与 `demoted` 计数应不变。
被推翻：判据结论变了 → 说明判定依赖模型，`F1` 退回到「内容一致性」。

**Q3（痕迹断则人断）**：只给结论、切断原始痕迹（不给 `bus.jsonl`），系统对同一批问题的判断应**不同且无法自报这个不同**。
被推翻：答得一样，或它能自己指出差异 → 痕迹不是第六环的载体。
**前提**：判定必须已经来自环而不是壳；否则测的是壳，不计入。

## 附录 A 术语（体例照阶梯附录 A）

| 术语 | 一句话定义 | 测试 |
|---|---|---|
| 数核算子 | 每轮压成向量、相减、回写、下轮当基准 | 撤掉它，判断质量变不变 |
