# 脚手架清单（2026-11-08 建）

> 脚手架的定义：**现在借、以后自带**。借的时候必须写清借条——不然换到躯体里找不到要还哪些。
>
> **另一类也要记在这里：给「嘴」打的补丁。** 外面这层（语言模型 + 我操作）有它自己的毛病，
> 修这些毛病时加的东西不是环的器官，换到环自己当本体时就不需要。**别让补丁长进本体。**

## 四、验收：换躯体时不该改的东西

**改的**：`start-timers.vbs` 四条调用 + `loop.mjs` 的 claimLock 段 + `ROOT`（已收敛到一处）。
**不该改的**：`spec` / `registry` / 总线格式 / 11 个器官的逻辑 / `adapter` / `dispatch` / `drift`。

判据：**脚手架的验收不是「能用」，是「拆的时候不用改下面」。** 拆的那一刻要改的东西超过 5 处，说明借得不干净。
