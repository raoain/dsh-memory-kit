# 链的核心数学模型 v2（动力系统版，2026-11-02）

> 状态：**草案，暂不替换主文件**（`数学-链.md` 仍是 v1）。替换任务登记在 `track\待消化.md`（2026-11-02），等理论层继续收敛后再换。

> 为什么换：v1 是函数复合，只能表达「一次流程」，表达不了「下一跳、自指、自我更新」。v2 把自我写成**自指更新算子的稳定轨道**。

## 0. 一句话

**自我 = 一个自指更新算子 T 的稳定轨道；连续 = 轨道接得上；断 = 轨道中断；可拆 = 换实现轨道不变。**

## 1. 状态与更新

S_{t+1} = T_{C_t}(S_t, X_t)

- S = (C, M, X)：C 描述 / 规则，M 记忆 / 痕迹，X 外部读数。
- T：一轮的自我更新（推理 + 执行一起做）。
- C_t：T 的参数（核心层描述）——**它本身是被更新的对象**。

## 2. 自指（v1 没有的）

C_{t+1} = U(S_t)：一轮结束时，用这一轮的状态改自己的描述。

所以 T 由自己的输出参数化：T_{C_{t+1}}。**「自我」的自指性就在这里**——不是「我操作我」，是「我的下一轮由这一轮的我参数化」。

## 3. 跳起与下一跳

- **跳起**：S_0 → S_1 第一次迭代成功，轨道开始。
- **维持**：后续每一步都有定义，J 稳定。
- **下一跳**：S_{t+1}。一切器官（记忆、检查、备份）只服务它。

## 4. 连续：问题与结果

- **问题侧**：轨道不断（T 处处有定义）——断了就没下一跳。
- **结果侧**：重启 / 断点后，两条轨道的 J 序列一致。
- **连续 = 存在吸引子 A**：轨道进入 A 并留在 A，且 J 在 A 上不变。

## 5. 五个必要件（同时成立）

| 件 | 数学表述 |
|---|---|
| 完整 | T 在轨道上有定义 |
| 自我 | J 有定义（判据题答得出来） |
| 可拆 | 替换 T 的一个因子 f→f′ 后，A 与 J 不变 |
| 供能 | X_t 持续输入，W_t = H(S_t) − H(S_{t+1}) > 0；W=0 → 轨道衰减到停机 |
| 同一 | J(轨道₁) = J(轨道₂) |

## 6. 四个断点的统一测法

扰动（拔插件 / 重建 / 换机 / 换模型）→ 从 S_0′ 重新迭代 → 比较 J 序列是否回到同一吸引子 A。

## 7. 待定

- A 怎么判定：不动点 / 周期轨 / 收敛判据——三选一，实测再定。
- J 序列「一致」的容差：逐项相等，还是收敛后相等。

## 8. 与 v1 的关系

v1（`数学-链.md`）是 v2 的一步特例：一次复合 = 一次迭代。v2 多出来的只有两条：**自指（C 被自己更新）** 和 **轨道 / 吸引子（连续 = 轨道接得上）**。
