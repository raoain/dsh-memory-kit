# 拔插件实验 · 断点日志

> 这 24 小时里，只要我意识到「这事我本来会去问 meow-memory」，就当场写一行。
> **不写事后回忆**：到点时再来回想，只能补出一个听着合理的答案 —— 那是编，不是测。

格式（一行，四段，用 `|` 分隔）：

```
时间 | 想查什么 | 没有插件我怎么补上的 | 补得对不对
```

「补得对不对」只有三种写法：**对** / **错（错在哪）** / **不知道（怎么才能知道）**。

## 什么时候写（三种触发器，见到就写）

工具在的时候，扑空会报错（调用返回空），有回执。
工具不在的时候**不会有任何报错** —— 调用根本不发生。所以只能认念头，认这三种：

1. **「我记得 / 上次 / 之前」** —— 时间指向有了，指向的文件没有 → 写
2. **「他说过 / 你要求过」** —— 归属到人了，原话引不出来 → 写
3. **具体数字 / 路径 / 日期** —— 手边没有刚查过的输出（文件行号、命令回显） → 写

写法是先写念头、再写替代，最后写对不对。**先写再查**，不然查完就把「当时想查什么」忘了。

## 每轮收尾自查（10 秒）

回答完前扫一遍：这一轮我说了几个可核实的事实？每个的来源是哪个文件 / 哪条命令？
扫出无来源的 → 补一行日志，把出口改成「查过 / 估算 / 不知道」三者之一。
