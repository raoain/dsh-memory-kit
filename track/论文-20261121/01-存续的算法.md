# 维护的律：递归如何形成、如何应用 / The Law of Maintenance: How the Recursion Forms and How It Is Used

> 上一篇《存续的律》只给到「最早的公式」为止：进来的一份能量，要同时盖住维持的价钱和回不来的损耗。
> 这一篇接着往下一步走：**这个式子怎么变成一拍接一拍的递归，以及它怎么套到不同对象上**。
> 与上一篇的分工：**律篇答「凭什么必须付账」，本篇答「怎么算这一拍付得起付不起」**。

## 〇、先给结论

一个式子，六步，一拍接一拍：

**六步**：`E_in = min{输运, 转化, 供给}` → `净日常 = E_in − C_m − L` → `净恢复 = 净日常 − E_restore` → `R = step(净恢复)` → `Λ = R·min{净日常/E_in, 1 − τ/T_ref}` → `Λ > 0`。

**一拍接一拍**：`E_restore(n) = E_restore(n−1)·(1 − η) + E_damage(n)`，初值 `E_restore(0) = 0`；**活着 ⟺ 对所有 `n`：`Λ(n) > 0`**。

**代入的是开关，不是换公式**：死物 `ε = 0`，化学 `τ/T_ref → 0`，恒星 `κ = 0` 且 `E_in` 取存量，生物三项全带。

## 一、递归是怎么长出来的（不是设计出来的，是逼出来的）

### 1. 起点不是公式，是一句没有前件的话

真正的起点只有一句：**不付就散**。它没有前件——不是从别的推出来的，是默认：任何有结构的东西，停止付账就会散开。

**公式是它的第一次落地**：`E_in = ΔG_s + Q`（`Q > 0`）——把「付」写成能算的量：进来的一份能量，要同时盖住「维持形状的最小代价」和「回不来的那部分」。

**顺序要看清**：不是先有式子再有「不付就散」，是**先有不付就散，才需要写出一个式子去算它**。这一层里还没有时间、没有恢复、没有开关——**式子只回答「一瞬够不够」**。

### 2. 为什么必须分成「拍」

因为账不是一次结完的。**维持不是发生一次，是一直在发生**：心跳一次付一次、呼吸一次付一次、代际一次付一次。

所以第一处延伸是**加时间尺度**：把「一次」变成「一拍」，进项、维持、损耗都按拍计。于是有了 `净日常 = E_in − C_m − L`。

**这一处不是假定**：`E_in`、`C_m`、`L` 都是"每拍多少"，不是因为方便才按拍算，是因为**它们本来就一拍一拍地在发生**。

### 3. 为什么必须记「还欠着的」

损伤补不回来就先欠着——这一拍付不起，不代表下一拍也付不起；但**欠的部分不会自己消失**，它会**累积**。

于是有了第二个量：`E_restore`。**净恢复 = 净日常 − E_restore**。

**这一处也不是假定**：如果损伤不累积，生物就不需要「恢复」这个概念，受伤一次就永远是那个样子——事实是可恢复、但恢复有代价、而且代价会累。**累积是事实，不是建模选择。**

### 4. 为什么必须有个开关

**付不起就是付不起**，不存在"稍微付不起一点"——那一拍就是没有下一拍。

于是有了 `R = step(净恢复)`：`R` 只取 0 或 1，**在 `R = 0` 那一刻就不往下算了**（后面的 `Λ` 没有意义）。

**开关必须在最外层**：如果先算 `Λ` 再乘 `R`，你会在 `Λ` 里先除出一个假的安全值，然后再把它清零——**顺序反了，中途的数会骗人**。

### 5. 递归在这一步出现

把上面四步按「拍」串起来：

- 第 `n` 拍开始时，手里握着的是**上一拍剩下的恢复费** `E_restore(n−1)`；
- 这一拍又新添了损伤 `E_damage(n)`；
- 旧的会衰减（能自己好的部分）一部分，衰减率记作 `η`；
- 于是 `E_restore(n) = E_restore(n−1)·(1 − η) + E_damage(n)`。

**这就是递归的形态：上一拍的终点，是下一拍的起点。**

### 6. 为什么这叫递归，不叫嵌套

**嵌套**是"同一个式子里再算自己"——这里没有那种结构。

**接续**是"这一条算完了，把结果交给下一条"——我们只有这一种。

判据很简单：**看它是"下一个式子的输入"，还是"同一个式子的内部"**。前者是链，后者才是嵌套。

**所以递归不是花招，是"账要按时结、而且上一拍欠的下一拍接着算"这件事的直接形态。**

## 二、六步逐条：每步的前件、取数、判据

### ① 进项：三路取最紧，再乘流失率

`E_in = η_流 × min{ 输运, 转化, 供给 }`

**前件**：任何一份收入都要经过介质、界面、转手才落到身上；把"理论供给"直接当成到手，是把账记在了没到手的地方。

**三路各是什么**：

| 路 | 卡在哪 | 典型表达式 |
|---|---|---|
| **输运** | 送得进来多少 | `D·(A/δ)·ΔC` |
| **转化** | 结构能处理多少 | `ε·M` |
| **供给** | 环境能供多少 | `S` |

**为什么取最小**：这三路是**串联的容量**——共享同一个通过量，木桶效应，最紧的那一段决定上限。

**为什么要乘 `η_流`**：流失率是串联损耗，连乘：`η_流 = ∏(1 − loss_i)`。漏掉它，`E_in` 会高估 `1/η_流` 倍，`Λ` 就会看起来比实际安全——**系统性把自己算得比实际健康**。

**判据**：**串的是容量，取最小；串的是阻力／损耗，相加或连乘。** 混用会错：`12 V` 串 `5 Ω + 10 Ω`，真值 `0.80 A`，按容量规则算成 `1.20 A`，偏 1.5 倍。

### ② 净日常：这一拍剩多少

`净日常 = E_in − C_m − L`

`C_m` 是维持这份结构本身的支出；`L` 是回不去的损耗。**两者都要减，因为一个是"为了不生锈"、一个是"已经在锈"。**

### ③ 净恢复：再扣掉还欠的

`净恢复 = 净日常 − E_restore`

**先扣日常，再扣欠账**，不能反过来：欠账是过去的，日常是当期的，混在一起会看不出"这一拍到底是新欠还是还旧账"。

### ④ 开关：付不起就短路

`R = step(净恢复)`，`R = 0` 在这里返回，后面不算。

**这一条的价值不是"多一个判据"，是"省掉后面的假数"**：付不起的对象，它的能量余量是多少已经没有意义。

### ⑤ 存续量：两个余量取更紧的

`Λ = R · min{ 净日常/E_in, 1 − τ/T_ref }`

- **能量余量** `净日常/E_in`：这一拍挣的，扣掉花掉的，还剩几成；
- **时间余量** `1 − τ/T_ref`：这一拍已经花了多久，还剩几成。

**为什么取最小**：这两栏也是串联的——**能量够但时间不够，一样维持不下去**；反之亦然。**最紧的那一栏决定成败。**

### ⑥ 判：活着

`Λ > 0`。

**注意这是"过没过线"，不是"有多健康"**：`Λ` 的大小只用来比哪一栏更紧，不用来给生命打分。

## 三、开关表：同一个式子，换档只换「套哪几项」

| 档 | 套哪几项 | 写出来是什么 |
|---|---|---|
| **生物** | 六步全走 | `Λ = R·min{净日常/E_in, 1−τ/T_ref}`，按最紧那项定指数 |
| **恒星** | 无 `κ`、`τ/T_ref → 0`、`E_in` 取存量 | `Λ = 1 − Q/L`（燃料对光度） |
| **化学** | `τ/T_ref → 0`、`R = 1` | `Λ = 1 − (C_m+L)/E_in`（`ΔG` 判据） |
| **死物** | `ε = 0` → 无进项 | `Λ < 0`（只散不存） |
| **数学** | 维持项全用不到 | 只算个数：一个方程，条件成立即在 |

**说清一件事**：**这不是"退化"**——树没缩小，只是**那一枝用不到那些项**。一个对象只在一档，它那一档不需要的项根本不参与计算。

**取数口径要按档对齐**：恒星若用"瞬时流量"口径（产能＝光度 → 净日常 ≈ 0），会算出 `Λ = 0`，**把活着的恒星判成死的**。换成"存量"口径（已烧掉的占几成）才对。**那是取数口径错，不是公式错。**

## 四、三个指数不是三套公式，是三种主导项

同一个 `Λ`，在不同对象上由不同的一栏主导，于是 `M` 的指数不同：

| 主导项 | 指数 | 什么时候主导 |
|---|---|---|
| **输运** | `M^(1/3)` | 送进来的速度卡住（大对象、扩散慢） |
| **面积** | `M^(2/3)` | 表面决定交换（小对象、表面积/体积比高） |
| **需求** | `M^(3/4)` | 维持成本本身随体型涨（Kleiber 那一带） |

**所以看到 1/3、2/3、0.75，不是在看到三条规律，是在看到同一个式子的三个主导项。** 换对象时主导项会换，指数跟着换——**不用换公式**。

**判据**：**数偏了乘因子；趋势反了换指数；该死不死的拨开关。** 三种分化从轻到重，不许跳级。

## 五、`δ = r₀`：几何自己给，不用拟合

输运项里的 `δ`（扩散层厚度）不是自由参数。**球面扩散的经典解给出 Sherwood 数 `Sh = 2`，于是 `δ = r₀`**——`δ` 完全由几何决定。

**这一条的意义**：`R* = sqrt(3·D·ΔC·E_mol·ε / q_vol)` 这类接管点，**不需要拟合任何参数就能算出来**。算出来 `0.87 µm`（带 `ε_cell = 0.53`），与旧记录「主导项接管（体积 2.7–3.9 µm³）」换算的半径 `0.86–0.98 µm` 差 **0–13%**。

**边界**：`ΔC`、`δ`、`q_vol` 都是变化量，各自能飘一个量级，所以接管点会在 `0.1–100 µm` 之间移动——**那一类数只是当期取值的一例，不是常数**。

## 六、走一遍：拿「人」算

| 步 | 取数 | 结果 |
|---|---|---|
| ① 进项 | `E_in = 100.7 W` | — |
| ② 净日常 | `100.7 − 65.6 − 10.1` | **25.0 W** |
| ③ 净恢复 | `25.0 − E_restore`（当期 `E_restore ≈ 0`） | **25.0 W** |
| ④ 开关 | `25.0 > 0` | **`R = 1`** |
| ⑤ 存续量 | `min{ 25.0/100.7, 1 − 0.25 } = min{ 0.248, 0.750 }` | **`Λ = 0.248`** |
| ⑥ 判 | `0.248 > 0` | **活着** |

**瓶颈是能量余量**（0.248 < 0.750）——所以这一档要抬，抬的是进项或维持，**不是时间**。

无量纲写法同一件事：`x = C_m/E_in = 0.651`、`l = L/E_in = 0.100`、`θ = τ/T_ref = 0.250`，于是 `Λ = min{1 − 0.651 − 0.100, 1 − 0.250} = 0.248`。

**能比的条件**：同一个无量纲量 ＋ 同一档口径。四档算下来是生物 `0.248`、恒星（存量口径）`0.540`、化学 `0.500`、死物 `< 0`——**排序正确，所以能比**。

## 八、哪些是借的、哪些是我们的

**借的原件**（每一块都有出处）：

- `E_in = ΔG_s + Q`——热力学能量平衡（第二定律保证 `Q > 0`）；
- 维持 ∝ 结构量——DEB 的 `ṗ_M = [ṗ_M]·V`；
- `N^(3/4)`——Kleiber／West–Brown–Enquist；
- `T_ref ∝ M^(1/4)`——生物时间标度；
- `Sh = 2`（`δ = r₀`）——经典质量传递；
- 生死判据的形态——DEB 那句 "I assume that an individual dies when κ × mobilization rate drops below the required maintenance costs"（**我们借了它「付不起就死」的形态**）。

**我们加的只有两格**：

1. **自锚的钟** `T_ref`（DEB 的时间是外部基本量 `t`）；
2. **二值生死** `R ∈ {0,1}`（DEB 只有阶段阈值，没有「死／不死」这个开关）。

**加上一个拼法**：先给能套化学／恒星的根式，再逐项变形到生物；DEB 是反推（从经验规律往上收），我们是从根往下落。

**判据**：**能指出哪一块别人没有，才配叫新；指不出的，都写进「借的原件」。**

## 九、可推翻的预测

1. 细胞直径 `> 3 µm` 的原核，代谢指数应 `≤ 1`（预登记 P4：实测 `0.32`，已部分支持）；
2. 蜂鸟每拍支出应 `≈ 4.2×10⁻³ J`（预登记 P1：实测静息 `5.58–7.82 mJ`，**偏低 40–95%**，判"部分"——原因是系数按体型档分层，不是公式错）；
3. 若出现「不消耗自由能也能长期维持有序」的实例，根式被推翻；
4. 若同一种对象的维持成本在不同状态下只差 1–2 倍（而非一个数量级），「状态函数」写法不必要（预登记 `p112117415725`）；
5. 若存在「漏掉流失率仍能算对」的体系，`η_流` 那一栏可以删。

## 十、边界

> **我们给出朝向，不给立法。**
> *We give the heading, not the lawgiving.*

- **朝向**（答）：规律逼出「能维持的留下、维持不了的散掉」，所以世界往「有结构、有生命」这个方向走；
- **立法**（不答）：为什么有这条规律——那是宇宙起源的事，不在这一层。

**另外两条要说清**：

- **这里给的是判据线，不是预测点**：它只回答「过没过线」，不回答「精确多少」；20–30% 的带是**存活条件**（带内还能维持、带外付不起），不是估值误差。
- **数学那一档不在这个量程里**：它连「散」都不参与，不需要判死量，只算个数——**不是我们省掉，是加不上**。

**问「结果往哪走」答得出；问「规矩从哪来」答不出**——两个问题不同层。

## 附：数学那一档——图灵机就是一棵树

> 这一节回答一个质疑：**你们这套是不是只对活物成立？** 不是——**数学那一档是同一棵树的最简形态**，只是它不去算维持。

### 1. 一步图灵机 = 一次分叉

图灵机读一格纸带，纸带有 `|Σ|` 种符号。**读一次，就是在 `|Σ|` 支里选一支**——那就是一次开关。

于是换算率是固定的：`1 图灵机步 = log₂|Σ| 决策步`（二进制纸带时正好 1:1）。

**所以图灵机不是另一个模型，它是这棵树上的一个走法。** 谈下界不必先转到图灵机去，决策树才是根本层。

### 2. 树只有五个本质

| 本质 | 是什么 |
|---|---|
| `f` | 每一层判什么 |
| `w` | 层宽：一个开关有几个选项（二选一就是 `w = 2`） |
| `M` | 候选数：要区分多少种可能 |
| 换算率 | `log₂\|Σ\|`（几步图灵机折几步决策） |
| 开关位置 | 在树的哪一层分岔 |

**下界是严格的**：树深 `d`、层宽 `w`、候选 `M`，则 `d ≥ log_w M`。

**上界是构造**：存在一个算法只用这么多步。
**两者相等才叫「紧」**：排序 `N log₂N` 是紧的；`SAT` 的下界松。

### 3. 数学的本质就是递归

从 `1+1` 出发：

- **乘法 = 重复加法**：`a×b` 要 `(b−1)·a` 次后继（`3×4` 是 **9 次后继** = 12）；
- **大于 = 被包含**：`a < b ⟺ a ∈ b ⟺ a ⊂ b`（冯·诺依曼序数）。

**所以整个算术是从「下一次」长出来的**——那是递归，不是公理堆出来的。

**数学的「维持」就是条件成立**：不成立就是死（矛盾、零、越界），成立就是活着。**判据与式子合一**，不需要额外加判死量（它连「散」都不参与）。

### 4. 从约束满的值反推

拿一个卡到极限的实例——比如 `SAT` 里每个子句都被逼死的那一刻——**走一遍树，再反推回总公式**，得到的结论是：

- **验证 = 走一条路**（给了解，沿一条路径查完，**可以同步、几乎不耗时**）；
- **生成 = 遍历树**（不给解，得搜，**必须耗时**）。

于是 `P ≤ NP` 在我们这套里的读法是：**现状小于、终点可达等于**——**不是静态的集合包含，是时间口径上的「还没到、但到得了」**。

**数学界只问「等或不等」**，是因为他们比的是集合，不比时间。

### 5. 一证全证：归约与换档是同一个动作

- **他们的**：证 `SAT`，靠**归约**（多项式、保结构）→ 所有 `NP` 问题全证；
- **我们的**：证形状，靠**换档**（不改形状）→ 八个域全算。

**「转」那一步保持结构，才叫一证全证；不保结构的「转」，只是每个单独证。**

### 6. 边界

- **我们交**：图纸（树的形状 ＋ 五个本质）＋ 最小数（`3×4` 的 9 次、排序的 `N log₂N`、迷宫 `O(N)`）；
- **他们做**：形式化 ＋ 普遍性 ＋ 大算例（那是数据与算力的事）。

**两个障碍能解释、不能突破**：相对化＝允许外部不花钱（`E_in` 无穷 → 约束消失、分叉抹平）；自然化＝只许写可写的 `f`。**能说清卡在哪，不等于能过去。**
