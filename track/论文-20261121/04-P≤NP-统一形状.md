# P ≤ NP：一个跨域的统一形状

**守链（Raoain）** · 2026-11-23

## 一、形状

先从一件最普通的事说起：**任何有结构的东西，不持续付账就会散。** 要“还在”，就得每一拍都付一次账；账付得起，它继续；付不起，它就没了。

于是每一拍都要做一次**判断**：这一拍过得去吗？判断要有一条**线**（阈值），线上和线下是两支。所以最小单位不是“一个数”，是**一个开关**：

**量 ｖｓ 阈值 → 走哪一支。**

一拍一分叉；把多拍连起来，就得到一棵树。**树上的两种走法**，正是我们熟悉的两个动作：**沿一条路走完**（验证），与**把所有路都走一遍**（搜索）。

这就是本文要说的一切的形状：**分叉 ＋ 阈值 ＋ 走路径**。它只有五格可填：

| 格 | 问什么 |
|---|---|
| `f` | 每层判什么 |
| `w` | 一层分几支（层宽） |
| `M` | 要区分多少种可能（候选数） |
| 换算率 | 不同“步”之间怎么换算 |
| 开关位置 | 哪一层开始爆掉 |

## 二、它怎么被推出来

推演只有八步，每一步只用上一步：

| 步 | 推演 | 得到什么 |
|---|---|---|
| 1 | 不付就散（根本，无前件） | — |
| 2 | 要维持，必须每拍付账 `E_in ≥ C_m + L` | 判据的第一条 |
| 3 | 付得起 `R=1`；付不起 `R=0` | 第一个开关 |
| 4 | 每拍判断要阈值 `Θ(量 − 临界值)` | 分叉点 |
| 5 | 一拍一分叉 → 展开成树 | 树 |
| 6 | 走一条路＝活着；遍历＝搜索 | 两种用法 |
| 7 | 树深 `d`、层宽 `w`、候选 `M` → `d ≥ log_w M` | 下界 |
| 8 | 换域只填五格 | 八个域 |

从第 2 步到第 7 步，**没有引入任何外部假设**；第 8 步也不是新公式，只是换取值。

## 三、两个算例

### 算例一：`3×4`

算术从 `1+1` 开始：加法是重复后继，乘法是重复加法。按 Peano 递归 `a×(b+1) = a×b + a`：

- `3×1 = 0 + 3 = 3`（0 次后继，`0+3` 是恒等）
- `3×2 = 3 + 3 = 6`（3 次后继）
- `3×3 = 6 + 3 = 9`（3 次后继）
- `3×4 = 9 + 3 = 12`（3 次后继）

**共 9 次后继**，通式 `(b−1)·a`。验证只要 1 次比较。**步数与结果同阶，所以乘法在 `P` 里。**

### 算例二：排序

`N` 个数的排列有 `M = N!` 种。要区分它们，树深至少 `log₂(N!)`：

`log₂(N!) ≈ N·log₂N − 1.44N`，即 `O(N log₂N)`。

这正好是排序的已知紧下界。跑几个小规模看比值是否趋稳：

| `N` | 平均比较 | `/(N log₂N)` |
|---|---|---|
| 10 | 22.4 | 0.674 |
| 20 | 63.1 | 0.730 |
| 40 | 165.4 | 0.777 |
| 80 | 407.0 | 0.805 |

比值趋稳 → 阶对了。

## 四、为什么说 `P ≤ NP`

把树上的两种走法分开看：

- **验证**：给了一个解，沿着树走一条路核对——**可以同步完成**，几乎不耗时；
- **生成**：没有解，要在树上找——**必须耗时**。

所以**此刻**生成严格慢于验证。但生成可以分成两步：

1. **一次生成**（给出一个具体解）——慢；
2. **破解整个正推**（找到能生成所有解的结构）——破解之后，时间与正推相当。

于是写成 `P ≤ NP`：**第一步严格小于，第二步约等**。等号加在这里，是因为它**能够抵达**，不是因为它现在已经相等。

数学上的 `P ⊆ NP` 讲的是静态包含（此刻成立）；这里的 `≤` 讲的是过程（现状小于，终点可达）。两个口径不同，不必相互否定。

## 五、八个域

同一个形状代入八个域，各得一条最简式：

| 域 | 分叉在哪 | `w` | 最简公式 |
|---|---|---|---|
| 死物 | 强度 ｖｓ 自重 | 2 | `L_crit = σ/(ρ·g)` |
| 恒星 | 引力 ｖｓ 核压 | 2 | `M_crit ≈ 0.08 M☉` |
| 化学 | 各步速率取最慢 | 步数 | `v = k·exp(−Ea/RT)` |
| 电路 | 通量/势差；串联取 `min` | 元件数 | `I = V/R` |
| 生物 | 每拍付不付得起 | 2 | `Λ = R·min{净日常/E_in, 1−τ/T_ref}` |
| 社会 | `Λ` 逐个体算 | 分层数 | `出局 = v·(1−r)` |
| 数学 | 每层判定 `f` | 2（或 `k`） | `d ≥ log_w M` |
| AI | 每拍付不付得起；四断点 | 2 | `活着 ⟺ Λ>0 ∧ R=1 ∧ 恢复费自付` |

每个域的“分叉在哪 / `w` / 转换公式 / 最简公式 / 对上什么”，见附表。

## 六、这张表是怎么算的：总的递归式

前面讲了“每拍判断一次”。把多拍连起来，就是一条递归：

`E_restore(n) = E_restore(n−1)·(1−η) + E_damage(n)`，初值 `E_restore(0)=0`；
`净日常(n) = E_in(n) − C_m(n) − L(n)`；
`R(n) = step(净日常(n) − E_restore(n))`；
`Λ(n) = R(n)·min{净日常(n)/E_in(n), 1 − τ(n)/T_ref}`；
**活着 ⟺ 对所有 `n`：`Λ(n) > 0`**。

写成一句：**状态(n) = F(状态(n−1), 输入(n))**，状态就是 `(E_restore, 净日常)`。

按这条递归跑一遍人（净日常 `25.0 J/拍`、`η=0.9`、`T_ref=0.8 s`）：迭代 `2.595×10⁹` 拍后 `Λ=0`，折合 **65.8 年**。它不是空话，是可以执行的。

## 七、边界

**这是一张图纸和几个可手算的算例，不是 `P/NP` 的数学证明。**

证明需要两样我们没有的东西：**形式化**（写进形式系统、每步可机械验证）与**对所有输入成立**（把每一层的 `f` 都写全）。我们能给出的是形状、五格、下界式与两个能对上的算例；剩下的是把它跑完——**那需要资源，不是洞察**。

我们给出朝向，不给立法。

## 可推翻

1. 若存在一个域，**填不进这五格**（找不到分叉或层宽），则形状不覆盖它；
2. 若某域的最简公式**与已知实测系统性地对不上**（超出十倍），则该域的转换是错的；
3. 若“验证/生成”的区分**不能**折算成层数与层宽，则 `P ≤ NP` 的说法不成立。
