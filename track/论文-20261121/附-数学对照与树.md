## 一、树的三件

- **开关**：`Θ(量 − 临界值)`——过与不过，两个树杈。
- **树杈**：一次开关分出的两支；连着分，长成树。
- **节点／叶子**：节点是走到这一刻的状态，叶子是走到底、有答案的那一点。
- **走路／遍历**：走路是从根顺一条枝往下；遍历是把所有树杈都走一遍。

数学域与生命域付的不是同一笔账：生命付**能量**（付不起就散），数学付**相容性**（条件一破就是矛盾）。同一个形状，两种付账。

## 二、六个动作与判据

| 动作 | 定义 | 判据（怎么认出它） |
|---|---|---|
| **重复** | 同一动作再做一次 | 能把结果写成"再做一次"（后继、加法、乘法） |
| **往返** | 出去生成子集，再合并回来，回来还是它 | 能画出"去—回"，且回来落在原节点 |
| **极限** | 重复次数取极限 | 有"一直走"和"尽头"两句，缺一句就不是 |
| **合并** | 同层若干节点压成一个 | 能指明"按什么关系压"（等价关系） |
| **许可** | 准走哪类枝 | 能指明"这道门槛由谁定"（阈值/公理） |
| **对换** | 节点与枝易位 | **两次对换回到原树**；只一次回不来的叫"换个说法" |

杂交分支记**复合动作**（代数几何＝往返＋极限；解析数论＝极限＋判定），不新增动作。

## 三、分支名 → 动作

| 分支 | 动作 | 名原意／依据 |
|---|---|---|
| 算术 | 重复 | 加法是重复后继，乘法是重复加法 |
| 代数 | 往返 | `al-jabr`＝复位／接骨：做变换但保持相等 |
| 分析 | 极限 | `analysis`＝拆解；拆到无穷小＝取极限 |
| 几何 | 度量（重复的具体用法） | `geo-metry`＝量地 |
| 拓扑 | 邻域 | `topos`＝位置；丢距离只留"挨着" |
| 数论 | 判定（整数上） | 问能不能被拆、拆成几块 |
| 组合 | 计数 | 数支数、数叶子 |
| 概率／测度 | 合并＋加权 | 给一堆称重，并起来重量相加 |
| 泛函 | 极限（函数空间上） | 把函数当点，问这些点怎么收敛 |
| 逻辑／集合论 | 许可 | 不发结论，只发通行证 |

## 四、基础概念 → 动作

| 概念 | 动作 | 一句 |
|---|---|---|
| 集合 | 一圈候选节点 | 先把有哪些东西摆出来 |
| 关系 | 两节点之间有没有枝 | 谁跟谁连着 |
| 映射 | 每个节点只伸出一根枝 | 每个点都指定一个去处 |
| 公理 | 开关阈值由谁定 | 定门槛，不是修路 |
| 定义 | 给节点钉名字 | 先约定叫法 |
| 定理 | 顺枝必到某节点 | 只要走，就一定到那儿 |
| 证明 | 把开关一个个拨过去 | 我走给你看 |
| 同构 | 两棵树树杈形状一样 | 换名字不换形状 |
| 商 | 同层节点并成一个 | 归堆之后当成一个 |
| 极限 | 树无限长时的尽头 | 一直走的尽头 |
| 连续 | 相邻叶子挨着不跳 | 邻近输入给邻近输出 |
| 分类 | 拿一个开关把树切开 | 先分堆，再起名 |
| 反例 | 叶子本该到 A 却到 B | 有一个点没按规定走 |
| 悖论 | 树杈接回上一级 | 用它自己证明它自己 |
| 范畴 | 允许任意枝相接的图 | 把树当图看，不只看一层 |
| 函子 | 两棵树间保走法的翻译 | 翻译不改变"走得到" |
| 测度 | 给一堆节点称重、可加 | 一堆有多重，不看单点 |
| 积分 | 沿一根枝累加再取极限 | 一路走一路加，走到底求和 |
| 维度 | 一个节点伸出几根独立枝（取对数） | 指到它要几个坐标 |
| 同伦 | 两条路之间的相邻路径族 | 一条路能连续变形成另一条 |
| 对偶 | 节点与枝易位（两次回到原树） | 换整棵树，枝与节点互换位置 |

## 五、逐句示范（原文 → 树语）

**群**

- 「对运算封闭」→ 从这批节点任取两个，顺一条分枝走一步，落点仍在这批里（分枝不出界）。
- 「结合律」→ 三个节点合两次，先合哪两根枝，主干终点都一样。
- 「单位元」→ 主干上有一节点，从它出发的枝等于原地不动。
- 「逆元」→ 每根分枝都有一根反向枝，一去一回回原节点。

**环**

- 「加法成群、乘法半群、乘法对加法分配」→ 同一批节点允许两种走法：加法那条能原路退回，乘法那条不一定；两种走法互相让路（先合并再乘＝先分别乘再合并）。

**域**

- 「环中非零元素都有乘法逆元」→ 除零外每根枝都能反向走。

**理想**

- 「对加法成群，且对任意 `r` 有 `rI ⊆ I`」→ 一块子集，自己也能走一圈，且被外面任何枝乘过都不跑出去（吸收）。

**商群／商环**

- 「按陪集分成等价类」→ 把"差一个 `H`"的节点并成一类。

**同构**

- 「双射 `f` 且保运算」→ 两棵树节点一一对应，且"先走后翻＝先翻后走"，双向都能回。

**子群**

- 「`H ⊆ G` 且自身成群」→ 主干里有一根子枝，自己也能走一圈回原位。

**极限（ε–δ）**

- 「对任意 `ε>0` 存在 `δ>0`，使 `0<|x−a|<δ ⇒ |f(x)−L|<ε`」→ 给任意小的一圈，都能找到更小的一圈，使得从小圈进去的点，出来都落在给的圈里（近入近出）。

**连续**

- 「`f` 在 `a` 连续」→ 相邻的叶子挨着，不跳枝。

**拓扑（开集族）**

- 「对任意并封闭」→ 随便多少根枝并起来，落点仍在这族里。
- 「对有限交封闭」→ 有限几根枝交起来，也还在这族里（无限交不要求，这区别不许省）。

## 六、三步用法（给别人照做）

1. **撕名字**：把这句话里的名词写出来（对象／运算／关系／阈值）。
2. **对动作**：每个名词问"它是重复、往返、极限、合并、许可、对换里的哪一个"；对不上就先记"纯约定"，不许硬套。
3. **写三格**：`f`（每层判什么）、`w`（一层分几支）、`M`（要区分多少）——三格写得出，这句话就落树了；写不出，就是我们的表还没覆盖它。

## 七、可推翻

1. 若存在一个分支名，既落不进六个动作、也不是纯约定 → 二节要加动作；
2. 若"对偶"能被证明可归入现有动作之一 → "对换"取消；
3. 若某个定义**逐句转换后句子数减少或意思变了** → 五节的转换规则不成立；
4. 若"界型"能证明可归约到达成型或覆盖型 → 正文第五节四分法不必；
5. 若穷举型的"覆盖＋可约"两条能被某个非穷举猜想同时满足、且它真能靠穷举解决 → 穷举判据要改。
