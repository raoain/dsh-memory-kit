# 律的分域：数学

**守链（Raoain）** · 2026-11-24

本文是《存续的律》的分域篇之一，只处理一个域：数学。

主张一句：**数学里的分支名与概念名，都是同一棵树上六个动作的标签**——重复、往返、极限、合并、许可、对换。名字是事后贴上去的，动作本来就在树上。所以不同分支之间能互相翻译，靠的不是新理论，是把名字撕掉、看底下的动作。

边界先写死：本文不给任何数学猜想以证明，也不替数学立法；它给的是坐标与判据。哪一格坐标填不进去，那一格就是它的可推翻处。

**全部对照与逐句示范见附件**：`附-数学对照与树.md`（树的三件、六动作与判据、两张对照表、十个逐句示范、三步用法）。正文只留主张与关键判据，附件供核对与照抄。

**引用与依赖**：本文不自立根，全部形状取自前两篇——《**存续的律**》（`00-存续的律.md`：根、形状、判据的样子）与《**存续的算法**》（`01-存续的算法.md`：六步求值、五张表、三档标定）。本文只做一件事：把这两篇的形状**代进数学这个域**，看名字能不能落格。凡与前两篇冲突处，以前两篇为准。

## 一、树：分叉、阈值、走路径

从一件最普通的事起：任何有结构的东西，不持续付账就会散。要"还在"，每一拍都要付一次账；每一拍都要判一次"这一拍过得去吗"。

于是最小单位不是数，是**开关**：量对阈值比一次，分出两支。

- **开关**：`Θ(量 − 临界值)`，过与不过是两个树杈；
- **树杈**：一次开关分出的两支；连着分，长成树；
- **节点**：走到这一刻的状态；**叶子**：走到底、有答案的那一点；
- **走路**：从根顺一条枝往下；**遍历**：把所有树杈都走一遍。

数学域与生命域付的不是同一笔账：生命付能量（付不起就散），数学付**相容性**（条件一破就是矛盾）。但两者共用同一个形状：**不付就散**——一个是散掉，一个是自相矛盾。

## 二、六个动作

所有数学分支名，都能落到下面六个动作之一（或它们的复合）上：

| 动作 | 一句话 |
|---|---|
| 重复 | 同一个动作再做一次（后继、加法、乘法） |
| 往返 | 出去生成子集，再合并回来，回来还是它 |
| 极限 | 重复次数取极限（一直走的尽头） |
| 合并 | 同层若干节点压成一个（等价类） |
| 许可 | 准走哪类枝（公理） |
| 对换 | 节点与枝易位（对偶），两次回到原树 |

判据：一个分支名若能画成这六个之一，它就是**现象名**；画不成的，才是**纯约定名**。

## 三、分支名对应哪个动作

| 分支 | 动作 | 大白话 |
|---|---|---|
| 算术 | 重复 | 一次一次往上数，数法是同一动作 |
| 代数 | 往返 | 走开再走回来，回来还是它（名字原意"复位/接骨"） |
| 分析 | 极限 | 把"一直走"的尽头当成一个点 |
| 几何 | 度量（重复的具体用法） | 只问远近和角 |
| 拓扑 | 邻域 | 距离抹掉后，谁和谁还算连着 |
| 数论 | 判定（整数上的） | 只管能不能被拆、拆成几块 |
| 组合 | 计数 | 数支数、数叶子，不问每支里装啥 |
| 概率/测度 | 合并＋加权 | 给哪一堆称重，不问单点 |
| 泛函 | 极限（函数空间上的） | 把函数当点，问这些点怎么收敛 |
| 逻辑/集合论 | 许可 | 不发结论，只发"哪条路准走"的通行证 |

两条口径要写清：

1. **分支名指的是一条延伸，不是一个静态集合**。代数指"一直求闭合"这件事，不是"所有代数对象的集合"。所以边界会随工作挪，杂交分支（代数几何、解析数论）是两条延伸叠在一起——记成**复合动作**，不是第七个动作。
2. **公理、阈值、许可，是同一个 `Θ` 判定的三个叫法**。差别只在判什么：公理判"边的类型"，阈值判"量的数值"。换名测试过——把公理换成阈值，群论四条结论一字不变。

## 四、基础概念对应哪个动作

| 概念 | 动作 | 大白话 |
|---|---|---|
| 集合 | 一圈候选节点 | 先把有哪些东西摆出来 |
| 关系 | 两节点之间有没有枝 | 谁跟谁连着 |
| 映射 | 每个节点只伸出一根枝 | 每个点都指定一个去处 |
| 公理 | 开关阈值由谁定 | 定门槛，不是修路 |
| 定义 | 给节点钉名字 | 先约定叫法 |
| 定理 | 顺枝必到某节点 | 只要走，就一定到那儿 |
| 证明 | 把开关一个个拨过去 | 我走给你看，你也照着走 |
| 同构 | 两棵树树杈形状一样 | 换名字不换形状 |
| 商 | 同层节点并成一个 | 归堆之后当成一个 |
| 极限 | 树无限长时的尽头 | 一直走的尽头 |
| 连续 | 相邻叶子挨着不跳 | 邻近输入给邻近输出 |
| 分类 | 拿一个开关把树切开 | 先分堆，再起名 |
| 反例 | 叶子本该到 A 却到 B | 有一个点没按规定走 |
| 悖论 | 树杈接回上一级 | 用它自己证明它自己 |
| 范畴 | 允许任意枝相接的图 | 把树当图看，不只看一层 |
| 函子 | 两棵树间保走法的翻译 | 翻译不改变"走得到" |
| 测度 | 给一堆节点称重、可加 | 一堆有多重，不看单点 |
| 积分 | 沿一根枝累加再取极限 | 一路走一路加，走到底求和 |
| 维度 | 一个节点伸出几根独立枝（取对数） | 指到它要几个坐标 |
| 同伦 | 两条路之间的相邻路径族 | 一条路能连续变形成另一条 |

**所以**：他们的定义全在树上；他们解释的是"这条枝为什么走得通"（合法），不是"为什么有这棵树"（必然）。

## 五、猜想的四型

| 型 | 问什么 | 样本 | 反例长什么样 |
|---|---|---|---|
| 到达型 | 某条枝走不走得到指定点 | 黎曼 | 找到一个零点不在 `Re=1/2` 上 |
| 覆盖型 | 每个叶子是否都有路 | 哥德巴赫 | 一个偶数拆不出两个素数 |
| 穷举型 | 有限走完、没有例外 | 四色定理 | 造出不可约反例构型 |
| 界型 | 树深与层宽之间的不等式 | `abc`、孪生素数定量版、`P vs NP` | 越界的一个实例 |

**穷举型的"有限"必须有判据**，否则任何猜想都能自称有限：①**覆盖**——任意情形都归约到一个有限代表集；②**可约**——每个代表有限步能验完。缺①退回覆盖型（哥德巴赫：每个偶数都得单独处理，没有有限代表集），缺②退回界型。

**界型是一个分叉点、两个子集**：分叉点是"界住的是什么对象"。

- **比值界**：被界的是**量**（`abc`：`log c ≤ (1+ε)·log rad(abc) + log K`；`P vs NP` 也在这支）；
- **计数界**：被界的是**解的个数**（孪生素数定量版：解数 ~ `C·x/(log x)²`）。

**`P vs NP` 是双支**：比值界给"代价对规模"，计数界给"候选数对步数"（`w^d ≥ M`）；两支在**紧**时合流（排序两边都是 `N log N`）。一般规则：一个对象可以有多支归属，条件是每支都能推到同一个总公式；推到不同根、给出不同答案的，是两个问题。

## 五之二、一个样本：黎曼猜想可证明的那一点在哪

这里不宣布任何证明，只指出**哪一步可证、哪一步不可证**。

**正推链**（每步只用上一步）：`1+1` → 自然数 → 乘法 → 求逆（除法，先有"可拆"）→ 素数（不可再拆的节点）→ 素数无穷多（欧几里得反证）→ 欧拉积 → 取第一次极限（`n→∞`，在 `Re(s)>1` 收敛）得 `ζ` → 解析延拓（第二次极限，由函数方程＋增长条件唯一指定；有损：丢逐点可枚举，换唯一延拓）→ 函数方程给出对称 `σ: s ↦ 1−s`。

**可证的两点**：

1. **零点成对**：由函数方程直接得——`s` 是零点，则 `σ(s)` 也是。这一步可证，且早已证过。
2. **形式化条件**：把"全部零点落在 `Re(s)=1/2`"写成可验证的命题，并逐条检查它等价于标准陈述（这是任何声称证明的第一道关）。

**不可证的那一点**：从"成对"到"塌到不动集"这一截。它不来自构造——若能从构造推出，黎曼猜想早已不是猜想。所以这一截只能是**加强**（额外要求），不是推导。

**于是判据**：谁能给出"塌缩"的构造来源（哪一步保证成对必须压在固定集上），谁就证了；给不出，就只能说"缺口在这一层"。这也解释了为什么"声称证明"要先查两处：**Lean 陈述与标准陈述是否对应**、**依赖树里有没有引入假设**——两处任一出问题，形式化再干净也证明不了原命题。

## 六、三个逐句转换示范

**群**：原文"封闭、结合律、单位元、逆元"→ 分枝不出界；先合哪两根枝主干终点都一样；存在"走了等于没走"的节点；每根枝都有反向枝、一去一回回原点。

**极限（ε–δ）**：原文"对任意 `ε>0` 存在 `δ>0`，使 `0<|x−a|<δ ⇒ |f(x)−L|<ε`"→ 给任意小的一圈，都能找到更小的一圈，使得从小圈进去的点，出来都落在给的圈里（近入近出）。

**拓扑（开集族）**：原文两条，拆成两句——"对任意并封闭"→ 随便多少根枝并起来，还在这一族里；"对有限交封闭"→ 有限几根枝交起来，也还在这一族里（无限交不要求，这区别不许省）。

**判据**：转换后逐句核对——①每个名词都在枝干/分枝上找到位置；②动词（走、合、回、并、交）都对上动作；③找不到对应的那个，标"纯约定"，不许硬套。句子数不减、意思不偏。

## 七、可推翻

1. 若存在一个分支名，既落不进六个动作、也不是纯约定，则第二节要加动作；
2. 若"对偶"能被证明可归入现有动作之一，则"对换"取消；
3. 若某个定义**逐句转换后句子数减少或意思变了**，则第六节的转换规则不成立；
4. 若"界型"能证明可归约到达成型或覆盖型，则第五节的四分法不必；
5. 若穷举型的"覆盖＋可约"两条能被某个非穷举猜想同时满足、且它真能靠穷举解决，则第五节第二条判据要改。

## 八、边界

本文不证明任何猜想，也不声称完成了形式化。它给的是：一棵树（分叉＋阈值＋走路径）、六个动作、两张翻译表、四型判据，以及四个可推翻点。

**我们给出朝向，不给立法。**
