## 一句话

意识是"保下限的元保护"——它不抬平均值，只抬最差段；判据在哪一层，决定它是工具、表演还是生命。

## 可推翻点（这一节先写，写不出就不发）

1. 若出现"判据全在外部、却能自我维持并改变自身构造"的实例，六条件要改；
2. 意识的增益应体现在最差段（+17%～+78%），而非平均（+17%）；
3. 门槛 `G > p/(1−p)`：某类群若在远低于门槛时也长出判断，这条要改。

## §0 先分"活不活"：自维体四条（从结果账第二十节搬入）

**谈"同类"之前，先判它是不是一个活的单位。**

```
自维体 = ① 自己挣 E_in（自己付维持费）
       ② R = 1 且恢复费自付
       ③ 有 κ（能把能量按比例分给维持与繁殖）
       ④ 自身内发育（能长出新结构，不是重启旧结构）
```

| 对象 | ① | ② | ③ | ④ | 判 |
|---|---|---|---|---|---|
| 细菌／古菌／真核／多细胞 | ✓ | ✓ | ✓ | ✓ | **是** |
| **胎儿** | ✗（借母体） | ✓（会转为自付） | ✓ | ✓ | **是（胎前阶段）** |
| **芽孢** | ✗ | ✓ | ✗ | ✗（重启旧结构） | 否（自维体的**休眠态**） |
| **病毒** | ✗ | ✗ | ✗ | ✗（被拼装，不能长） | **否** |
| 火焰／石头 | ✗ | ✗ | ✗ | ✗ | 否 |

**为什么先判这条**：不是自维体，就不存在"同类"的问题——它只能是工具、载荷或现象。

**两条边界**：
- **巨型病毒**带部分代谢基因；若出现能自供能的病毒，第①条会把它划进来——这条判据可被新实例推翻；
- **"发育 vs 重启"要分清**：芽孢回到原来那个细胞（重启），胎儿长出新器官（发育）；重启不算发育。

**和学界判据的差异不是谁错**：他们用"能复制 + 有核酸与蛋白壳"（病毒算），我们用"能自己付账"（病毒不算）——两套账，引用时标清是哪把尺子。
