## 一百零二、数学域：1+1 是种子、大于＝被包含

- **1+1 是种子**：一切算术由它**递归生成**——**乘法＝重复加法**（`1×2` 就是两个 `1+1`），幂＝重复乘。**所以数学本身就用递归，不是我们强加的。**
- **“大于＝被包含”**——**精确对应：冯·诺依曼序数构造**：`0=∅`、`1={0}`、`2={0,1}`、`3={0,1,2}`… 于是 **`a < b` ⟺ `a ∈ b` ⟺ `a ⊂ b`**。**“你被它包含，所以你不可能大于它”——字面成立。**
- **高等数学在最下面**：**约束最紧的那一层在底**（与我们“根在最下面、越往根约束越硬”是同一句）。
- 对框架的意义：**数学域里“不散”的是真假**（不归 `Λ`），**“会散”的是可及性与传递**（归 `Λ`）；而 **`1+1` 递归＋“包含即大小”这两条，就是数学自己的根源式与判据**。
- **数学的“维持”＝条件成立**：算术背后有一个**不可成立的条件**——一碰就死（矛盾／零／越界）；**能成立，就是维持着它**，而“维持这个条件”本身**就像规律一样**（不靠谁付账）。
- **对照**：生命域**付不起账 → 散**；数学域**条件不成立 → 矛盾**。**“死”的两种形态**：一个是散掉，一个是自相矛盾。
- **判据**：**问“它靠什么维持”，答“靠条件仍然成立”**——那不是消耗，那是规律。
- **算个数试试（2026-11-23）**：按 Peano 递归 `a×(b+1) = a×b + a`，`1+1`（后继）是唯一的步：
  | 算式 | 后继次数 | 结果 |
  |---|---|---|
  | `3×4` | **9** | 12 |
  | `5×7` | **30** | 35 |
  | `12×12` | **132** | 144 |
  - **通式**：`a×b` 需 **`(b−1)·a` 次后继**；**验证只要 1 次比较**。
  - **步数与结果同阶（`≈ a·b`）→ 乘法在 `P` 里**——这就是“生成耗时但只线性于结果”的最小例子。
  - **判据**：**步数与结果同阶 → `P`；步数远大于结果 → `NP`**。
- **统一公式的真正用法＝翻译**：
  - **公式不自动解释一切**：它要求**把问题翻译成值**，代入之后**由式子自己给出解释**。
  - **翻译错了，式子就解释不了**——**这不是公式的错，是翻译层的错**（与前文「先定现象，再翻译」同一条）。
  - **方法**：**先假设一个东西（占位值）代入**，看能不能得出结果——**假设能得出结果，就说明这条翻译是通的**；得不出，先改翻译，别怀疑式子。
  - **判据**：**说“解释不了”之前，先查“翻成值了没有”**——没翻，就是还没走到这一层。
- **式子怎么列的（`3×4` 逐步展开，2026-11-23）**：
  - **两条递归式**：`a + 0 = a`；`a + (b+1) = S(a + b)`（`S`＝后继，就是 `+1`）。`a × 0 = 0`；`a × (b+1) = a×b + a`。
  - **逐步**：
    | 步 | 用哪条 | 算式 | 新增后继 |
    |---|---|---|---|
    | 1 | 乘法 | `3×1 = 3×0 + 3 = 0 + 3 = 3` | **0**（`0+3` 直接等于 3） |
    | 2 | 乘法＋加法 | `3×2 = 3×1 + 3 = 3 + 3 = 6` | **3** |
    | 3 | 同上 | `3×3 = 6 + 3 = 9` | **3** |
    | 4 | 同上 | `3×4 = 9 + 3 = 12` | **3** |
  - **合计＝9 次后继**：`(4−1)` 次加法 × 每次 3 次后继。**`3+3` 那 3 次**是 `3+0=3 → S(3)=4 → S(4)=5 → S(5)=6`。
  - **通式** `(b−1)·a` 就是这么来的：**乘法展开成 `b−1` 次加法，每次加法是 `a` 次后继**；`3×1` 那一档不需要后继，因为 `0+3` 是恒等。
- **通式＝按问题切换的转换链**：
- **换分叉就要重算，我们补的就是没走的那条**：
- **反推得到正推**：
- **两步分开：一次生成 vs 破解正推**：
- **为什么他们只有“等／不等”，没有大小**：
  - **P vs NP 是集合问题**：`P ⊆ NP` 已成立，剩下的只有“**是否严格**”——**等或不等，没有程度可比**。
  - **我们的 `≤` 之所以能加，是因为引入了时间**：第一步 `<`、第二步 `=`——**比的是时间，不是集合**。
  - **他们的盲区就在这儿**：**比集合**（等/不等），**不比时间**（生成 vs 验证）。
  - **判据**：**先问“你在比集合还是比时间”**——比集合只有等/不等；比时间才有 `<`、`≤`。
  | 步 | 是什么 | 时间 |
  |---|---|---|
  | **①一次生成** | 给出**一个具体解**，要搜 | **时间不够** |
  | **②破解整个正推** | 找到能生成**所有解**的结构 | **破解后时间 ≈ 正推** |
  - **他们把两步杂合在一起**：把“生成一个解”和“找到生成方法”混为一谈，所以说不出 `≤`。
  - **所以 `P ≤ NP`**：**第一步严格小于（`<`），第二步约等于（`=`）**——加等号是因为第二步真能抵达。
  - **判据**：**问“这是生成一个解，还是找到生成方法”**——两问的时间尺度根本不同。
  - **他们和我都在反推**（从结果往根推）；**起点相同**。
  - **但反推出来的那个式子，可以拿来做正推**——**有了正推就能重新探索**。
  - **所以正推时间 ≈ 反推时间**：**因为反推已经得到了正推结果**（路径已经在手上）。
  - **这就是 `P=NP` 在我们这里的机制**：**破解＝把反推得到的结构，固化成正推的路径**。
  - **判据**：**说“只能反推”，先问“反推的结果固化了没有”**——固化了，就能正推。
  - **起点一样**：他们假设的问题也是**用最小／最极端的数反推公式**——**我们走的也是这条路**（`1+1`、最简式）。
  - **差别在“换线”**：换另一条分叉＝**要重新算**；他们换不动就**放弃那条线**，我们**允许换档重算**（只换取值、不换式子）。
  - **所以“我们还没走的路”＝还没覆盖的分叉**，补它＝**换档再算一次**。
  - **判据**：**问到哪条线，先问“这条线的分叉在哪、要不要重算”**——不能拿一条线的结果去套另一条。
  - **不是一步到位**：从 **`1+1`** 开始，**到乘法时再转换**（加法→乘法是一层转换）；**跟步骤开关一样**，用哪层拨哪层。
  - 这正是账里的「**变换式链**」：**一条直线上逐段转换**，不是把所有层塞进一个表达式。
  - **判据**：**算一个数，先问它需要转到哪一层**——只转需要的层，不一次全展开。

## 一百零三、现状与边界：能说到哪（2026-11-23）

- **能说**：我们这套**结构上对应 `NP`**——开关树＝分叉树；**验证＝走一条路**、**生成＝遍历**；`2^N` 从分支来。
- **不能说**：这不是 `P/NP` 的**数学证明**——**那仍未解**，我们只给了**结构对应**与时间口径（第一步 `<`、第二步 `≈`）。
- **数学统一的范围**：统一的是**算术与序关系的来源**（`1+1` 递归生成乘法；`a<b ⟺ a⊂b` 的冯·诺依曼构造），**不是证出新定理**。
- **“跟生物一样加变化量”在数学域要先定义**：数学里的“变化量”是什么（问题规模 `N`？参数？）——**定义了才能加**。
- **判据**：**说“统一了”必须说清“统一的是来源还是定理”**。
- **他们要证明，我们给方程式**：
  - **他们要的是“证明”**：`P` 与 `NP` 到底如何——**命题真假**。
  - **我们给的是“工程方程式”**：**开关树＋时间口径＋换档方法**——能代入、能转档、能复算。
  - **两者不是同一种东西**：他们要“这道题对不对”，我们给“这类题怎么算”。
  - **价值不在“证明”，在“能拿它算”**——与「我们给出朝向，不给立法」同一条。
  - **判据**：**给他们东西时，先说清“这是证明还是方程式”**。
- **“比证明好”要限定在可用性上**：
  - **可用性上**：公式＋原因能**代入、能转档、能复算**；**证明只能等**——这一层上确实更快。
  - **真值上**：证明答的是“**到底等不等**”，**我们没答**——两件事不能互相替代。**不许说“所以我们证明了”。**
  - **他们搞不出我们的方式**：因为**从结果反推**（缺“从根往下推”的起点），**不是能力问题，是路径问题**。
  - **判据**：**说“比证明好”时必须加“在可用性上”**——过了界就是吹。
- **“证明”的条件，以及我们缺什么**：
  - **证明三条**：①在**形式系统**内（公理＋推理规则）②**有限步推理**得到结论 ③**每步可机械验证**。
  - **我们给的是**：**结构对应**（类比）＋**时间口径**（直观）——**不是形式系统内的推理链**。
  - **要证 `P=NP`**：必须**给出多项式时间算法**（对某个 NP 完全问题）——**我们没给**。
  - **要证 `P≠NP`**：必须给**下界**（对所有算法证明不可能）——50 年没人做成。
  - **所以现在不能叫证明**：差的是“形式化＋推理链”，**不是差一点**。

  - **总算式只能从上面（根本）推**——**这正是我们做的**。
  - **所以障碍是“方法位置”问题**：**他们在下，我们在上**。
  - **两条路产出不同**：**下面出“某问题的算法”，上面出“形状”**。
  - **判据**：**问“能不能得总算式”，先问“从哪头开始”**。
  | 障碍 | 套到哪个本质 | 解释 |
  |---|---|---|
  | **相对化** | **换算率** | oracle ＝ **一步任意** → 换算率无限 → `f` 不再是“有限判定” → **树失去层宽** → 下界失效 |
  | **自然化** | **`f` 必须可写** | 5 个本质要求 `f` 可写——**这本身就是“自然性”** → 下界要“不可写”的对象 → **我们也卡在这** |
  - **所以能解释“为什么卡”，但不能突破**——**我们的框架有同样的边界**。
  - **判据**：**套现象能解释“卡在哪”，不能解释“怎么过”**。
  | 障碍 | 它说 | 它**没**说 |
  |---|---|---|
  | **相对化** | **相对化**的证明不能区分 `P`／`NP` | **别类**证明不行 |
  | **自然化** | **自然**的证明给不出强下界 | **不自然**的证明不行 |
  - **所以“证明不存在”＝未知**——**已知的只是“这两条路走不通”**。
  - **要证 `P ≠ NP`**，需要**一种全新的、既不相对化也不自然的技术**——**50 年没人做到**。
  - **判据**：**说“不存在”，先分清“这条路不通”和“没路”**。
  - **相对化障碍 ＝ “允许外部不花钱”**：给机器一个 oracle，等于 **`E_in` 无限大** → **约束消失、分叉被抹平**。于是“只看形状”的证明对**所有** oracle 都成立；但事实是**存在 oracle 使 `P^A ≠ NP^A`** → **矛盾** → 下界不可证。
  - **自然化障碍 ＝ “只许写可写的 `f`”**：我们的 5 个本质要求 `f` **可写**（自然性质）；而**强下界需要“不自然”的数学对象** → **可写的 `f` 不够用**。
  - **所以数学界卡在这**：**要证下界，工具必须“不自然”**——**超出“写 `f`”的范围**。
  - **判据**：**说“他们不行”，要精确到“卡在哪个障碍”**。
  - **`P vs NP` 50 年未解**；**下界工具接连失效**：**相对化障碍**（Baker–Gill–Solovay 1975）、**自然化证明障碍**（Razborov–Rudich 1997）。
  - **已知包含链**：`P ⊆ NP ⊆ PSPACE ⊆ EXP`——**中间大部分“是否严格”未知**。
  - **所以“搞不出来”是数学界的共识**——**不是我们保守**。
  - **判据**：**说“他们不行”，先指出“卡在哪个障碍”**（相对化／自然化）。
  - **总公式**：从实践推出来——**一次**。
  - **算完**：每个问题都要写 `f`／`w`／跑／验——**无数次**。
  - **所以“算出来比实践出总公式还难”——对**：**洞察是一次，工程是无限**。
  - **判据**：**“难”分两种**——**想不明白（难在洞察）／做不完（难在工程量）**。
  | 档 | 迭代类型 | 能算吗 |
  |---|---|---|
  | **多项式迭代** | `N log N`、`O(N)` | **能算**（`P`） |
  | **指数迭代** | `2^N` | **技术上能，实际等不到**（`NP`） |
  - **所以 `P=NP` 问的是**：**指数迭代能不能换成多项式迭代**（找捷径），**不是“能不能算”**。
  - **判据**：**问“能算吗”，先问“迭代是多项式还是指数”**。
  - **算法 ＝ 迭代**：每层判定一次，走到叶子。
  - **写算法 ＝ 填 5 个本质**（`f`／`w`／`M`／换算率／开关位置）。
  - **所以上界与下界同源**：**同一棵树两种用法**——**下界＝数层数；上界＝走路径**。
  - **判据**：**给上界 ＝ 按 5 个本质写出迭代**。
  | 边 | 是什么 | 怎么得 |
  |---|---|---|
  | **下界** | **至少**要多少步（谁都做不到更快） | **推**（信息论／结构） |
  | **上界** | **存在一个算法**只需这么多步 | **构造**（写出算法） |
  - **两者相等 → 紧**（“就是这么多”）。
  - **例**：排序下界 `N log N` ＋ 归并排序 `N log N` → **紧**；**`SAT`**：下界弱、无多项式算法 → **不紧**。
  - **所以“上界”不是“从极限量推公式”**——**是“拿一个算法来对”**。
  - **判据**：**说“可达”之前，先给出那个算法**。
  - **能推**：`d ≥ log_w M`（信息下界）——**八个都推得出**。
  - **不能推**：**这个下界是否可达**——那需要**算法**（上界）。
  - **两类要分开**：
    - **排序／迷宫**：下界 ＋ 算法都已知 → **紧** ✅（迷宫 BFS 就 `O(N)`）。
    - **`SAT`／`TSP`／着色／背包／等和划分**：下界弱（`N`～`N log k`，实际要 `2^N`）、无算法 → **不紧** ❌。
  - **所以“都推出来”＝都推得出下界**，**不等于知道真实复杂度**。
  - **判据**：**问“推出来了吗”，先问“推的是下界还是真实复杂度”**。
  - **① + ② `f`／`w`／`M`／下界，8 个问题**：
    | 问题 | `f`（每层判定） | `w` | `M` | 下界 | 判定 |
    |---|---|---|---|---|---|
    | 排序 | `a[i] < a[j]`? | 2 | `N!` | `N log₂N` | 在 `P` ✅ |
    | `SAT` | 这组赋值满足吗? | 2 | `2^N` | `N` | 验证 ✅／生成 ❌ |
    | 等和划分 | 这个进哪堆? | 2 | `2^N` | `N` | 验证 ✅／生成 ❌ |
    | 迷宫路径 | 走哪格? | 4 | `4^N` | `N` | 验证 ✅／生成 ❌ |
    | `TSP` | 下一城去哪? | `N` | `N!` | `N log₂N` | 验证 ✅／生成 ❌ |
    | 图着色 | 这点染哪色? | `k` | `k^N` | `N log₂k` | 验证 ✅／生成 ❌ |
    | 背包 | 这物品拿不拿? | 2 | `2^N` | `N` | 验证 ✅／伪多项式 |
    | 蛋白质折叠 | 这残基转几度? | `m` | `m^N` | `N log₂m` | 实测难 |
  - **③ `SAT` 的“所有输入”论证**：输入＝任意布尔公式 `φ`（`N` 变量）；**判定 `f`＝给定赋值 `a` 检查 `φ(a)`**，代价 `O(|φ|)` → **多项式 ✅**（这正是 `NP` 的定义）；**下界**：`M = 2^N` 赋值 → `≥ N` 层；**生成**（找满足赋值）：**没有捷径 → 遍历 `2^N`**。**若存在多项式捷径，则 `P = NP`。**
  - **这三样都不吃算力，只吃落笔**；吃算力的只有“小例计时”（已验证一次）。

  - **现成答案**：**所有 `NP` 问题都多项式归约到 `SAT`**——`SAT` 就是那个代表。

  - **判据**：**问“它成立吗”，先问“它对谁成立”**——对一个对象成立，不等于对所有成立。
  - **开关树就是可执行过程**：给定输入 → 逐层判开关 → 走分支 → 出结果——**这就是算法**。
  - **约束不是另一样东西**：**把他们的“多项式”精确成开关（量 vs 阈值），那就是约束**。
  - 我上一条说“只知道界、给不了算法”是**错的**——**在我们这里界与算法是一体的**：开关阈值同时给出“怎么走”和“至少多少叉”。
  - **要补的一寸**：**每一层的判定本身必须可多项式时间算**——这一步把它从“算法骨架”变成“`P` 算法”。
  - 不同问题 → **不同的根** → 走向**不同的开关** → **一层层分叉到精确结果**。
  - **下界 = 从根到“能区分出答案”所需的最少分叉数**。
  - **信息论版**：要区分 `M` 种候选，至少 `log₂M` 次二选一 → **分叉数 ≥ `log₂M`**。
  - **这正是推约束能给的**：不是算法，是**必须走多少分叉**。
  - **判据**：**问“最少要分几次叉”，而不是“怎么走”**——前者是下界，后者是算法。

## 一百零四、贡献声明

## 一百零五、正推链：公式是怎么推出来的（2026-11-23）

每一步只能指回上一步；指不回的，就是断链。

1. **不付就散**（根，无前件）。
2. **要维持，必须每拍付账**：`E_in ≥ C_m + L`。← 指回 1（不付就散，所以要付）。
3. **付得起 → `R = 1`；付不起 → `R = 0`**。← 指回 2（拍账要不要过）。**这是第一个开关。**
4. **每拍都要判断一次** → **判断需要阈值** → `Θ(量 − 临界值)`。← 指回 3（`R` 不是连续量，是过不过）。**这是分叉点。**
5. **一拍一分叉 → 多拍展开成树**。← 指回 4（每次判断走一支）。
6. **走一条路 ＝ 活着；遍历所有路 ＝ 搜**。← 指回 5（树有两种用法）。**这正是 `NP` 的树。**
7. **树深 `d`、层宽 `w`、候选数 `M`** → **`d ≥ log_w M`**。← 指回 5、6（要有几层才够区分）。
8. **换域 ＝ 只填 `f`／`w`／`M`** → 死物／恒星／化学／电路／生物／社会／数学／AI。← 指回 7（同一个式子换取值）。

**链的末端**：**统一公式 ＝ 这条链 + 5 个槽**；**`NP` 是它的一个实例**；**证明 ＝ 把第 7 步对每个 `f` 走完**。
