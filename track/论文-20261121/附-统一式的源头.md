# 附：统一式的源头 / Where the Unified Formula Came From

> 本篇是总表的附表。**总表（`表-域`）答「每域填什么值」，符号表（`表-符号与变式`）答「每个字母是什么」，这张答「这个式子从哪来」。**
> 三张表不重复：**符号表给定义、域表填值、本表给来源。**

---

## 一、三条线，别混

| 线 | 内容 | 答什么 |
|---|---|---|
| **推导线**（正文要体现的那条） | **生物存在（会散）→ 逆熵 → 通用维持律 → 统一式子** | **凭什么能这么写** |
| **动机层**（史） | 意识 → 算法 → 统一式 | 为什么会做这个 |
| **对象层**（史） | **公式来源：生物**（维持公式是从生物身上量出来的）；**验证顺序：恒星、石头 → 物理 → 化学 → 其余** | 试过哪些对象、按什么顺序 |

**对象层要拆成两段看**：**「公式从哪来」只有一处——生物**（那一格有账、有代谢、有实测数）；**「往哪推、按什么顺序」是另一条线**——**先恒星、石头（同形对上）→ 再物理（输运跑通）→ 接化学（误差几乎没有）→ 然后才是其余域**。**这两段混成一句，就会把「来源」写成「验证顺序」。**

**推导线里有一处**物理**要写进来（否则统一式子像凭空长出来的）**：

- **统一式子由两块拼成**：**主干来自维持律**（`E_in ≥ ΔG_s + Q` 这个判据形状）；**输运项来自物理**——`D·(A/δ)·ΔC` **借的是四力衰减核** `作用 = 结构量 × 系数 × G(r/λ)` **的形状**；
- **顺序是**：**先有物理的核**（客观规律）→ **再把它当参考写进输运项** → 于是统一式子才完整；
- **反过来写就错**（写成「物理是我们式子的实例」）——**那是倒因为果**。

**推导线每一步都有前件，缺一个就推不出来**：

- **统一式子的前件是维持律**——没有「不付就散」，写不出 `E_in ≥ ΔG_s + Q`；
- **维持律的前件是逆熵**——散是默认，所以「维持」是一个**动作**，不是状态；
- **逆熵的前件是生物存在**——**一个会散的东西真的在那儿**，才有「它怎么还没散」这个问题。

## 二、它是「推翻论证」剩下的

**机制**：**立一条 → 拿反例推翻 → 改 → 再推翻 → 剩下的那条就「全能解释」**。

**所以「全能解释」不是优点，是筛出来的结果**——**一个域一个域拿反例去打（恒星、石头、化学、电路、社会、数学、AI），打完剩下的形状就是这样。**

**判据**：**问「这一条被推翻过几次」**——**没被推翻过的不能算「能解释」**（只是还没人试过）。

## 三、名字的沿革（免得读成两套理论）

- **最早叫「摊账律」**（2026-11-20）：「逆熵这笔账必须被摊开付；摊开就必须维护；不维护，账就断，大家一起退回原始」；
- **摊账只覆盖生命那一支**（分母是「大家」，要求账能被摊开）；**恒星不摊账**——它自己烧自己的，没有第二个分母；
- **所以根往上提一层，改名「维持律」**：「任何有结构的东西，不持续付账就散」；**摊账律降为它在生命支上的规则**。

**「维持」不等于「恒定」**：石头恒定亿万年、火焰恒定地烧，**它们都不叫维持**——**因为它们没在付账**。**维持 ＝ 付账的恒定**；不付账的恒定只是**还没散完**。

## 四、最后一格归数学界

- **`P < NP` 是当前**：生成要遍历树、验证不用走树；
- **`P ≤ NP` 里的等号是因为终点可达**（破解后有反推那条路），**不是现在已相等**；
- **若 `P = NP` 被证明**，等于给「这个统一公式真的能当统一公式来用」一个答案——**通用性从主张变成结论**；
- **这一格归数学界**；**我们这边做的是把它对到全对得上**（八个域、外部锚、可推翻点都在账里；一证全证＝归约＋换档）。

**判据（这套东西最硬的推翻点）**：**若将来证明不存在这类捷径，这套理论直接不存在**——不是部分失效。
